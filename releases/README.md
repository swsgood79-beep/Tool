# 완료톡 v2.1.0 — 회사 PC 서버 통합 프로그램

Windows 10/11 64비트용입니다. 수주 관리 서버, QR 발급, 작업 완료 소리·팝업 알림, 무료 임시 인터넷 연결을 포함합니다. Python이나 별도 서버를 설치하지 않아도 됩니다.

## 다운로드

**[프로그램 ZIP 다운로드](https://github.com/swsgood79-beep/Tool/raw/refs/heads/main/releases/WanryoTalk-MyPC-Windows-x64-v2.1.0.zip)**

**v2.1.0 변경사항**

- 작업 완료 알림을 오른쪽 아래의 둥근 카드로 변경했습니다. 노란 포인트, 작업자·프로젝트명 구분, 부드러운 등장/사라짐과 새 알림음을 적용했습니다.
- 알림이 현재 작업 중인 창의 포커스를 빼앗지 않습니다. 12초 뒤 자동으로 사라지고, 마우스를 올리면 유지됩니다. X로 닫거나 카드를 눌러 완료 내역을 볼 수 있습니다.
- 여러 접수는 화면 공간에 맞춰 최대 3개씩 표시하고 나머지는 순서대로 보여 줍니다. 기록은 모두 관리자 화면에 남습니다.
- **작업 완료가 저장된 수주는 작업자 목록에서 자동 제외합니다.** 다른 작업자가 열어 둔 화면에서도 약 5초 내 사라집니다.
- 관리자 화면에는 ‘작업 완료’ 상태와 기록을 유지합니다. 재접수가 필요하면 ‘다시 표시’를 눌러 수주를 다시 열 수 있습니다.
- v2.0.1의 Chrome 수주 등록 수정은 유지했습니다. 이전 프로그램을 종료한 뒤 새 EXE를 실행하세요. 기존 수주 데이터는 같은 Windows 계정에서 유지됩니다.

ZIP 안의 `사용방법.txt`에 실행 순서가 들어 있습니다. 무결성 확인용 ZIP SHA-256은 `ZIP-SHA256.txt`에 있습니다.

## 실행 순서

1. 예전 완료톡이 켜져 있으면 프로그램의 **종료** 버튼으로 끝냅니다.
2. ZIP을 풀고 `WanryoTalk.exe`를 실행합니다.
3. **수주·QR 관리**에서 수주번호와 프로젝트명을 등록합니다.
4. **인터넷 연결**을 누르고 주소가 표시될 때까지 기다립니다(최대 약 90초).
5. 관리자 화면을 다시 열거나 새로고침하고 **QR 이미지 저장**을 누릅니다.
6. 휴대폰 와이파이를 끄고 데이터로 QR을 찍습니다. 해당 수주에 이름을 적고 **작업 완료**를 누르면 PC에서 소리·팝업 알림이 발생합니다.

X 버튼은 알림 영역으로 숨깁니다. PC와 프로그램, 인터넷이 켜져 있어야 접수할 수 있습니다.

## 주의할 동작 조건

- 무료 임시 Cloudflare Quick Tunnel을 사용합니다. 프로그램 재시작이나 새 연결 시 주소가 바뀔 수 있으므로 QR을 다시 전달해야 할 수 있습니다. 기존 수주·완료 기록은 유지됩니다.
- Quick Tunnel은 시험용 서비스이며 가동 시간 보장이 없습니다. 고정 QR과 상시 업무용 안정성이 필요하면 고정 주소 연결로 전환해야 합니다.
- 회사망에서 Cloudflare 연결을 허용해야 합니다. 인터넷 통신은 Cloudflare를 경유하고, 기록 파일은 PC에 저장합니다.
- Windows 실행 파일은 Linux에서 교차 빌드했습니다. 실제 Chromium 수주 등록·작업 완료를 포함한 테스트 21개와 경쟁 상태 검사, Windows 대상 정적 검사, ZIP 무결성 검사를 통과했습니다. 새 알림 카드의 실제 Windows 화면·소리와 회사망 터널 연결은 실기기 확인이 필요합니다. 창 제목의 버전은 v2.1.0입니다.
- 실행 파일에 디지털 코드 서명은 포함하지 않았습니다.
