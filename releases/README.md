# 완료톡 v2.3.0 — 고정 QR + 날짜별 Excel 자동 저장

Windows 10/11 64비트용입니다. 이전 프로그램을 **종료**하고 새 ZIP의 `WanryoTalk.exe`를 실행하세요. 기존 수주·출하검사·세팅검사 기록은 유지됩니다.

## 다운로드

**[v2.3.0 프로그램 ZIP 다운로드](https://github.com/swsgood79-beep/Tool/raw/refs/heads/main/releases/WanryoTalk-MyPC-Windows-x64-v2.3.0.zip)**

## 1. 같은 QR을 계속 사용하기

1. EXE에서 **고정 QR 설정**을 누릅니다.
2. 설정 화면의 링크로 [ngrok 무료 계정](https://dashboard.ngrok.com/signup)을 만듭니다.
3. [Domains](https://dashboard.ngrok.com/domains)에서 할당된 고정 주소를 복사합니다. 예: `example.ngrok-free.app` 또는 `example.ngrok-free.dev`.
4. [Your Authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)의 인증키를 **프로그램 설정 화면**에 입력합니다. 채팅·GitHub·이메일로 보내지 마세요.
5. **암호화하여 설정 저장** → EXE의 **인터넷 연결**을 누릅니다.
6. 연결 후 **수주·QR 관리**에서 QR을 저장·출력합니다.

**기존 임시 주소 QR은 고정 주소용으로 한 번 새로 출력해야 합니다.** 이후 같은 ngrok Domain과 PC 데이터 파일을 유지하면 재시작해도 같은 QR을 사용합니다. 회사 PC·프로그램·인터넷은 켜져 있어야 합니다. 별도의 ngrok 프로그램 설치는 필요 없습니다.

ngrok 무료 요금제의 현재 사용량 한도와 첫 방문 안내 화면이 적용될 수 있습니다. 첫 방문에 안내 페이지가 보이면 사이트로 이동하는 버튼을 눌러 주세요. ngrok 계정의 Domain을 삭제·변경하면 기존 QR을 유지할 수 없습니다. 유료 기능이나 구독을 자동으로 구매하지 않습니다.

## 2. 파일 하나에 날짜별 시트 자동 저장

기본 저장 위치는 Windows **문서 폴더 → 완료톡 → 작업완료기록.xlsx**입니다. EXE의 **엑셀 폴더** 버튼으로 정확한 위치를 열 수 있습니다. 문서 폴더가 OneDrive로 지정된 PC는 해당 Windows 문서 위치를 따릅니다.

- 한 Excel 파일 안에 `2026-11-05`, `2026-11-06`처럼 **한국시간 날짜별 시트**를 추가합니다.
- 기록 열: **완료일자 / 완료시각 / 작업자 / 수주번호 / 프로젝트명 / 검사구분 / 기록번호**.
- 출하검사와 세팅검사가 각각 한 행입니다. 날짜·시각은 분석 가능한 실제 Excel 날짜/시간 값입니다.
- 검사 완료 후 자동 저장하며, 프로그램을 재실행해도 기록번호를 기준으로 중복 추가하지 않습니다.
- 기존 완료 내역도 날짜에 맞춰 채웁니다. 프로그램 실행 중 새 날짜가 되면 오늘 시트를 만듭니다. 꺼져 있던 날의 빈 시트를 임의로 만들지는 않습니다.
- Excel에서 파일을 열어 잠겨 있으면 PC의 원본 완료 기록을 먼저 저장하고, 파일을 닫으면 **10초 간격으로 자동 재시도**합니다. 관리자 화면에서 Excel 저장 상태를 확인하세요.
- 브라우저의 **엑셀 파일 받기**는 현재 파일의 다운로드 사본입니다. 자동 갱신되는 원본은 위 문서 폴더의 파일입니다.
- 개인 분석 메모용 추가 열은 보존합니다. 자동 기록 열 A~G와 숨겨진 내부 정보 시트·기록번호는 바꾸지 않는 편이 좋습니다. 기존의 다른 Excel 파일을 같은 이름으로 두었으면 덮어쓰지 않습니다.
- 기록은 **완료 시각**입니다. 작업 시작 시각이나 작업 소요시간은 수집하지 않습니다.

## 기존 기능

프로젝트별 출하검사·세팅검사를 별도 담당자와 시각으로 접수하고 두 검사 완료 후 작업자 목록에서 숨깁니다. 관리자는 완료 기록을 확인하고 검사를 다시 열 수 있습니다. 우측 하단 카드 알림과 미리보기, 원본 기록 암호화·기존 데이터 백업은 유지합니다.

## 검증 범위

실제 Chromium 설정 저장·인증키 비노출·검사 접수·Excel 다운로드를 포함한 테스트 **38개**와 경쟁 상태 검사를 통과했습니다. 날짜 경계, 파일 잠금 후 재시도, 중복 방지, 기존 Excel 메모 보존, 재시작 시 고정 QR 동일성, 외부 연결의 관리자 화면 차단도 검증했습니다.

**실제 ngrok 로그인·고정 주소 접속은 사용자 계정 설정 후 확인해야 합니다.** 테스트는 모의 고정 엔드포인트를 사용했습니다. 실제 Windows 문서 폴더·DPAPI·소리·화면 및 회사망 접속은 실기기 확인이 필요합니다. EXE는 디지털 코드 서명이 없는 자체 빌드입니다.
