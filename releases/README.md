# 완료톡 v2.2.0 — 회사 PC 서버 통합 프로그램

Windows 10/11 64비트용입니다. 수주 관리 서버, QR 발급, 작업 완료 소리·팝업 알림, 무료 임시 인터넷 연결을 포함합니다. Python이나 별도 서버를 설치하지 않아도 됩니다.

## 다운로드

**[프로그램 ZIP 다운로드](https://github.com/swsgood79-beep/Tool/raw/refs/heads/main/releases/WanryoTalk-MyPC-Windows-x64-v2.2.0.zip)**

**v2.2.0 변경사항**

- 한 프로젝트 안에 **출하검사 / 세팅검사**를 각각 표시합니다. 검사별 작업자 이름과 완료시각을 별도로 저장합니다.
- 검사 순서는 자유입니다. 한 검사만 끝나면 나머지는 계속 접수할 수 있고, **두 검사 모두 완료되면** 작업자 목록에서 프로젝트를 제외합니다.
- 다른 작업자가 열어 둔 화면에도 약 5초 간격으로 검사 상태를 반영합니다.
- 알림 카드, PC 수신 목록, 관리자 내역, CSV에 검사 구분을 표시합니다. 예: ‘홍길동 · A프로젝트 출하검사 완료’.
- 관리자 화면에서 검사별 담당자·완료시각을 확인합니다. ‘검사 다시 열기’는 두 검사를 새로 접수할 수 있도록 초기화하며 과거 완료 기록은 보존합니다.
- 기존 수주·완료 기록은 유지하고 데이터 형식 변경 전에 자동 백업합니다. 과거 일반 작업 완료는 검사 종류를 임의로 지정하지 않고 이전 기록으로 표시합니다.
- v2.1.0의 카드 알림 디자인과 Chrome 수주 등록 수정은 유지했습니다.

ZIP 안의 `사용방법.txt`에 실행 순서가 들어 있습니다. 무결성 확인용 ZIP SHA-256은 `ZIP-SHA256.txt`에 있습니다.

## 실행 순서

1. 예전 완료톡이 켜져 있으면 프로그램의 **종료** 버튼으로 끝냅니다.
2. ZIP을 풀고 `WanryoTalk.exe`를 실행합니다.
3. **수주·QR 관리**에서 수주번호와 프로젝트명을 등록합니다.
4. **인터넷 연결**을 누르고 주소가 표시될 때까지 기다립니다(최대 약 90초).
5. 관리자 화면을 다시 열거나 새로고침하고 **QR 이미지 저장**을 누릅니다.
6. 휴대폰 와이파이를 끄고 데이터로 QR을 찍습니다. 해당 수주의 출하검사 또는 세팅검사에 이름을 적고 **검사 완료**를 누르면 PC에서 소리·팝업 알림이 발생합니다.

X 버튼은 알림 영역으로 숨깁니다. PC와 프로그램, 인터넷이 켜져 있어야 접수할 수 있습니다.

## 주의할 동작 조건

- 무료 임시 Cloudflare Quick Tunnel을 사용합니다. 프로그램 재시작이나 새 연결 시 주소가 바뀔 수 있으므로 QR을 다시 전달해야 할 수 있습니다. 기존 수주·완료 기록은 유지됩니다.
- Quick Tunnel은 시험용 서비스이며 가동 시간 보장이 없습니다. 고정 QR과 상시 업무용 안정성이 필요하면 고정 주소 연결로 전환해야 합니다.
- 회사망에서 Cloudflare 연결을 허용해야 합니다. 인터넷 통신은 Cloudflare를 경유하고, 기록 파일은 PC에 저장합니다.
- Windows 실행 파일은 Linux에서 교차 빌드했습니다. 실제 Chromium 수주 등록·작업 완료를 포함한 테스트 27개와 경쟁 상태 검사, Windows 대상 정적 검사, ZIP 무결성 검사를 통과했습니다. 새 알림 카드의 실제 Windows 화면·소리와 회사망 터널 연결은 실기기 확인이 필요합니다. 창 제목의 버전은 v2.2.0입니다.
- 실행 파일에 디지털 코드 서명은 포함하지 않았습니다.

데이터 업그레이드 후에는 v2.2.0을 사용하세요. 이전 EXE는 새 검사 구분 형식을 읽지 못합니다. 자동 백업은 `%APPDATA%\WanryoTalk\projects-v1-backup-*.dat`에 저장합니다.
