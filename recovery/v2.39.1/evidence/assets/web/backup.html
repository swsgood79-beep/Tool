1. 복구키를 PC 밖에 보관

복구키 파일은 새 PC에서 백업을 여는 열쇠입니다. USB나 다른 기기에 보관하세요. 같은 PC에만 두면 포맷 때 함께 잃습니다. 복구키를 잃으면 저희도 해독할 수 없습니다. 채팅·GitHub 파일로 올리지 마세요.

2. 자동 백업 켜기

기존 GitHub 연결키를 사용합니다. 현재 Tool 저장소는 공개일 수 있으므로 자료는 강력한 복구키로 암호화한 파일만 Releases에 올립니다. 복구키는 올리지 않습니다. 최근 3개를 보관하고 더 오래된 암호화 백업 사본은 정리합니다.

새 PC에서 복원

수주·기록·명단·휴대폰 등록이 없는 새 PC에서 인터넷 연결을 누르기 전에 진행하세요. 복구키 파일을 선택하면 GitHub에서 백업을 받아 새 Windows 계정에 맞게 저장합니다. 기존 수주가 있는 PC의 자료는 덮어쓰지 않습니다.

수주·사진·설정과 원래 QR 접근 키를 복원합니다. 프로그램을 다시 실행하고 인터넷 연결을 누르면 같은 작업자 QR을 사용합니다. GitHub 연결키가 만료/폐기된 경우 새 연결키가 필요합니다. 기존 휴대폰 브라우저의 수신 보관함은 휴대폰에 저장되어 별도이며, PC의 알림 발신 설정을 복원합니다.
