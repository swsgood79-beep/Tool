토스증권 Open API · 국내 지수

토스증권 WTS 설정 → Open API → 허용 IP에 회사 PC의 공인 IP를 등록하세요. 키와 토큰은 휴대폰에 보내지 않으며 키는 기존 Windows 계정 보호로 저장됩니다.

원·달러 환율은 토스의 참고용 매매기준율(midRate)을 1분 간격으로 조회하며 실제 환전 적용 환율과 다를 수 있습니다. 코인 시세는 업비트 KRW-BTC / KRW-ETH 공개 API를 사용합니다. 국내 지수는 이전 거래일 종가, 코인은 전일 종가(UTC) 대비입니다. 시세 기준시각을 함께 표시하며 실시간 체결을 보장하지 않습니다.
