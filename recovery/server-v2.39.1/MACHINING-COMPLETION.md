# 완료할 때 수량 입력 · PC 1.4.114

PC 업데이트 후 휴대폰 화면을 새로고침해 주세요. 가공팀 화면의 절단·가공1차·가공2차 모두 같은 방식입니다.

1. **시작**을 누르면 수량 입력 없이 현재 시각·작업자를 저장합니다.
2. 진행 중인 공정에 빈 수량 칸과 **완료** 버튼이 나타납니다. 왼쪽 수량은 해당 품목의 전체 작업 수량입니다.
3. 실제 끝낸 수량을 빈칸에 적고 **완료**를 누릅니다. 완료한 시각과 수량을 저장합니다.
4. 예: 32개 중 12개를 완료하면 **완료 12/32 · 남음 20**입니다. 남은 20개는 다시 **시작**을 누르고 이후 실제 완료한 수량을 입력합니다. 이전 12개 기록을 덮어쓰지 않고 회차별로 남깁니다.
5. 다음 공정은 앞 공정에서 완료한 수량까지만 완료할 수 있습니다. 절단 12개가 완료됐다면 가공1차는 최대 12개이며, 가공2차도 가공1차 완료분까지만 가능합니다.

빈칸·0·음수·소수·남은 수량 초과는 저장되지 않습니다. 다른 계정이 시작한 작업도 완료할 수 없습니다. 전체 수량을 완료하면 시작 버튼 대신 완료가 표시됩니다.

작업자에게 날짜·시간은 보이지 않으며, 관리자 작업 기록과 CSV에는 시작·완료 시각과 실제 완료 수량이 남습니다. 새로 시작한 작업의 완료 전 수량은 아직 미정이므로 진행 기록의 수량 칸은 비어 있습니다. 오늘 시작하고 내일 완료해도 실제 각 시각을 보존합니다.

업데이트 전 시작한 작업은 기존 ID·시작 시각·작업자를 유지합니다. 새 화면에서는 이 작업도 실제 완료 수량을 입력합니다. 구버전 화면 요청의 기존 수량 방식은 호환 처리하되 새 화면에서는 시작 시 수량을 요청하지 않습니다. ERP DB 자동 연동과 기존 완료·입고 확인 기록은 유지합니다.
