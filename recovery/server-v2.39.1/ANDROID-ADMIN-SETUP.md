# 알파 관리자 Android 앱 처음 설정하기

관리자 APK v1.0.9은 Android 8 이상에서 사용합니다. 회사 PC 프로그램은 v1.4.66 이상 (본인 아이디 표시 개선은 v1.4.67)이어야 합니다. 앱의 하단 메뉴는 작업·출고 일정·검사·토크·전체입니다. 수주카드와 출고 일정·출하 기록·토크는 기존 기능을 사용하며, 검사 탭에서 완료·반려 처리합니다. PC 관리자 화면과 일반 작업자 메뉴는 그대로 유지합니다. 전체 메뉴에서 업체 특이사항·공지사항·내 계정·알림 설정·로그아웃을 사용합니다. 작업자 앱은 변경하지 않습니다.

### 상단 담당자와 로그아웃

로그인 후 앱 상단에는 전체 메뉴와 같은 담당자 이름이 표시됩니다. 이름이 길면 줄임 표시하고 길게 누르면 전체 이름을 볼 수 있습니다. 옆의 **로그아웃** 버튼을 누르면 로그인 화면으로 돌아가고, 해당 휴대폰의 저장 로그인·지문 연결과 앱 알림 수신이 해제됩니다. 다음 로그인은 아이디·비밀번호가 필요합니다. 다른 관리자 휴대폰과 PC의 로그인은 유지합니다. 입력 중인 내용이 있으면 로그아웃 전에 확인합니다. 인터넷이 끊겨도 로컬 로그인 해제와 알림 차단은 즉시 적용하고, 서버 연결 해제는 가능한 경우 처리합니다.

## 1. 회사 PC와 APK 설치

기존 자료 저장 경로를 유지한 채 회사 PC 프로그램을 업데이트합니다. 인터넷 연결과 ‘휴대폰 관리자 접속’을 켭니다. 관리자 APK를 휴대폰에 설치하고 아이디 wssong과 현재 관리자 비밀번호, 또는 본인 개인 관리자 아이디·비밀번호로 로그인합니다.

서버의 앱 전용 로그인 연결은 직접 로그아웃할 때까지 유지합니다. 앱 종료·휴대폰 재시작·동일 서명 APK 업데이트·회사 PC 재시작·접속 주소 변경 후에도 저장된 연결을 사용할 수 있습니다. 한 번 로그인한 뒤에는 직접 로그아웃할 때까지 매번 인증하지 않습니다. 앱 전환은 업무 화면을 유지하고 완전 재실행은 저장된 연결을 서버에서 확인하여 복원합니다. 비밀번호는 저장하지 않고 별도의 로그인 키를 Android Keystore로 암호화합니다. 앱 삭제/데이터 초기화, 관리자에 의한 연결 해제, 비밀번호 변경 또는 계정 중지는 재로그인이 필요합니다. 일반 브라우저의 기존 로그인 시간은 변경하지 않습니다.

분실한 휴대폰은 기존 관리자 계정의 ‘전체 → 관리자 앱 알림 연결 → 로그인이 유지되는 관리자 앱 → 앱 로그인 해제’로 끊을 수 있습니다.

### 로그인 유지와 화면 전환

처음 설치하거나 직접 로그아웃한 경우에는 아이디·비밀번호 화면을 표시합니다. 한 번 로그인하면 다른 앱을 쓰다 돌아오거나 화면을 껐다 켜도 기존 업무 화면을 그대로 사용하고, 앱을 완전히 종료했다 켜도 저장된 계정을 서버에서 확인하여 접속합니다. 매번 비밀번호·지문 인증을 요구하지 않습니다. 저장된 연결이 있으면 로그인 폼이 잠깐 나타나지 않고 연결 화면을 표시합니다. 잠시 통신이 안 되면 저장된 키를 지우지 않고 다시 연결하며, 연결 화면에서 직접 로그아웃할 수 있습니다.

직접 로그아웃·앱 데이터 삭제·관리자에 의한 계정/기기 연결 해제·비밀번호 변경 등으로 저장 연결이 무효화되면 다시 로그인해야 합니다. 지문창은 직접 지문 버튼을 눌렀을 때만 엽니다. 사진/파일 선택 복귀도 기존 업무를 유지합니다.

회사 PC v1.4.72 이상에서는 상단 ⋮ 또는 하단 전체 메뉴의 **작업자 화면 보기**로 실제 작업자 수주카드와 메뉴를 볼 수 있습니다. 작업자 화면에서 같은 위치의 **관리자 화면으로 돌아가기**를 사용합니다. 화면만 바뀌고 관리자 로그인·권한·FCM 수신은 유지합니다. 다른 검사자의 권한이 늘어나지 않으며 일반 PC/작업자 브라우저에는 이 전환 쿠키를 적용하지 않습니다.

### 업체 원본 특이사항 수정

회사 PC v1.4.74 이상에서는 관리자 화면 전체 메뉴의 기존 업체 특이사항 위치가 **업체 특이사항 관리 → 해당 업체의 업체 특이사항 수정**으로 바뀝니다. 이 경로로 글·사진을 편집하고 **업체 수정 저장**을 누릅니다. 자동 반영으로 연결된 수주에도 업체 원본 변경이 적용됩니다. 작업자 보기 중이면 먼저 관리자 화면으로 돌아옵니다. 이 메뉴 추가는 서버 업데이트이며 APK 1.0.7을 다시 설치할 필요가 없습니다.

### 밝게·어둡게·기기 설정

전체 → 화면 밝기에서 선택합니다. PC v1.4.76과 APK v1.0.9은 웹 입력 묶음·검사·관리 화면과 Android 상단 바·로그인·연결·앱 대화상자를 같은 설정에 맞춥니다. 밝게/어둡게는 기기 설정보다 우선하고 기기 설정은 Android 주야간 설정을 따릅니다. 선택은 앱에 저장해 재실행과 접속 주소 변경 후에도 사용합니다. 이전 APK는 웹 화면 보완은 받을 수 있지만 앱 상단 테마 보완에는 APK 업데이트가 필요합니다.

## 2. Firebase 프로젝트 생성 (처음 한 번)

1. https://console.firebase.google.com/ 에 Google 계정으로 접속합니다.
2. ‘프로젝트 추가’로 새 프로젝트를 만듭니다. Analytics는 필수가 아닙니다.
3. 프로젝트 개요의 Android 앱 추가를 선택합니다.
4. Android 패키지 이름을 정확히 `com.alpharobotics.admin` 으로 입력합니다. 닉네임은 ‘알파 관리자’로 합니다. 이 FCM 설정에는 SHA 인증서 등록이 필수가 아닙니다.
5. `google-services.json`을 내려받습니다. SDK 추가 단계는 이 APK에 이미 구현되어 있으므로 넘어갑니다.
6. 톱니바퀴 → 프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성으로 서비스 계정 JSON을 받습니다.
7. 프로젝트 설정 → 클라우드 메시징에서 Firebase Cloud Messaging API (V1)가 사용 설정되어 있는지 확인합니다. 꺼져 있으면 ‘API 관리’에서 활성화합니다.
8. 회사 PC의 기존 관리자 화면 → 전체 → 관리자 앱 알림 연결에서 두 JSON을 선택하고 ‘Firebase 연결 저장’을 누릅니다.

서비스 계정 JSON은 비밀키입니다. 채팅·토크·공개 GitHub에 올리지 마세요. 회사 PC의 기존 보호 자료 저장소에 저장됩니다. 기존 암호화 백업에는 함께 포함됩니다. APK에는 비밀키를 넣지 않습니다.

## 3. 휴대폰 알림 확인

앱에 로그인하고 Android의 알림 허용을 선택합니다. 앱 상단 ⋮ → ‘앱 테스트 알림 보내기’를 누릅니다. 알림을 누르면 해당 검사 화면으로 이동하며 관리자 인증이 적용됩니다.

알림 소리와 진동은 전체 → 알림 소리·진동 설정 또는 ⋮ → ‘알림 소리·진동 설정’ → ‘검사 신청·비고 알림’에서 조정합니다. 삼성 인터넷 알림과는 별개입니다. 중복 알림이 필요 없으면 기존 브라우저 알림을 수동으로 끌 수 있습니다.

앱을 화면에서 닫아도 FCM 수신을 사용합니다. Android 설정에서 앱을 ‘강제 종료’한 경우 다시 실행해야 합니다. 휴대폰 인터넷·알림 허용·절전 정책에 따라 도착이 지연될 수 있습니다. 회사 PC와 프로그램·인터넷은 계속 켜져 있어야 합니다. 이 앱이 회사 PC의 서버를 대신하지는 않습니다.

## 4. 업데이트

기존 관리자 업무 화면은 회사 PC 프로그램 업데이트를 따라갑니다. 앱은 약 15초마다 서버 버전을 확인하며 입력·저장 중에는 화면 갱신을 보류합니다. 카메라·알림·Android 기능처럼 APK 자체 변경이 있을 때만 새 APK를 같은 서명으로 덮어 설치합니다. 앱을 열면 새 APK 버전을 확인하고, 사용 중에는 약 5분마다 확인합니다. 새 버전이 있으면 ‘업데이트’ 버튼을 눌러 앱 안에서 내려받고 Android 설치 확인으로 진행합니다. 최초 한 번 알파 관리자의 ‘이 출처 허용’이 필요할 수 있습니다. APK의 패키지·버전·SHA-256·기존 설치 앱의 서명을 확인한 뒤에만 설치 화면을 엽니다. 입력·저장 중이면 보류합니다. 완전 무인 설치는 하지 않습니다. ⋮ → 앱 업데이트 확인으로 수동 확인할 수도 있습니다.

## 검증 범위

서버 로그인 복원·권한·로그아웃·계정 변경·푸시 전송 형식·실패 재시도는 자동 시험으로 검증합니다. Android APK 빌드·단위 시험·Lint·서명을 검사합니다. 실제 회사 Firebase와 실제 휴대폰의 잠금/백그라운드 알림은 Firebase 설정 후 테스트해야 합니다. 회사 데이터에 접속하거나 변경한 시험은 없습니다.

## 사진 선택

APK 1.0.9에서 앨범을 누르면 갤러리/파일/카메라 선택이 표시됩니다. 삼성 갤러리가 사용 가능하면 갤러리 항목에서 직접 엽니다. 사진 장수·미리보기·저장 수정은 PC v1.4.76에도 포함되어 있으므로 함께 업데이트하세요.
