# v1.4.32 — 출고일정 목록의 겹친 프레임 제거

새 디자인의 출고일정에서 바깥 dialog 박스와 날짜별 수주목록의 회색 배경·테두리·안쪽 여백을 제거합니다. 출고 일정 제목과 달력은 위에, 선택 날짜·건수는 수주 카드 위에 한 줄로 표시합니다. 목록이 작업 메뉴와 같은 본문 폭을 사용해 PC 2열·모바일 1열 수주 카드의 폭·왼쪽 시작선·간격이 같아집니다.

달력의 날짜 격자 테두리·출고일/오늘/선택일 색상은 유지합니다. 수주 카드 자체의 남색 제목·3칸 버튼·출고일/검사 열기·녹색 완료·작업자 표시는 그대로입니다. 날짜·건수 계산·납기표 연결/제외·신청/승인/반려·전화·팝업·음성·자료·관리자 일반 수주목록은 변경하지 않습니다. 변경은 modern 인라인 캘린더에 한정한 CSS이며 기존 팝업 화면은 그대로입니다.

Chromium 관리자/작업자 × 밝게/어둡게 × 320/390/1100px 12조합으로 확인합니다. 원래 작업 목록의 실제 카드 폭, 동일 내용의 자연 높이, 목록 전체 폭/시작선, 카드 간격/아래 여백과 비교하고, 두 겹의 테두리/배경과 여백이 없어졌음을 검사합니다. 카드가 놓인 행에 작업자 줄 수가 다른 이웃 카드가 있으면 기존 grid 정렬에 따라 행 높이가 늘어날 수 있으므로 자연 높이는 align-self:start 상태로 별도 비교한 뒤 원래 상태로 복원합니다. 작업 메뉴의 기존 grid 정렬은 변경하지 않습니다.

공통 카드의 남색 제목·3칸 배치·전화·사급품 팝업·특이사항/키보드 진입·녹색 완료/작업자/건수·승인 후 자동 갱신·기존 화면 전환과 재선택·가로 넘침 없음도 함께 회귀 검증합니다. 스크린샷과 서버 응답은 합성 시험 자료입니다. 실제 Windows 실행·전화 앱·외부 연동은 이 환경에서 실행하지 않았습니다.

전체 Go race·Linux/Windows vet·Windows GUI 교차 빌드·전달 소스 ZIP 동일 실행파일 재빌드로 검증합니다. 별도 파일 경로가 필요한 선택 납기표 시험은 미지정으로 건너뜁니다. 원본 57개 web 에셋은 그대로 보존합니다.

기존 프로그램을 트레이에서 종료하고 새 EXE를 실행한 뒤 PC·휴대폰 화면을 새로고침하세요. 전체 소스·실행 ZIP·검증 자료는 GitHub 복구 브랜치에 보존하고 기존 ZIP은 덮어쓰지 않습니다. ERP 첨부파일·접속정보는 포함하지 않습니다.
