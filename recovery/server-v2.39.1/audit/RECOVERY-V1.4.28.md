# v1.4.28 — 기존 출고 일정 흐름을 유지하며 미정 집계 수정

요청한 범위는 캘린더·미정 건수에 연결되지 않은 과거 자료가 섞이지 않게 하는 수정입니다. 출고일이 있는 수주는 기존대로 캘린더에 표시하고 검사 완료 수주는 녹색 카드·완료 표시·세팅/출하 작업자를 유지합니다. 출고일이 없는 경우 현재 납기표 연결 표시가 있는 수주만 미정 집계에 포함합니다. 날짜도 없고 연결 표시도 없는 과거 완료 자료는 캘린더나 미정 집계에 포함하지 않습니다.

납기표에 연결돼 있던 수주가 원본에서 빠지면 저장된 출고일과 연결 표시를 해제하여 일정에서 제외하는 기존 동작을 유지합니다. 현재 납기표에 ASAP·미정 등으로 연결되면 날짜 미정으로 유지하고, 확정 날짜로 변경되면 해당 날짜에 표시합니다. 빈 날짜에서 연결 여부만 변경돼도 폴링이 갱신되도록 카드 개정 번호를 갱신합니다. 기존 수주·검사 기록은 삭제하지 않습니다.

‘미등록’ 메뉴 추가, 빠진 출고일 보존, 날짜 구분줄 배치 변경은 적용하지 않았습니다. 다른 화면·업무 흐름·음성·자료 형식은 변경하지 않습니다. 실제 회사의 27건이 어떤 수주인지나 이미 비워진 출고일은 여기서 확인할 수 없으며 날짜를 임의 생성하지 않습니다.

검증: 합성 자료로 연결되지 않은 과거 완료 27건, 실제 연결된 미정 2건과 날짜 확정 1건을 구성하여 실제 Go 렌더링 및 Chromium 관리자/작업자 320/390/1100px 밝게/어둡게에서 확인합니다. 미정 2건에 과거 27건이 섞이지 않음, 원본에서 빠지면 일정에서 제외, 날짜 확정 및 연결 여부 변경 갱신, 새로운 메뉴 없음과 가로 넘침 없음을 검증합니다. 별도로 v1.4.27의 완료 수주 녹색·작업자·건수·승인 후 폴링·새로고침 동작 12조합도 회귀 검증합니다. Go race 전체 시험, Linux/Windows vet, Windows GUI 교차 빌드, 전달 소스 ZIP 동일 실행파일 재빌드 검증을 수행합니다. 별도 파일 경로가 필요한 선택 납기표 시험은 경로 미지정으로 건너뜁니다. 실제 Windows나 회사 납기표를 여기서 실행·조회한 결과는 아닙니다.

기존 프로그램을 트레이에서 종료하고 새 EXE를 실행한 뒤 PC·휴대폰 화면을 새로고침하세요. 기존 납기표 연결 설정은 유지하며 필요하면 납기표 연결 화면의 ‘지금 갱신’을 실행합니다. 전체 소스·실행 ZIP·검증 자료를 GitHub 복구 브랜치에 보존합니다. ERP 첨부파일·접속정보는 포함하지 않습니다.
