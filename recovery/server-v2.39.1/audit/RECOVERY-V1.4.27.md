# v1.4.27 — 완료된 검사와 실제 출고 일정 분리

검사 완료만으로 출고 캘린더에서 수주를 제외하던 조건을 제거합니다. 미리 세팅·출하검사를 끝내도 지정된 출고 예정일에 수주와 건수를 유지합니다. 과거 검사 완료 수주도 예정일에 포함합니다. 날짜 미정은 기존 미정 목록에서 조회합니다. 숨김 수주는 기존 동작대로 제외합니다.

관리자와 작업자 캘린더의 완료 카드는 녹색 배경·테두리, ‘✓ 검사 완료’, 세팅·출하 작업자 이름으로 표시합니다. 다크모드에서는 어두운 녹색 배경과 밝은 녹색 글자를 사용합니다. 설계담당자·사급품·특이사항과 v1.4.26 시장정보/캘린더 격자는 유지합니다. 일반 작업목록·금일 완료·오늘 납기 필터는 변경하지 않습니다. 실제 출하 완료를 의미하는 새 상태는 추가하지 않습니다.

검증은 실제 Go 신청/승인 함수로 미래 납기의 완료 수주를 생성하고 페이지·폴링·재시작을 확인합니다. Chromium 관리자/작업자, 320/390/1100px, 밝게/어둡게 12조합에서 예정일 건수, 녹색 카드와 작업자, 이전 날짜 검사 완료, 숨김 제외, 완료 직후 자동 갱신, 새로고침 후 유지, 가로 넘침 없음과 인라인 캘린더를 검증합니다. 모든 자료는 합성 시험 자료입니다. 전체 Go race, Linux/Windows vet, Windows GUI 교차 빌드와 전달 소스 ZIP의 동일 실행파일 재빌드로 검증합니다. 별도 납기 파일 경로가 필요한 선택 시험은 경로 미지정으로 건너뜁니다. 실제 회사 Windows 실행은 이 환경에서 수행하지 않았습니다.

이전 프로그램을 트레이에서 종료하고 새 EXE를 실행한 뒤 열려 있는 PC·휴대폰 화면을 새로고침하세요. 데이터 형식·원본 자료·음성 설정은 변경하지 않습니다. 이전 ZIP과 전체 소스는 GitHub 복구 브랜치에 보존합니다. ERP 분석 자료·접속정보는 본 저장소나 배포 ZIP에 포함하지 않습니다.
