# v1.4.76 / APK 1.0.9 · 출하사진 추가와 갤러리 선택

사용자는 PC에서는 추가 저장이 되지만 관리자 휴대폰 앱에서 사진 선택 후 미리보기·추가 장수가 갱신되지 않는다고 보고했습니다. 사진 선택 창에는 카메라와 파일만 있었고, 파일을 누르면 Google Photos가 열렸습니다. Google Photos 사용 자체를 원인으로 단정하지 않습니다.

기존 자산 v1.4.60은 DataTransfer/FileList 대입 실패 시 카운트/미리보기 렌더 전에 예외가 발생함을 Chromium에서 의도적으로 해당 API를 실패시켜 재현했습니다. 실제 기기의 원인이 동일하다고 확정한 것은 아닙니다. 새 v1.4.76 자산은 실제 File 배열로 FormData를 직접 전송합니다. Android 제공자의 빈/일반 MIME은 허용 확장자와 서버 실제 이미지 디코딩 검사를 거칩니다. object URL 미리보기와 출하기록 페이지의 img-src blob 허용으로 큰 Base64 복사를 줄입니다. 인증/CSRF/이미지 크기/30장 한도는 유지합니다.

POST 성공 응답 JSON을 요청한 경우에만 JSON으로 결과 경로를 돌려주고 일반 POST의 303은 유지합니다. 서버 성공·동일 출처/정확한 결과 경로 확인 뒤에만 form.reset으로 입력 중 상태를 지우고 이동합니다. 오류 시 파일 선택을 유지하고 중복 업로드 키를 재사용합니다. 기존 사진/보관일과 서버 롤백/중복 방지 검사를 유지합니다.

APK 1.0.9/versionCode 10은 갤러리/파일/촬영을 명시적으로 표시합니다. 삼성 갤러리가 사진 선택을 처리할 수 있으면 패키지 지정 ACTION_PICK으로 직접 열고, 없는 기기는 갤러리 선택 창으로 연결합니다. 파일은 ACTION_OPEN_DOCUMENT이며 복수 선택 ClipData와 단일 URI를 수집해 중복 제거합니다. content URI만 WebView에 전달합니다. 카메라는 앱 캐시 FileProvider URI와 제한된 임시 읽기/쓰기 권한을 사용합니다. 기존 로그인 유지·FCM 채널·앱 서명은 변경하지 않습니다.
