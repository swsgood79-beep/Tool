# v1.4.50 보관함 상세 화면 정리

메뉴 이름은 관리자·작업자 화면 모두 **출고 일정 | 출하 기록**으로 통일합니다.

승인한 PC·휴대폰 시안을 기존 보관함의 상세 화면에 적용합니다. 데이터·검사·사진 업로드·D 드라이브 저장 경로는 변경하지 않습니다. 기존에 보관한 수주에도 같은 화면이 적용됩니다.

- ‘수주카드 정보’ 제목과 별도 전화번호 텍스트를 제거합니다. 설계담당자 이름 전화 버튼은 유지합니다.
- 세팅·출하 작업자와 검사 날짜를 PC에서 3열, 휴대폰에서 세로 행으로 배치합니다. 값이 없는 출고 예정일은 표시하지 않습니다.
- 비어 있는 사급품 영역은 숨깁니다. 내용이 있으면 엑셀 색상의 상태와 수령내역 표(종류·제조사·품번·수량)를 표시합니다.
- 표 내부에서만 가로·세로 스크롤하며, 휴대폰에서는 가로 스크롤 안내를 표시합니다. 사진 2열과 확대·저장 동작은 유지합니다.

검증 결과는 go-test-race-v1.4.50.txt, shipping-browser-v1.4.50.txt 및 browser-shipping-records-v1.4.50.json에 기록합니다. Chromium PC/휴대폰 밝게·어둡게 및 320px 폭, 사진 등록/보관/검색/전화 링크를 검증합니다. 기존 검사·비고·토크 52개 및 재연결 22개 검증은 변경하지 않은 해당 기능의 v1.4.49 기록을 참조하며, 이 버전에서 재실행했다고 표시하지 않습니다. 실제 Windows GUI/DPAPI·실물 휴대폰·회사 자료 실행은 하지 않았습니다.

GitHub recovery-v2.39.1 브랜치에 전체 소스와 Windows ZIP, 소스 ZIP, 재빌드 확인 기록을 함께 배포합니다.
