# v1.4.21 — 새 모바일 디자인 선택형 미리보기

## 사용

기존 프로그램을 트레이의 종료로 완전히 종료하고 새 EXE를 실행합니다. 휴대폰/PC 브라우저에서 현재 화면을 새로고침한 뒤 상단 ‘새 디자인 미리보기’를 누릅니다. 마음에 들지 않으면 상단 ‘기존 화면’으로 즉시 되돌립니다. 기본은 기존 디자인이며, 브라우저 localStorage `alpha-design-preview-v1`에 선택을 저장합니다. 다른 직원이나 다른 기기에 강제 적용하지 않습니다. 접속 주소(origin)가 바뀌거나 브라우저 저장소를 비우면 다시 선택해야 합니다.

## 화면

- 관리자 홈: 실제 대기 건수·오늘 납기·활성 수주 요약 및 검사 신청 목록. 하단 홈/수주/검사/전체 메뉴.
- 관리자 수주: 기존 필터·검색·페이지 이동·수정 및 상세 기능을 유지하며 카드로 정리.
- 검사 신청 목록: 검사 종류·수주·프로젝트·신청자 표시. 새 디자인에서는 목록의 직접 완료 폼을 숨기고 검사 화면 열기로 이동하며, 검사 상세의 완료·반려 버튼은 유지. 기존 화면에서는 목록의 원래 완료 폼도 그대로 표시.
- 전체 메뉴: 화면 전환·업무 관리·연결/설정·관리 도구를 묶음. 기존 관리 도구 전체 보기에서 QR·엑셀·최근 기록 등 기존 기능에 접근. 브라우저 음성 도구는 전체 메뉴에 표시되며 기존 수신·음성 기능은 유지.
- 작업자: 간결한 시세 요약(펼치기 가능), 검색·단계 필터·납기 필터·캘린더, 수주 카드. 작업/출고 일정/업체 특이사항/전체 하단 메뉴.
- 검사 신청: 세팅·출하 함께/세팅만/출하 선택. 기본은 실수로 통합 신청하지 않도록 세팅만 선택. 원래 폼·서버 토큰·요청 주소·잠금 조건을 사용. 선택 가능 여부는 실제 작업 단계에 따름. 특이사항 확인 창과 비고 입력 유지. 카드 갱신 중 이름·비고 및 선택한 신청 종류 보존.
- 출고 캘린더, 특이사항 확인, 검사 상세, 업체별 특이사항, 관련 설정/등록 화면을 같은 밝은 스타일로 표시.

원본 57개 web 파일은 수정하지 않습니다. CSS는 `html[data-alpha-design=modern]` 아래에만 적용하고, 원래 폼이나 검증 로직을 복제하거나 대체하지 않습니다. 디자인 전환 자체는 서버에 저장 요청을 보내지 않습니다. 로그인/지문 핸드오프는 대상에서 제외하고 원래 인증 절차를 유지합니다. PC 네이티브 창 자체의 레이아웃은 이번 미리보기에서 바꾸지 않았습니다. 모든 특수 보조 페이지를 새로 제작했다는 의미는 아닙니다.

## 검증

Go로 렌더링한 합성 수주를 사용하고 브라우저의 폴링/요청 응답은 시험용으로 대체했습니다. 360/390/1100px에서 관리자/작업자 페이지 이동, 초기 기존 화면, 선택 유지, 기존 화면 복귀 시 검색·이름·비고 보존, 실제 신청 폼의 종류·토큰·주소, 실시간 갱신 중 선택 보존, 특이사항 선확인, 캘린더의 해당 수주 진입·담당자, 업체 내용, 관리자 완료/반려 표시, 가로 넘침을 확인합니다. 신청 POST는 시험용 HTTP503 캡처로 실제 업무 데이터에 쓰지 않습니다. 전체 Go race 검사, Linux/Windows vet, Windows GUI 교차 빌드 및 배포 소스 ZIP 재빌드 일치도 확인합니다. 별도 입력 납기표가 필요한 선택 검사 1건은 입력 경로 미지정으로 건너뛰었습니다. 실제 회사 Windows/삼성 인터넷 실기기 실행은 이 환경에서 수행하지 못했습니다.

**중요:** 디자인만 선택해서 미리보는 기능입니다. 별도 시험용 자료가 생기는 것은 아니며, 실제 검사 신청·완료·반려·수주 수정은 기존 업무 자료에 그대로 반영됩니다. 화면 선택을 되돌려도 이미 처리한 업무가 취소되지는 않습니다.
