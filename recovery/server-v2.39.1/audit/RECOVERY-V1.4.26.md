# v1.4.26 — 시장정보와 출고 캘린더 가독성 개선

작업자 시장 패널 왼쪽 위에 ‘시장정보’를 표시합니다. 원래 시장 화면 느낌의 남색 그라데이션·흰 가격·코랄 상승·하늘색 하락을 적용합니다. 4종 시세는 2×2, 환율은 아래 한 줄로 유지하고 펼치면 기준시각·조회 정보도 그대로 확인합니다. 실제 시세 API와 계산 로직은 변경하지 않습니다.

관리자와 작업자 출고 캘린더에 날짜 격자 테두리·요일 머리글 색·이전/다음 달 빈칸 배경을 적용했습니다. 출고가 있는 날은 연한 파랑, 선택일은 진한 파랑, 오늘은 노랑으로 구분합니다. 달 이동·오늘·날짜별 수주·하단 메뉴와 일반 화면 방식은 유지합니다. 작은 화면에서 날짜와 건수가 잘리지 않도록 간격을 조절합니다.

기존 자료·설정·음성·네이티브 창·수주 카드·관리자 메뉴 통합·반려 제외 기록 기능은 그대로 유지합니다. 원본 57개 내장 파일은 변경하지 않고 별도 스타일과 렌더링 연결로 적용합니다.

검증: Go 실제 렌더링의 합성 자료를 Chromium 320/390/1100px, 밝게/어둡게 6조합으로 확인했습니다. 제목 위치, 색상, 4종 시세/환율, 펼친 시각, 관리자·작업자 격자, 네 가지 날짜 상태, 가로 넘침 없음, 메뉴와 달 이동을 검증했습니다. 화면 캡처의 가격과 수주는 시험용 합성 자료입니다. 전체 Go race, Linux/Windows vet, Windows GUI 교차 빌드 및 전달 소스 ZIP 동일 실행파일 재빌드 검증을 수행합니다. 별도 파일 경로를 요구하는 선택 납기표 시험은 경로 미지정으로 건너뛰었습니다. 실제 Windows 실행, 실시간 시세 제공처, Samsung 브라우저 강제 다크 엔진은 여기서 실행하지 않았습니다.

업데이트: 이전 프로그램을 트레이에서 종료하고 새 EXE를 실행한 뒤 휴대폰/관리자 화면을 새로고침합니다. 전체 소스·실행파일 ZIP·검증 자료와 이전 버전은 GitHub 복구 브랜치에 보존합니다.
