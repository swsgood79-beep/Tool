# v1.4.73 · 관리자 앱 업체 원본 관리 메뉴

관리자 앱 전체 메뉴의 관리 그룹에 업체 특이사항 관리(/client-notes)를 추가합니다. 기존 목록/원본 수정/사진/저장/연결 수주 반영 기능을 바로 엽니다. 조회용 업체 특이사항(/client-directory/...)은 그대로 두고, 개인 관리자 계정의 기존 편집 권한도 유지합니다. APK용 디자인 JS를 v1.4.73으로 새로 배포하고 이전 자산은 보존합니다. PC 화면과 일반 작업자 화면·원본 web 57개 자산은 변경하지 않습니다.

PC 프로그램 v1.4.73 업데이트로 반영되며 APK는 서명·코드·업데이트 manifest 모두 기존 1.0.7 그대로입니다. 로그인 유지·작업자 화면 전환·알림과 회사 운영자료는 변경하지 않습니다.

검증: 임시 Go 서버/Chromium APK UA로 대표 관리자 및 개인 관리자 × 휴대폰/태블릿 4개 경로에서 전체 메뉴 진입→원본 목록→수정→실제 multipart 저장→작업자 조회 반영을 확인합니다. 나가기 대화상자/페이지 JS 오류가 없고 연결된 수주의 원본 내용도 반영되는지 서버에서 확인합니다. 전체 Go 테스트, Linux/Windows vet, Windows GUI 교차 빌드, 소스 ZIP 동일 Windows 재빌드·전체 체크섬·공개 다운로드 SHA-256 확인. 변경하지 않은 Android 빌드/23 JUnit/서명과 로그인/전환 race 증거는 v1.4.72 이력입니다.

제한: 실제 Android 기기/Windows 실행은 수행하지 않았습니다. 회사 데이터와 자격증명은 테스트에 사용하지 않았으며 공개 소스에 넣지 않았습니다.
