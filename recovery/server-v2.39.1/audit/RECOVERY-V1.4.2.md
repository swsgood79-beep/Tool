# v1.4.2 출고 캘린더 설계담당자 표시

관리자·작업자 캘린더에서 검사 대기/완료 수주 모두 담당자를 표시한다. 이름/전화는 기존 projectView의 연결된 담당자 명단을 기준으로 한다. 초기 화면, 관리자 수주 패널 갱신, 작업자 카드 갱신에 같은 data 속성을 포함한다. 이름이 있는 경우 녹색 버튼으로 표시하고 유효 전화번호가 있으면 tel 링크, 없으면 이름만 표시한다. 미지정 수주에는 버튼을 만들지 않는다. 검사 상태와 특이사항은 유지한다.

원본 web 자산 57개는 보존한다. 템플릿 파싱 때 두 카드 템플릿에 escaped 속성을 추가하고 extras의 버전별 캘린더 JS를 사용한다. 이전 JS 캐시를 피하기 위해 새 URL을 쓴다. 캘린더 렌더 서명과 MutationObserver가 이름/전화 변경도 감지한다. DOM textContent와 제한된 tel 스킴만 사용한다.

calendar_designer_test.go: 관리자/작업자 전체 화면과 폴링 조각, 완료 카드, 명단 변경, HTML 이스케이프 확인.
browser-calendar-designer-v1.4.2.json: 합성 자료로 관리자/작업자 × PC1100px/휴대폰390px 검사. 담당자/완료수주/전화번호/미지정/특이사항/열린 캘린더 갱신/가로 넘침/JS 오류 검증. 사진은 합성 자료다. 실제 통화 및 Windows 실기기는 실행하지 않았다.

v1.4/v1.4.1 운영 자료는 기존 선택을 그대로 열며 재가져오기·마이그레이션이 필요 없다. 원본 및 이전 ZIP은 보존한다.
