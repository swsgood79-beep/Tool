# v1.4.5 완료 수주를 출고 일정에서 제외

최신 사용자 정정: 출고 캘린더에도 완료 수주를 남기지 않는다. 이전 ‘납기·캘린더 예외 유지’ 동작을 폐기하고 일반/오늘납기/다음출고/캘린더에서 완료 수주를 제외한다. 캘린더 월간/날짜별/선택 날짜/미정 건수와 필터 건수도 미완료 기준이다. 오늘 완료한 수주는 금일 검사 완료에서만 보인다. 과거 완료는 직접 번호 조회/기록/엑셀에 보존하고 삭제하지 않는다.

공통 due-view, 관리자 필터, 작업자 필터, 캘린더의 버전별 extras JS를 적용한다. 원본 자산은 보존하며 URL을 바꿔 이전 캐시와 구분한다. 승인 뒤 열린 캘린더에서도 MutationObserver/렌더 서명을 통해 완료 수주와 건수를 갱신한다. 담당자·특이사항 기능은 유지한다.

browser-order-filters-v1.4.5.json: 합성자료로 관리자·작업자 일반 목록/금일 완료/오늘납기/캘린더에서 완료 수주 필터 및 건수, 열린 캘린더의 완료 전환, 담당자 유지를 검증한다. 이전 브라우저 보고서는 당시 정책으로 보존한다. Windows GUI 실제 실행이나 회사 자료/외부 계정은 이 환경에서 사용하지 않았다.
