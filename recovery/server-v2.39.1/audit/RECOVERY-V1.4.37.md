# v1.4.37 — 일반 공지 보라색 디자인

승인한 이미지에 맞춰 일반 공지 카드만 보라색으로 구분합니다. 테두리 #8958CF 2px, 왼쪽 강조선 5px, 연한 보라 배경 #F7F2FC, 배지 #8050C0/흰 글자와 확성기 아이콘, 하단 링크 #7040AC를 사용합니다. 다크모드에서는 배경 #292236, 테두리 #AC86E5, 링크 #D0B0FF로 표시합니다. 작업 화면과 전체 공지 목록의 일반 공지에 같은 스타일을 적용하며 긴급 공지의 빨간 테두리는 유지합니다.

## 변경 범위

새 announcements-v1.4.37.css와 로딩 주소 및 표시 버전, 배포 문서만 변경했습니다. 기존 공지 JS/HTML, 모델·저장·등록/수정/게시 종료·첨부 사진·백업과 수주·검사·알림·일정·카드 디자인은 그대로입니다. 원본 web 자산 57개도 보존했습니다.

## 확인

- 기존 Go 공지 테스트 2개 통과: 등록/수정/종료, 권한/CSRF/개정 충돌, 사진 제한·삭제/조회, 재실행·암호화 백업 및 수주/이벤트/엑셀 불변 검증과 화면 fixture.
- 기존 공지 브라우저 검증 12조합 통과: 새/기존 화면 × 밝게/어둡게 × 320/390/1100px. 메뉴·사진 확대·미리보기·자동 갱신/게시 종료 확인.
- 실제 Go 합성 작업 화면에서 일반 공지 비교용 카드를 복제해 390/1100px 밝게/어둡게 색상과 테두리를 확인하고 캡처했습니다. 회사 자료를 변경하지 않았습니다.
- Windows amd64 GUI 교차 빌드, ZIP 무결성·원본 자산 SHA-256, 소스 ZIP에서 동일 실행 파일 재빌드 확인. Windows GUI 실실행은 하지 않았습니다.
- v1.4.36의 전체 race/vet 검증 기록은 보존합니다. 이번 CSS 변경에는 해당 전체 검사를 반복하지 않았습니다.

## 업데이트

PC 프로그램을 트레이에서 완전히 종료하고 새 ZIP을 풀어 AlphaWorkComplete-Recovered.exe를 실행한 뒤 관리자·작업자 브라우저를 새로고침하세요. 공지를 다시 등록하거나 자료를 옮길 필요는 없습니다. 일반 공지는 새 색상으로 표시되고 긴급 공지는 기존 빨간색으로 남습니다.

전체 소스와 실행 ZIP·소스 ZIP·검증 기록을 GitHub 복구 브랜치에 추가하고 이전 버전은 보존합니다.
