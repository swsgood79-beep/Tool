# v1.4.65 · 관리자 앱 현장 메뉴

관리자 PC와 일반 작업자 브라우저 화면은 기존 mobile-design-v1.4.64.js 및 메뉴를 유지합니다. 인증된 Android 관리자 앱 요청에만 별도의 화면 자산을 제공합니다. 앱 하단은 작업·출고 일정·검사·토크·전체입니다. 작업 탭은 기존 관리자 수주카드, 출고 일정은 기존 달력과 출하 기록, 검사 탭은 기존 검사 신청·확인·완료·반려를 재사용합니다. 토크 탭은 작업자와 같은 분류·글쓰기·댓글을 사용하며 전체 메뉴에서 기존 관리자용 정리 화면도 열 수 있습니다.

APK 1.0.1은 명시적 User-Agent로 앱 화면을 선택하고 전체 메뉴의 고정 알림 설정/테스트 URI 두 개만 네이티브 동작으로 처리합니다. User-Agent는 권한을 부여하지 않습니다. 관리자 계정 인증·권한·CSRF 검증을 그대로 적용하며 네이티브 앱에서 작업자용 페이지로 이동할 때에도 관리자 인증을 요구합니다. 기존 APK의 지속 로그인 세션에도 새 서버 화면을 제공합니다. 일반 브라우저 세션에는 앱 화면 자산을 삽입하지 않습니다.

로그인 유지·로그아웃·FCM 백그라운드 수신은 v1.4.64를 유지합니다. APK는 기존 배포와 같은 비공개 키로 서명하여 덮어 설치 시 앱 자료와 로그인 연결을 유지합니다. 토크 읽음 정보는 기기/계정별 기존 서버 저장 방식을 사용하고, 앱 내부에서는 Pages 사이트나 작업자 PWA로 자동 전환하지 않습니다. 입력·저장 중 업데이트 보류와 의도된 제출 시 이탈 경고 억제를 유지합니다.

검증: Chromium에서 APK User-Agent를 사용한 실제 임시 Go 서버로 휴대폰 390px/태블릿 850px·밝게/어둡게의 메뉴·수주카드·달력·출하 기록 왕복·검사 신청 배지·검사 승인·토크 글 저장과 기존 PC/작업자 메뉴 보존 28개 항목 통과. Go 전체 시험·native race·Linux/Windows vet, Windows GUI 교차 빌드. Android release 빌드·JUnit 3개·Lint 오류 0개·기존 서명 인증서 일치 확인.

실제 회사 자료를 읽거나 수정하지 않았습니다. Android 실기기 설치·OS 설정 화면·실제 Firebase 푸시 수신은 이 환경에서 실행하지 않았으며, Firebase 최초 연결 후 휴대폰에서 테스트해야 합니다. 기존 회사 PC 프로그램이 자동으로 교체된 것은 아닙니다. Windows v1.4.65와 APK 1.0.1을 배포 파일로 제공합니다.
