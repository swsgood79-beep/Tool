# PC v1.4.99 · 토크 게시판 간격 정리

토크 상단의 **전체 · 작업안내 · 건의사항 · 일상생활 · 매뉴얼 게시판**을 한 줄로 정리했습니다. 넓게 나뉘던 4칸 고정 배치를 없애고 글자 길이에 맞춰 좌우 여백과 간격을 줄였습니다. 작은 휴대폰에서는 간격을 더 줄이고, 화면이 아주 좁으면 메뉴 안에서만 좌우로 이동합니다. 관리자·작업자, 밝은 화면·다크모드에 함께 적용하며 선택한 게시판의 파란 밑줄은 유지합니다. **회사 PC를 v1.4.99로 업데이트한 뒤 토크 화면을 새로고침하세요. 휴대폰 APK는 v1.0.11 그대로 사용합니다.**

수정 범위는 extras/talk-tabs-v1.4.99.css와 기존 렌더 경로(main.go/mobile_design.go)의 스타일 로딩입니다. 기존 web 원본 57개는 변경하지 않습니다. 목록/분류/상세에서 같은 talk-tabs에만 적용하고 선택 상태·색상 변수·게시글/첨부/권한은 유지합니다. 좁은 화면은 nowrap+컨테이너 스크롤로 본문 밖으로 메뉴가 넘치거나 두 줄로 내려가지 않게 합니다. 최소 44px 터치 높이를 유지합니다.

Chromium 관리자/작업자, modern/classic, 320/390/1100px, 밝게/어둡게에서 목록·3분류·상세 5탭 단일행/터치 높이/390px 이상 가로 스크롤 부재/선택 분류·매뉴얼 링크를 확인합니다. 전체 Go 시험·Linux/Windows vet·Windows GUI 교차 빌드·소스 ZIP 재빌드 일치를 확인하며 실제 Windows/휴대폰 기기 실행은 하지 않습니다.
