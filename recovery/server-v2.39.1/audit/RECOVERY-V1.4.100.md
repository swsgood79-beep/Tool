# PC v1.4.100 · 매뉴얼 토크 화면 통일

매뉴얼 게시판도 다른 분류와 같은 **토크 제목·설명 → 다섯 게시판 메뉴 → 검색·글쓰기 → 글 목록** 구조로 통일했습니다. 매뉴얼 목록·글쓰기·상세에서도 전체/작업안내/건의사항/일상생활/매뉴얼 게시판 메뉴가 유지되고 **매뉴얼 게시판**에 선택 밑줄이 표시됩니다. 각 메뉴를 눌러 다른 게시판으로 바로 이동할 수 있으며 관리자·작업자별 경로를 유지합니다. 본문 폭과 목록 여백을 맞추고 휴대폰 작업자·앱의 하단 토크 선택 표시도 유지합니다. 기존 매뉴얼 글·첨부파일과 **파일당 300MB/글당 5개** 한도는 그대로입니다. **회사 PC를 v1.4.100으로 업데이트한 뒤 토크 화면을 새로고침하세요. APK는 v1.0.11 그대로 사용합니다.**

매뉴얼 페이지에 같은 talk-tabs partial을 재사용하며 Talk(분류 메뉴 주소)와 Base(매뉴얼 동작 주소)를 분리합니다. Category=manual로 다섯 번째 메뉴만 aria-current를 제공합니다. 관리자 메뉴는 community-admin/manuals-admin, 작업자 메뉴는 현재 Board의 community/manuals로 연결합니다. 등록/검색/파일 다운로드 주소와 CSRF/소유권은 유지하고 저장 형식/용량 정책을 변경하지 않습니다. 일반 토크 화면의 기존 메뉴도 같은 partial을 사용합니다. 매뉴얼에서만 새 browser/app design 스크립트의 토크 탭 선택을 사용하고 다른 화면은 기존 script를 유지합니다.

Chromium 관리자/작업자, PC/휴대폰, 밝게/어둡게에서 목록·글쓰기·상세의 다섯 메뉴/매뉴얼 단독 선택·경로, 일상생활↔매뉴얼 왕복, 실제 파일 조각 업로드·원문 다운로드와 다크 목록 배경을 확인합니다. 기존 벨트 표/계산 검증도 유지합니다. 전체 Go 회귀, Linux/Windows vet, Windows GUI 교차 빌드와 소스 ZIP 재빌드 일치를 확인합니다. 실제 Windows/Android 기기 실행 및 실제 회사 자료 변경은 하지 않습니다. 원본 web 57개와 APK1.0.11은 유지합니다.
