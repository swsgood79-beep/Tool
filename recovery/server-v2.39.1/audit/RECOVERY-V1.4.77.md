# v1.4.77 / APK 1.0.9 유지 · 출하사진 개별 삭제

관리자 출하기록 상세의 각 출하사진 아래에 삭제 버튼을 표시합니다. 선택한 사진의 미리보기와 실제 삭제 결과를 설명하는 대화상자에서 확인한 뒤 삭제합니다. 일반 작업자와 특이사항 사진에는 삭제 버튼이 없습니다. 추가 업로드 파일을 선택했거나 업로드 중일 때는 먼저 저장/취소하도록 차단합니다. 기존 갤러리 확대/스와이프와 파일 추가 처리는 보존합니다.

관리자 세션, CSRF, 명시적 확인, 해당 기록 소유 사진, 사진 목록 버전을 검증합니다. 상태 저장 후 참조되지 않는 파일을 정리하므로 저장 실패 시 사진이 유지됩니다. 중간 사진을 삭제하면 다른 사진의 순서·보관일·메모·수주 스냅샷·담당자·검사 상태는 유지됩니다. 마지막 사진은 기존 전체 삭제 함수를 사용합니다. 현재 같은 검사 주기의 완료 수주는 새 기록 ID로 사진 대기로 되돌리며 이전 업로드 요청을 무효화합니다. 연결되지 않은 과거 수주 보관은 전체 기록을 삭제합니다. 확인창에 차이를 명시합니다.

검증: 서버 권한/CSRF/확인/다른 사진/오래된 버전/저장 실패 롤백/파일 참조 보호/디스크 재읽기/마지막 사진 재대기/이전 ID 업로드 거절/과거 기록 삭제. 실제 Go 임시 서버와 Chromium에서 PC/휴대폰 APK UA × 밝게/어둡게 4경우에 작업자 버튼 미노출·확인 취소·실패 후 재시도·중간 사진만 삭제·기존 보관일 유지·추가 사진 초안 보호·마지막 사진 재대기·나가기 창 없음 확인. 전체 Go, 사진 삭제/추가 race, Linux·Windows vet, Windows GUI 교차 빌드와 원본 web 57개 자산 해시 확인. 전체 소스 ZIP 체크섬/동일 EXE 재빌드/공개 배포 파일 SHA-256을 별도 기록합니다.

Android 소스/APK/업데이트 manifest는 v1.0.9 그대로입니다. 새로 서명하거나 재설치할 필요가 없습니다. 실제 Windows GUI, 삼성폰, Android 설치/FCM은 실행하지 않았습니다. 회사 자료와 개인키는 공개 패키지에서 제외합니다.
