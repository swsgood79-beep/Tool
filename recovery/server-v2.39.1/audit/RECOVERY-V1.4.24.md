# v1.4.24 — 관리자 홈·검사 메뉴 통합

홈은 이전 ‘기존 관리 도구 전체 보기’ 화면으로 변경합니다. 작업의 끝을 한눈에 헤더, 공용 QR(설정된 경우 PC에서), 월별 엑셀, 새 수주 등록, 수주 목록, 최근 기록 등 기존 관리 기능을 보여줍니다. 이전 홈의 큰 검사 요약과 검사 신청 목록은 홈에서 숨기고 검사 메뉴로 모읍니다. 전체 메뉴의 중복된 기존 관리 도구 바로가기는 제거합니다. 예전 `?design-tab=tools` 주소는 홈으로 표시합니다.

검사 메뉴는 이전 홈의 검사 대기 건수·오늘 출고·진행 중 수주·출고 일정 바로가기와, 검색/검사 종류 필터를 포함한 단일 검사 신청 목록을 함께 표시합니다. 홈의 검사 신청 버튼과 하단 검사는 같은 탭으로 연결됩니다. 알림/기존 링크의 `/inspection-requests` 주소도 요약과 목록이 통합된 화면으로 유지합니다. 이 주소는 초기 관리자 요약 값을 서버에서 제공하고 기존 읽기 전용 `/orders/panel`로 5초마다 갱신합니다. 관리자 인증·검사 처리·반려·읽음·수주 저장 방식은 바꾸지 않습니다. 기존 완료/반려 상세 화면 연결을 유지합니다.

작업자 DOM/메뉴/레이아웃/시세/검사 신청 로직에는 변경이 없습니다. v1.4.23과 v1.4.24 디자인 파일을 같은 합성 작업자 자료로 각각 로드하여 390/1100px × light/dark에서 목록·출고 일정·전체 메뉴의 전체 PNG가 정확히 일치하는지 확인했습니다.

관리자 검증: 390/1100px × light/dark. 새 홈의 관리 도구 표시, 검사 중복 제거, 통합 검사 요약/목록, 건수/검색/종류 필터, 단독 알림 주소의 실시간 건수와 목록 갱신, 완료/반려 상세 링크, 홈 검색 입력 보존, 뒤로/앞으로, 기존 tools 북마크, 가로 넘침을 확인했습니다. 자료는 합성이며 실제 업무 데이터에 쓰지 않았습니다. 전체 Go race·Linux/Windows vet·Windows GUI 교차 빌드 및 배포 소스 ZIP 동일 재빌드 검증을 수행합니다. 경로가 필요한 선택 납기표 검사 1건은 입력 경로 미지정으로 건너뛰었습니다. 회사 Windows/삼성 인터넷 실기기 실행은 이 환경에서 확인하지 못했습니다.

업데이트: 이전 프로그램을 트레이에서 종료한 뒤 새 EXE를 실행하고 관리자 웹 화면을 새로고침합니다. 실제 회사 자료·설정·QR·음성 및 작업자 주소는 기존 값을 사용합니다. 소스·실행 ZIP·검증 자료·이전 버전을 GitHub 복구 브랜치에 보존합니다.
