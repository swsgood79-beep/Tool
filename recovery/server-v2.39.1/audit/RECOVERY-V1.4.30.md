# v1.4.30 — 승인한 특이사항 화면 배치 적용

관리자 /projects/{id}/info와 작업자 /project-info/{board}/{id}에 같은 정보 배치를 적용했습니다. 출고 예정 배지는 단독 줄입니다. 그 아래 줄에 수주목록과 같은 연한 파란색 ‘☎ 담당자 이름’ 버튼을 놓고 두 줄의 왼쪽 시작선을 맞췄습니다. 버튼 문구에 ‘설계담당자’ 접두어와 전화번호를 표시하지 않습니다. 등록된 번호가 있으면 v1.4.29의 정상화한 tel 주소로 전화 앱을 엽니다. 번호 없는 담당자는 전화 링크를 만들지 않습니다.

사급품 버튼과 담당자 버튼 사이 가로 간격은 24px이며 좁은 화면에서 줄이 넘어가면 12px의 세로 간격과 왼쪽 정렬을 유지합니다. 사급품 내용 팝업·색상, 특이사항 글·메모·사진·돌아가기, 기존 목록·캘린더·납기표 동기화·녹색 완료 표시·검사 흐름·음성은 변경하지 않습니다. 원본 57개 web 파일은 그대로 두고 템플릿 메타 영역과 해당 화면에만 적용되는 스타일로 구현합니다.

Go 실제 관리자/작업자 경로에서 합성 페이지를 만들고 Chromium 관리자/작업자 × 기존/새 디자인 × 밝게/어둡게 × 320/390/1100px 24조합을 확인했습니다. 배지/버튼 왼쪽 좌표 일치·줄바꿈·간격·같은 파란색/문구·전화 링크 클릭·사급품 팝업·자동 갱신 후 전화번호/내용/배치 유지·날짜/번호/사급품 미등록·가로 넘침 없음을 검증합니다. 전화 앱은 OS를 실행하는 대신 tel 클릭 목적지를 확인했습니다. 캡처 자료는 회사 실제 자료가 아닌 합성 시험 자료입니다.

전체 Go race·Linux/Windows vet·Windows GUI 교차 빌드와 전달 소스 ZIP 동일 실행파일 재빌드를 수행합니다. 별도 납기 파일 경로가 필요한 선택 시험은 미지정으로 건너뜁니다. 실제 회사 Windows 실행·휴대폰 전화 앱은 이 환경에서 실행하지 않았습니다.
