# v1.4.44 긴급공지 수동 음성 방송

관리자 공지사항 관리 목록·상세의 게시 중인 긴급공지에 ‘음성 방송’ 버튼을 제공합니다. 공지 등록·수정·조회만으로는 방송하지 않습니다. 관리자가 버튼을 누르면 현재 수신 중인 공용 PC에 제목과 본문을 전달하고, 기존 선택된 음성·속도로 읽습니다. 사진을 읽거나 분석하지 않습니다. 일반 공지와 게시 종료 공지는 방송할 수 없습니다.

## 사용

1. 기존 프로그램을 종료하고 새 실행파일로 실행합니다.
2. 수신할 공용 PC의 작업자 화면을 열고 전체 메뉴에서 공용 PC 음성 알림을 켠 뒤 ‘이 공용 PC에서 긴급공지 음성 수신’을 선택합니다. 브라우저가 소리를 막으면 해당 화면을 한 번 눌러 허용해야 합니다. 이 선택은 현재 브라우저 원점의 localStorage에 저장됩니다. 주소·브라우저가 바뀌면 다시 선택해야 할 수 있습니다.
3. 관리자 → 공지사항 관리 → 게시 중인 긴급공지의 ‘음성 방송’을 누릅니다. 접수된 PC 수가 표시됩니다. 수신 PC가 없으면 설정 안내를 표시합니다. 실제 소리는 공용 PC 스피커에서 확인해야 합니다.
4. 필요하면 ‘다시 방송’을 누릅니다. 중복 클릭은 억제하며 별도의 의도적인 재방송은 가능합니다. 제목·본문 합계는 1,580자 이내를 권장하고 서버 생성 문장 포함 1,600자 초과는 안내 후 거부합니다. 긴 내용은 최대 220자씩 나누어 순서대로 읽으며 검사 음성의 기존 반복 설정은 유지하고 공지 방송은 한 번씩 읽습니다.

## 동작과 경계

- 기존 작업자 음성 poll과 동일한 브라우저 음성 소유권을 사용합니다. 같은 브라우저 여러 탭에서 중복 재생하지 않으며 음성 잠금 해제·연결이 실제로 활성화된 PC만 대상에 포함합니다. 수신은 명시적으로 선택해야 하며 전화기 UA/브라우저 모바일 감지에서는 선택란도 만들지 않고 서버에서 방송 오디오를 거부합니다. 기존 휴대폰 검사 알림 설정은 바꾸지 않습니다.
- 게시된 긴급공지를 서버에서 찾아 제목·본문을 조합합니다. 클라이언트 임의 텍스트는 사용하지 않습니다. 관리자 로그인·CSRF·공지 revision·요청 nonce를 검증합니다. 방송 대상은 버튼을 누른 순간의 유효한 수신 PC 목록으로 고정합니다.
- 반복 poll에서는 브라우저가 방송 ID로 중복을 제거합니다. 방송 요청의 응답이 끊겨도 동일 nonce 재시도는 추가 방송을 만들지 않습니다. 연결이 끊겼다가 돌아오거나 새 탭/새 PC가 연결돼도 예전 방송을 재생하지 않습니다. 게시 종료·수정 후에는 이전 방송의 남은 음성을 생성하지 않습니다.
- 방송 큐·수신 PC는 메모리에만 보관하고 최대 15분 후 만료합니다. 프로그램 재시작 시 지난 방송을 재생하지 않습니다. 수주·검사·기존 기록·공지 저장 데이터와 백업 형식, 납기표·사급품·D 저장 위치는 변경하지 않았습니다.
- 관리자 결과는 ‘방송 접수’입니다. 운영체제 음소거·스피커 고장·브라우저 중지·음성 생성 실패까지 실제 청취를 보장하는 재생 확인서는 아닙니다. 실패는 공용 PC 기존 음성 상태란에 표시합니다. 자동으로 무한 재방송하지 않습니다.

## 검증

- 전체 Go race 및 Linux/Windows go vet 통과. 권한·CSRF·수신 PC 없음·휴대폰 배제·대상 소유권·같은 요청 재시도·수신 해제·재접속/신규 PC 예전 방송 제외·게시 종료/수정 취소·음성 조각 전체 일치를 확인했습니다.
- Chromium 8개 조합에서 관리자 목록/상세 390/1100px, PC/휴대폰 밝은/어두운 테마를 확인했습니다. 명시적 전송만 발생하고 반복 조회에도 한 번 재생되며 긴 공지의 분할 오디오가 순서대로 재생 요청되는 것을 검증했습니다. 기존 검사 음성 재생과 수신 해제도 확인했습니다.
- 기존 기본 켜짐/자동 재생 허용/한 번의 클릭으로 잠금 해제/PC 기본 음성 선택 브라우저 회귀 시험을 관리자·공용 모드에서 확인했습니다.
- 브라우저 오디오와 HTTP 응답은 모의했습니다. 실제 회사 공용 PC의 스피커 소리·실제 AI 공급자 음성 합성·Windows 런타임은 이 환경에서 실행하지 않았습니다. Windows amd64 GUI 교차 빌드 및 소스 ZIP 재빌드 일치를 검증하고 이전 버전은 모두 보존합니다.
