# PC 1.4.104 · 대표 관리자 가공팀 화면 보기

대표 관리자도 **전체 → 가공 작업 · 입고 확인 → 가공팀 화면 보기**에서 작업자 전용 화면을 볼 수 있습니다. 수주별 표·로봇품번·수량·절단/가공 진행 및 작업 기록을 같은 화면으로 확인합니다. 미리보기에서는 시작/완료를 변경하지 않으며 **가공 관리로 돌아가기**로 ERP 엑셀 가져오기·입고 확인 화면에 복귀합니다. 관리자 APK 1.0.11은 유지합니다.

소유자 계정과 preview=1 요청을 서버에서 확인해 작업자 레이아웃을 읽기 전용으로 렌더링합니다. 미리보기의 데이터는 기존 인증된 가공 상태 API를 사용합니다. 작업 시작/완료 권한은 기존 가공팀 전용 서버 검증을 유지합니다. 새 JS 파일만 추가하고 원본 web57개는 변경하지 않습니다. Chromium 휴대폰 크기에서 미리보기 진입·시작 버튼 비활성화·관리 화면 복귀를 확인하고 기존 9개 가공 흐름을 함께 재확인합니다. 전체 Go·Linux/Windows vet·Windows GUI 교차 빌드 및 소스 ZIP 재빌드 일치를 확인합니다. 실물 Windows/Android 실행은 하지 않았습니다.
