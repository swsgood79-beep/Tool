# PC 1.4.116

대표 관리자 직접 실행형 가공 테스트 기록 초기화와 수주별 전체 거래처 미입고 조회를 추가했습니다. 실제 업무 기록 초기화를 실행하지 않았습니다.

초기화는 계정 고유 ID로 구분하고 미리보기 이후 변경을 거부합니다. 명시 확인 후 protect/unprotect 기반 로컬 백업을 저장하고 복호화 검증한 경우에만 journaled 상태 저장으로 반영합니다. Windows protect/unprotect는 기존 DPAPI입니다. 타 작업자의 후속 공정, 공유 작업자 기록, ERP 입고 확인 또는 원본 입고 수량이 있는 작업은 보류합니다. 수주, 필요 수량, 계정, 권한, 로그인, ERP 설정은 보존하며 초기화 대상/시각/실행자/백업 파일명을 이력에 보관합니다.

미입고 조회는 기존 ERP INI와 PowerShell SqlClient를 재사용합니다. 수주로 범위를 한정하며 거래처 및 BASE 필터를 적용하지 않습니다. 발주와 가공의뢰 복합 키로 로봇을 연결하고 행별 수주가 존재하면 헤더보다 우선합니다. 로봇 식별값이 하나로 확인되지 않으면 확인 불가로 표시합니다. 발주-입고 잔량은 소수를 보존합니다. SELECT 전용이며 결과 잘림/실패는 미입고 없음으로 표시하지 않습니다.

화면 검증은 합성 기록과 가상 ERP 응답을 사용하는 실제 Chromium 화면입니다. 모바일 320/360/390/430px 및 PC 1100px에서 로봇품번 전체 줄바꿈과 4열 표, 오류/새로고침, 초기화 미리보기/확인/이력을 검증합니다. 회사 내부 DB 접속, Windows GUI/DPAPI 실기 및 실제 ERP 결과 대조는 이 클라우드에서 검증하지 못했습니다. 현장 대조가 필요합니다. APK 1.0.11 유지.
