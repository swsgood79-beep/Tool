# PC v1.4.83 · 출하 기록 엑셀

관리자 전체 보관 ZIP과 수주 하나의 독립 XLSX를 지원합니다. 필터와 독립적으로 보관 완료만 스냅샷하고 계정/CSRF/구매 역할 제한을 검사합니다. 상태·다운로드는 작성 계정에만 허용합니다. 생성은 작업 잠금 밖에서 수행하고 원본 사진을 참조 수로 보존합니다. 완료 후 참조를 해제하고 미참조 파일만 정리합니다. 다운로드는 열린 파일/Reader 수를 유지하며 ServeContent를 잠금 밖에서 실행합니다. 서버의 일반 응답 제한과 별도로 긴 다운로드의 WriteDeadline을 설정합니다. 완료 작업 최대 3개·2시간 만료이며 활성 다운로드는 제거하지 않습니다.

월별 파일은 보관일 KST 기준, 40건/약 24MiB 사진을 기준으로 분할합니다. 전체 목록의 외부 파일 관계와 시트 location을 명시하고 파일들이 ZIP 안에 실제로 존재하는지 검사합니다. 단일 파일은 내부 링크만 사용하며 다른 수주를 포함하지 않습니다. 원본 값은 문자열 셀로 기록하여 수주번호·메모·파일명의 수식 실행을 방지하고 날짜는 KST 벽시계 값으로 저장합니다.

사진은 40MP 이하 유효 이미지만 읽고 960px/대체로 220KiB의 JPEG 미리보기로 넣습니다. 해독/이미지 오류는 자리 안내와 확인 시트로 남기고 조용히 누락하지 않습니다. 파일/영상 원본은 사용자가 별도 전달하기로 선택했으므로 삽입/패키징하지 않고 이름·종류·용량만 표시합니다. 해당 원본과 사진 원본, 보관 날짜 및 기록은 변경하지 않습니다.

실제 사진 객체·KST 날짜·원본 불변·월/사진량 분할·상대 파일/시트 링크·문자열 수식 방지·누락 사진 표시·핀 해제·계정/CSRF·느린 다운로드 중 작업 조회를 Go/race로 검사합니다. Chromium PC/휴대폰 밝게/어둡게에서 실제 ZIP/XLSX 다운로드·오류 재시도·새로고침 중복 다운로드 방지·작업자 버튼 부재·나가기 경고 부재를 확인합니다. LibreOffice로 파일을 열고 가로 잘림 없이 A4 너비에 인쇄되는지 시각적으로 확인했습니다. Windows GUI 및 Microsoft Excel/실제 Android는 실행하지 않았습니다. 원래 web 57개 자산과 APK 1.0.11은 유지합니다.
