# PC v1.4.85 · 엑셀 고객사 수주명 규칙 / 상세 목차 링크 제거

사용자가 제공한 회사 수주명 규칙에 따라 내보내기 스냅샷에서 고객사를 숫자+축 앞의 이름으로 표시합니다. 공백을 포함한 고객사 이름을 보존하며 숫자+축 형식이 없는 수주는 기존 저장 고객사/검증된 원본 보완을 사용합니다. 기존 고객사 값이 있더라도 규칙에 맞는 수주명 표기를 엑셀에 우선 적용합니다. 변경은 내보내기 복사본에만 적용하고 저장한 보관 수주와 업체 원본에는 쓰지 않습니다. 출고 예정일과 검사/보관 날짜는 v1.4.84 기준을 유지합니다.

상세의 목차로/전체 목록 링크를 제거하고 제목 병합을 A1:L2로 확장했습니다. 전체 목록의 상세 링크, 월별/단일 파일의 하단 목차 시트는 유지합니다. 실제 단일·전체 엑셀의 고객사 C8, 상세 링크 없음, 제목 전체 폭, 원본 고객사 불변을 검사합니다. 합성 비엔에스 수주로 LibreOffice 열기와 PC/휴대폰 크기 Chromium 다운로드를 확인합니다. 실제 Windows GUI·Microsoft Excel·Android/회사 운영 자료는 실행/접근하지 않았습니다. APK 1.0.11/code12 및 기존 web 57개 자산을 유지합니다.
