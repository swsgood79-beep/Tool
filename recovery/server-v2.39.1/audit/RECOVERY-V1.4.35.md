# v1.4.35 — 작업자 오늘 납기에 완료 수주 포함

## 변경

작업자 작업 메뉴의 오늘 납기 건수와 목록에 검사 완료 수주를 포함합니다. 출고 예정일이 오늘이면 과거에 완료한 수주와 원본 이전 완료 상태도 포함하여 출고일정의 같은 날짜 목록과 일치합니다. 완료 수주는 기존 카드 디자인과 녹색 구분을 사용하며 새 검사 버튼을 추가하지 않습니다. 담당자 전화·사급품 엑셀 셀 색상·특이사항·작업자 정보를 유지합니다.

수정 범위는 worker-v1.4.35.js의 오늘 납기 필터, 작업자 전용 납기 요약 자산, 완료 카드 디자인 적용과 자산/표시 버전입니다. 관리자 납기 요약은 기존 due-view-v1.4.5.js를 그대로 사용합니다. 전체/세팅/출하/금일 검사 완료/다음 출고는 기존 기준입니다. 서버 저장 스키마, 검사 신청/승인/반려, 알림, 납기표 동기화, 출고일정 집계는 변경하지 않았습니다. 원본 web/ 57개 자산도 그대로입니다.

자동 갱신 후 검사 완료된 수주도 오늘 납기에 남고, 출고일이 바뀌거나 기존 일정 동기화에 의해 출고일이 제거되면 오늘 납기에서 제외됩니다. 숨긴 수주·날짜 미정·다른 날의 완료 수주는 오늘 납기에 나타나지 않습니다.

## 검증

- 실제 Go 초기 화면/폴링 카드/상태 응답, 실제 통합검사 승인, 출고일 제거/변경으로 만든 합성 테스트 자료 사용. 회사 자료는 사용하지 않았습니다.
- 오늘 납기 Chromium 12조합: 새/기존 화면 × 밝게/어둡게 × 320/390/1100px. 달력과 ID/건수 일치, 과거 및 이전 완료 포함, 녹색, 전화 링크, 승인 후 유지, 납기 변경 시 제외, 다른 필터 유지, 검색, 화면 전환 복원을 확인했습니다.
- 승인 카드 디자인 Chromium 12조합: 관리자/작업자 × 밝게/어둡게 × 320/390/1100px. 사급품 원본 색상, 전화 링크, 기존 관리자 컨트롤, 캘린더 동작과 승인 후 갱신을 확인했습니다.
- 전체 Go race 테스트, Linux/Windows go vet, Windows amd64 GUI 교차 빌드와 ZIP 무결성, 소스 ZIP에서 실행 파일 동일 재빌드 검증.
- 원본 자산 57개 SHA-256 일치. 실제 Windows GUI/휴대폰 전화 앱 실행은 이 Linux 환경에서 확인하지 않았습니다.

## 업데이트

회사 PC의 기존 프로그램을 트레이에서 완전히 종료한 뒤 새 ZIP을 풀어 AlphaWorkComplete-Recovered.exe를 실행하세요. 작업자 휴대폰/관리자 브라우저를 새로고침하세요. 기존 자료와 설정은 그대로 사용하며 일반 업데이트에서 테스트 승격 스크립트를 실행할 필요가 없습니다.

전체 소스·실행 ZIP·소스 ZIP·검증 기록을 GitHub recovery-v2.39.1 브랜치에 추가하고 이전 배포 파일은 보존합니다.
