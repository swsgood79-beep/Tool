# PC 1.4.119

사용자 승인 배치대로 일반 작업자·관리자의 기본 수주카드에서 검사 화면 열기 왼쪽에 미입고 버튼을 배치했습니다. 팝업은 기본 카드에서 직접 열립니다. 가공팀 화면의 미입고 버튼을 제거했습니다. 관리자 기존 수정/펼치기 조작은 겹침 방지를 위해 버튼 행 바로 윗줄에 둡니다.

기존 작업자 보드 인증과 활성 수주 ID로 범위를 제한하고 한 번에 최대 10개 수주를 SQL 매개변수로 조회합니다. 조회는 백그라운드에서 실행하고 메모리에서 1분간 재사용하며 팝업 새로고침은 결과를 만료시켜 다시 조회합니다. 정상 조회 0건만 버튼을 숨깁니다. 실패/잘림/잘못된 수주 연결은 빈 결과로 취급하지 않습니다. 보드/DB 설정 변경 시 진행 중인 이전 결과를 폐기합니다.

결과는 App 메모리만 사용하며 State/Project/출하기록/엑셀/백업에 저장하지 않습니다. 조회 전후 State/CSV/엑셀 시트 일치 및 출하 스냅샷에 ERP 품목이 없는 것을 검증합니다. 기존 검사/구매팀 호출/계정/권한/자료/DB 설정은 보존합니다. 기존 PowerShell 표준입력 실행 방식을 사용합니다.

실제 Chromium에서 작업자/관리자, 320/360/390/430/1100px, 밝은/어두운 테마, 기존 APK 사용자 에이전트, 구형 디자인 및 갱신 후 카드 재생성 등 23개 사례를 합성 자료로 검증합니다. 캡처는 실제 구현 화면의 가상 자료입니다. 사용자 실제 카드 이미지/회사 ERP 자료를 공개 저장소에 포함하지 않습니다. 실제 회사 ERP 결과 및 Windows/Android 실기는 현장 확인이 필요합니다. APK v1.0.11 유지.
