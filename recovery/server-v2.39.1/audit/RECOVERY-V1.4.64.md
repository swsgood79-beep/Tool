# v1.4.64 · 관리자 Android 앱

관리자 전용 Android APK 1.0.0과 서버 FCM 연결을 추가합니다. 기존 관리자/개인 관리자 인증과 권한, 수주·출하·토크·작업자 PWA는 유지합니다. 원본 web 자산 57개는 변경하지 않습니다.

앱 전용 지속 로그인은 비밀번호 없이 별도 비밀값으로 세션을 복원하며, 서버는 해시만 저장하고 Android는 Keystore AES-GCM으로 보관합니다. 앱 종료·같은 서명 업데이트·서버 재시작·새 tunnel 주소 후 복원합니다. 로그아웃·관리자의 연결 해제·계정 중지·비밀번호 변경 시 복원할 수 없습니다. 일반 브라우저 세션 8시간은 그대로이며 앱 쿠키는 복원을 돕는 365일 쿠키입니다. grant 자체는 수동 해제 전까지 유효합니다.

FCM 서비스 계정 JSON은 회사 PC의 기존 보호 상태 저장소에만 저장하며 APK·공개 소스·bootstrap에 노출하지 않습니다. 업로드는 기존 관리자만 가능합니다. 개인 계정은 자기 앱 연결과 테스트만 사용합니다. 푸시는 별도 5초 펌프, 실패 재시도, 검사 통합 신청 중복 방지, 기기별 수신 위치를 사용합니다. 기존 브라우저/공용 PC 알림 설정은 변경하지 않습니다.

검증: Go 전체 테스트, 신규 인증·푸시 단위 테스트와 race, Linux/Windows vet, Windows GUI 교차 빌드, Android release 빌드/JUnit/Lint/서명. SDK 35, min26, target35. Android Lint는 UI에 필요한 JavaScript와 한국어 고정 문자열에 대한 경고 2개, 오류 0개입니다.

실제 Windows GUI·회사 자료·Firebase 서비스·실제 Android 설치/잠금 수신은 시험하지 않았습니다. Firebase 프로젝트가 아직 없어 사용자 초기 연결이 필요합니다. 설치/최초 연결은 ANDROID-ADMIN-SETUP.md를 따릅니다. APK 자동 설치 기능은 없으며 native 기능 변경 시 같은 서명 APK를 설치합니다. 서버 UI는 회사 PC 업데이트를 따릅니다.
