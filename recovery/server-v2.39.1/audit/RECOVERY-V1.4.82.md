# PC v1.4.82 · 출하 파일/영상

동일 출하 스냅샷에 첨부 메타데이터를 확장하며 기존 프로젝트·사진 스키마는 유지합니다. 바이너리는 4MB 단위로 기존 사진 보호 저장소에 별도 ID로 저장합니다. 각 조각의 크기·SHA-256을 검증하고 Range ReadSeeker는 요청 조각만 복호화하며 파일 I/O 중 App.mu를 잡지 않습니다. 업로드는 별도 임시 디렉터리·전송 잠금으로 분리하고, 완료 시에만 짧은 메타데이터 트랜잭션을 수행합니다. 인증·역할·CSRF는 본문 수신 전에 확인하고 완료 시 재확인합니다. 멱등 조각/완료 재시도, 2시간 임시 보관, 수주당 20개/1GB와 파일별 한도, 취소·삭제·참조 기반 정리를 적용합니다.

동영상은 브라우저의 Canvas/MediaRecorder/Web Audio로 가로·세로와 소리를 유지하여 자동 압축합니다. 작은 파일/압축이 더 큰 파일은 원본을 사용합니다. WebM Duration은 포함된 MIT fix-webm-duration 1.0.6으로 보완합니다. 원본 휴대폰 파일은 변경하지 않습니다. 지원하지 않는 입력·백그라운드 중단은 오류로 처리하며 완료 안 된 영상이 성공으로 표시되지 않습니다.

검사 완료 후 사진 필요 화면에서 첨부만 올릴 수 있으며 사진 등록 의무는 유지됩니다. 보관 후 추가는 최초 보관 날짜와 사진을 바꾸지 않습니다. 사진 재등록 시 첨부를 유지하고 검사 취소/기록 전체 삭제 시 참조되지 않는 조각을 정리합니다. 백업·복원·전체 자료 복사에 조각을 포함하고 기존 256MB 원격 백업 한도 초과는 명확히 실패합니다.

테스트는 실제 조각/재시도·범위 경계·재시작·백업/복원·권한·삭제·느린 전송 중 작업 화면 응답, Chromium 밝게/어둡게 PC/휴대폰 화면에서 20MB 초과 세로 MP4의 운영 압축 기준·재생·다운로드와 PCM 음성 레벨을 포함합니다. 원래 web 57개 자산·APK 1.0.11과 업데이트 manifest는 그대로입니다. Windows GUI 및 실제 Android 설치/카메라/코덱은 실행하지 않았습니다.
