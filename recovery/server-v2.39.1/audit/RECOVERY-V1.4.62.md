# v1.4.62 출하 기록 사진 연속 확대 보기

보관된 출하사진의 기존 새 탭 원본 링크를 개선해 같은 페이지의 전체 화면 dialog에서 사진을 이어 볼 수 있게 합니다. 좌우 스와이프·이전/다음·방향키를 지원하고 현재 순서/전체 개수를 표시합니다. 확대/축소 버튼·두 손가락 확대·확대 중 한 손가락/마우스 이동·더블클릭을 지원하며 확대 중 이동을 다음 사진 스와이프로 오인하지 않습니다. 처음/마지막 사진에서는 해당 방향 버튼이 비활성화되고 다른 수주나 특이사항 사진 그룹으로 넘어가지 않습니다. 사진 저장 링크와 JS/브라우저 미지원 시 기존 원본 링크는 유지합니다. Escape/닫기를 지원하고 닫은 뒤 선택한 썸네일로 초점·스크롤을 되돌립니다. 관리자·작업자 및 설치 앱이 사용하는 동일 페이지에 적용하며 서버 데이터/사진 순서/30장 제한은 변경하지 않습니다.

검증: 실제 임시 Go 서버에서 관리자/작업자 × PC/휴대폰 × 밝게/어둡게로 이미지 클릭·버튼·방향키·Chrome touch 이벤트 스와이프/핀치/확대 이동·그룹 분리·저장 URL·닫기 및 재열기를 확인합니다. 전체 Go 시험, Linux/Windows vet, Windows 교차 빌드 및 소스 ZIP 동일 실행 파일 재빌드를 포함합니다. 실제 Android/iPhone 기기 및 Windows GUI는 실행하지 않았습니다. 변경하지 않은 설치 앱 정적 파일과 다른 업무 브라우저 시험은 이전 버전을 명시해 참조합니다.
