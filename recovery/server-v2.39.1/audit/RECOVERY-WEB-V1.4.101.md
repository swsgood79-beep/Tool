# 작업자 설치 웹 v1.4.101

작업자 **앱 설치 버튼이 반응하지 않던 문제**를 수정했습니다. 네이버에서 Chrome으로 브라우저를 바꾸어 작업장 연결 정보가 없어진 경우에도 설치 안내는 항상 열립니다. 연결된 설치 주소를 복사하거나 Android에서 Chrome으로 여는 기능을 추가하고 일반 브라우저 주소의 작업장 키를 유지합니다. 브라우저가 설치 창을 제공하면 사용하고, 제공하지 않거나 취소·실패하면 메뉴로 설치하는 방법을 표시합니다. 작업자 설치 페이지를 다시 열거나 새로고침하면 적용되며 **회사 PC v1.4.100과 관리자 APK v1.0.11은 그대로 사용합니다.**

원인: 기존 app.js가 연결 키가 없을 때 beforeinstallprompt/click/닫기 리스너 등록 전에 return했습니다. 브라우저간 localStorage는 공유되지 않고 일반 브라우저 URL에서도 키를 제거해 복사 주소에서 연결이 빠질 수 있었습니다. 원본 localhost 재현은 heading=처음 한 번 작업장 연결이 필요합니다, installDialogOpen=false였습니다.

install.js를 독립 defer 스크립트로 먼저 로드해 연결 코드의 조기 종료·실패와 무관하게 안내를 제공합니다. Chrome handoff/주소 복사는 검증된 43자 Board만 fragment로 포함하며 사용자별 owner/reader 키와 토큰은 옮기지 않습니다. 일반 브라우저는 #k를 유지하고 standalone 주소는 기존처럼 키 없는 시작 주소를 사용합니다. prompt 취소/실패와 구형 dialog/클립보드 실패에 대체 UI를 제공합니다. cache101은 11개 쉘 파일만 저장합니다. 기존 연결·미저장 업로드의 업데이트 보류·테마 로직과 PC/Android 코드는 유지합니다. 현재 웹 소스는 worker-pwa-v1.4.101/, 기존 web/extras 원본은 변경하지 않습니다.

로컬 Chromium 실제 서버로 키 없음/키 유지·복사·다시열기/합성 설치 승인·취소·실패/네이버 UA와 Chrome URI/클립보드 거부/연결 script 실패/구형 dialog/실제 SW 설치·오프라인·63→101 캐시 전환을 확인합니다. Android OS 설치 창·외부 앱 실행 및 회사 데이터는 실제 실행하지 않습니다. gh-pages app/에만 배포해 다른 QR/관리자 페이지를 보존합니다. PC100 Windows ZIP과 APK11 해시를 유지하고 새 전체 소스 ZIP을 PC100과 재빌드 비교합니다.
