# v1.4.43 사급품 수령 내역 표시

‘사급품 수령’ 상태의 버튼을 누르면 납기표의 ‘사급품 수령 내역’ 시트에서 수주번호가 일치하는 모든 행을 원래 순서대로 읽어 종류·제조사·품번·수량을 표시합니다. 시트 이름의 공백과 머리글의 공백·줄바꿈은 허용합니다. 수주번호는 앞뒤 공백만 제거하여 정확히 비교하며 다른 수주의 자료를 섞지 않습니다. 수주번호 셀은 명시적인 Excel 병합 범위만 확장하고 일반 빈 행을 앞 수주로 간주하지 않습니다. 동일 품목의 여러 수령 행은 임의 합산·중복 제거하지 않습니다. 수량은 원본 표시 문자열을 유지합니다.

## 표시와 갱신

- 관리자·작업자 카드, 완료 카드, 출고일정, 특이사항의 기존 사급품 버튼에 공통 적용합니다. 다른 사급품 상태는 기존 문구 안내를 유지합니다. 엑셀 원본 버튼 색상과 전화·검사 업무는 그대로입니다.
- 제목과 닫기·하단 안내를 유지하고 표 내부만 세로 스크롤합니다. 열 제목도 스크롤 상단에 고정합니다. 모바일 320px부터 표가 창 바깥으로 나가지 않도록 줄바꿈하며 앱의 밝은/어두운 테마를 따릅니다.
- 기존 납기표 조회 시 같은 다운로드 데이터에서 함께 읽습니다. 자동 조회 활성 시 기존 5분 주기를 사용하고 별도의 파일 다운로드 타이머를 추가하지 않습니다. 열린 상세창은 15초마다 서버에 저장된 내역을 확인합니다. 창을 닫으면 해당 조회를 중단합니다.
- 수령 내역 변경·삭제는 다음 성공 조회에 반영합니다. 납기표 다운로드 자체 실패는 기존 정상 자료를 유지합니다. 시트 없음·열 구조 오류는 상세에 안내하고 불확실한 이전 내역을 표시하지 않습니다. 사급 상세 오류가 기존 납기·색상 갱신을 막지 않습니다.
- 자료는 기존 운영 저장 폴더의 _RecoveredV1 확장 State에 선택적 필드로 보관하고 재실행 후 유지합니다. 기존 D드라이브 설정을 사용합니다. 조회한 납기표 원본은 수정하지 않습니다. 현재 프로그램 수주와 연결된 내역만 보관하며 상세 API는 기존 비공개 작업장 키와 현재 숨김이 아닌 수주번호를 확인합니다.
- 설치 후 첫 납기표 조회까지는 조회 대기를 안내합니다. 자동 조회 설정·파일 경로·연결 URL 자체는 바꾸지 않습니다.

## 검증

- 전체 Go race 시험 및 Linux/Windows go vet 통과. 별도 사급품 race 시험으로 다음 자동 조회 시 수량 수정·행 삭제 반영을 검증했습니다.
- 업로드된 납기표를 프로덕션 파서로 읽기 전용 검증하여 앞서 확인한 Panasonic 모터 2행과 수량 2/1 일치를 확인했습니다. 실제 회사 PC 또는 최신 원격 파일에는 접속하지 않았습니다. 원본 회사 엑셀은 소스나 배포 ZIP에 포함하지 않습니다.
- 실제 Go 렌더링 화면 + Chromium에서 관리자/작업자/양쪽 특이사항 × 320/390/1100px × 밝은/어두운 테마 총 24개 조합을 검증했습니다. 2행·35행·열 제목 고정·내부 스크롤·빈 자료·통신 오류·ESC·기존 상태 안내·출고일정 복귀를 확인했습니다. 브라우저의 자료 응답은 합성 자료이며 회사 서버 쓰기를 하지 않았습니다.
- 기존 수주카드 브라우저 회귀 시험 12개 조합으로 엑셀 색상, 담당자 전화, 검사 진입, 완료 녹색, 갱신과 일정 복귀를 확인했습니다.
- Windows amd64 GUI 교차 빌드이며 Windows 실기기 실행은 검증하지 않았습니다. 원본 web 자산 57개 해시, ZIP 무결성 및 소스에서 Windows 실행파일 재빌드 일치를 검증합니다. 이전 배포본은 보존합니다.
