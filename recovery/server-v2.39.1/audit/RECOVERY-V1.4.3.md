# v1.4.3 중복 수주 조회

중복 방지 정책은 유지한다. 기존 수주를 덮어쓰거나 자동 삭제하지 않는다. 완료/숨김 등으로 목록에서 찾기 어려운 기존 수주를 오류 페이지에서 확인한다. 프로젝트명/번호/상태/출하 완료일과 검사/수정/삭제 확인 링크를 제공한다. 조회 GET /projects/find?number= 은 기존 관리자 인증 경계 안에 있고 번호 대소문자를 구분하지 않는다. 없는 번호는404. 등록 충돌은409 HTML이다. 이름은 html/template으로 이스케이프한다. 삭제 링크는 확인 GET만 열며 실제 삭제는 기존 CSRF/POST 확인을 유지한다.

duplicate_order_test.go: 완료/숨김 충돌 설명, 대소문자 일치, 기존 자료 불변, 이스케이프, 직접 조회, 없는 번호, 관리자 인증 확인. 원격 사용자 회사 자료는 확인하지 않았으므로 test가 실제 어떤 상태인지는 이 개발 환경에서 확정하지 않는다. 기존 브라우저/실기기 제한은 이전 보고서를 따른다.
