# v1.4.63 설치 앱 화면 밝기 동기화

기존 앱 외곽 CSS는 기기 다크모드만 따르고 작업 화면의 수동 테마와 연동되지 않았습니다. 설치 앱의 밝게/어둡게/기기 설정을 고정 앱 출처에 저장하고, 신뢰된 부모-자식 메시지로 작업 화면과 동기화합니다. 앱 설정이 아직 없으면 기존 작업 화면의 유효 테마를 먼저 가져와 명시적 선택을 덮어쓰지 않습니다. ‘밝게’는 앱·작업 화면에 color-scheme:only light를 지정해 지원하는 브라우저의 자동 어둡게 변환에서 제외합니다. 실제 삼성 인터넷의 강제 야간 모드/OS 필터는 물리 기기에서 확인하지 않았습니다.

서버가 검증한 system/light/dark 값을 HTTPS Secure SameSite=None Partitioned 테마 쿠키에 저장합니다. 테마는 비밀 값이 아니므로 첫 화면용 스크립트가 읽을 수 있게 HttpOnly를 사용하지 않습니다. 초기 앱과 작업 화면 모두 blocking 테마 초기화 스크립트로 CSS 첫 표시 전에 명시적 밝기를 반영합니다. 이후 UI 스크립트도 이 값을 우선하며 페이지 이동·재실행·접속 주소 변경 후 설정이 유지됩니다. 기존 작성자·읽음 capability 쿠키와 인증·사진·검사·저장 프로세스는 변경하지 않습니다.

고정 Pages app/의 자산 버전과 서비스워커 캐시를1.4.63으로 올립니다. 초기 테마 스크립트가 추가되어 캐시는 앱 껍데기10개 정적 자산만 저장합니다. 기존 안전한 업데이트 보류/활성화와 이전 앱 클라이언트 호환은 유지합니다.

검증: 실제 임시 Go 서버를 HTTPS 시험 프록시로 연결한 Chromium에서 PC/휴대폰 × 기기 밝게/어둡게의24개 테마 항목을 확인합니다. 버튼을 누른 직후 앱과 작업 화면의 실제 배경색·only-light 선언, UI 스크립트를 지연시킨 첫 표시, 앱 재실행, 터널 주소 변경, 명시적 어둡게 및 기기 설정 복귀를 확인합니다. 앱 내 사진·토크 저장과 저장 중 서버/앱 업데이트 보류12개, 실제 서비스워커 설치·캐시·오프라인3개를 현재 자산으로 회귀 검증합니다. 전체 Go 시험·Linux/Windows vet·Windows 교차 빌드·소스 ZIP 동일 EXE 재빌드를 포함합니다. Android 시스템 설치·강제 야간 모드·Windows GUI 실행은 이 환경에서 확인하지 못했습니다. Pages 직접 접속은 환경 프록시403으로 차단되어 공개 raw 파일과 게시 브랜치를 비교합니다.
