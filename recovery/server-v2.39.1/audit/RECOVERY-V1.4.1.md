# v1.4.1 EXE 통합 실행

Windows GUI 실행 파일 하나로 시작한다. v1.4 운영 선택 정보가 있으면 그대로 재개한다. 기존 운영 데이터/원본을 재복사하지 않는다. 운영 자료가 없는 최초 GUI 실행에서만 예/아니요/취소 대화상자로 원본 또는 테스트 업무 자료를 명시 선택한다. 테스트 자료가 없으면 아니요는 취소한다. 원본이 없는 새 PC는 예를 눌러야 빈 백업 복원용 자료를 만든다. headless/명시 CLI는 기존 동작을 유지한다. 이전 CMD는 소스에 호환용으로 보존하나 Windows ZIP은 EXE와 안내문만 제공한다.

first_start_test.go는 원본 선택/없는 테스트 선택 거부/테스트 선택/취소/빈 자료 명시 선택/원본 불변을 확인한다. 기존 운영 자동 재개는 production_test.go에서 검증한다. 이전 v1.4 브라우저 보고서는 당시 검증이며 이번 Windows MessageBox를 실기기에서 검증한 결과가 아니다. Windows는 GUI cross-build와 vet만 확인했다.

엑셀 설정 페이지에 파일 선택/연결/다운로드 순서와 자동 저장 파일명을 추가했다. 원본 엑셀 자동 수정 기능을 추가한 것은 아니다. 인터넷 연결은 기존 자동 연결 동작을 유지한다. 설정이 있으면 터널을 시작하고 외부 준비 검증 뒤 포인터를 게시한다. 이 개발 환경에서는 실제 포인터/푸시/회사 데이터에 쓰지 않았다.

연결 표시는 창 우측 상단의 작은 상태로 제공한다. 실제 터널 확인과 고정 포인터 게시 성공 상태일 때만 녹색, 나머지는 빨간색이다. 저장된 URL만 있어도 녹색으로 오인하지 않도록 테스트했다. 연결 상세 문구는 계속 표시한다. Cloudflare 및 브라우저 호출 자식 프로세스는 Start 전에 HideWindow와 CREATE_NO_WINDOW를 적용한다. Windows 전용 테스트는 빌드만 했으며 실제 창 미표시는 사용자 PC 확인이 필요하다.
