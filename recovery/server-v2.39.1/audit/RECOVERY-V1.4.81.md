# PC v1.4.81 · 업체 연결 수주 사진 추가 수정

## 문제와 결과

수주 수정 saveProject가 len(c.Photos)로 업체 원본의 모든 사진을 합산했지만, 화면과 기존 자료 저장은 ClientPhotoIDs로 선택한 일부만 사용했습니다. 원본 5장 중 3장 선택 + 수주 사진 1장으로 총 4장인 저장도 6장으로 검사해 막았습니다. selectedClientPhotos를 공통 사용하여 저장 제한·표시·기존 자료 투영의 사진 선택을 일치시켰습니다. 유효한 선택은 순서를 유지하고 같은 ID를 중복 합산하지 않습니다.

## 검증

실제 multipart 업로드, 업체 원본 보존, 기존 3장과 새 1장 저장, 원래 자료 형식 총 4장, 서버 재시작 후 4장 유지, 합계 5장 허용·초과 거부와 변경 롤백을 검사합니다. 임시 Go 서버 + PC/휴대폰 크기 Chromium의 밝게/어둡게 화면에서 저장·재진입·작업자 조회·나가기 확인 부재를 확인합니다. 원본 web 57개 파일은 변경하지 않고 렌더링 시 안내만 보완합니다.

실제 회사 MOT 자료, Windows 실행과 실제 Android 기기는 접근하지 않았습니다. APK 1.0.11·푸시 전송과 로그인 코드는 변경하지 않습니다. 알림 수신 지연 해결이나 엑셀 내보내기 배포를 뜻하지 않습니다.
