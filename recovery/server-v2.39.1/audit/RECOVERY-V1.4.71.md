# v1.4.71 · 관리자 앱 직접 인증 후 접속

사용자가 ‘지문·비밀번호로 접속’을 선택했습니다. APK 1.0.6 / versionCode 7에서 v1.0.5의 자동 접속을 제거합니다. 앱 시작은 기존 로그인 화면이며 onResume·주기 ticker·인증 오류에서 저장 계정을 자동 복원하는 경로를 삭제했습니다. restoreAfterBiometric은 사용자가 지문 버튼을 누르고 OS 인증에 성공한 콜백에서만 호출합니다. 비밀번호 로그인과 지문 버튼은 그대로 유지합니다. 자동 지문창은 없습니다.

일반 onStop에서 업무 화면을 잠그고 AuthEpoch를 갱신하여 앞선 비동기 인증/푸시 결과가 복귀 후 자동으로 열지 못하게 합니다. 사진/파일 선택 중에는 해당 작업 화면을 보존합니다. 서버 로그인 grant·암호화 secret·푸시 연결은 백그라운드 진입만으로 지우지 않습니다. 따라서 사용자는 매번 비밀번호를 입력하지 않고 직접 지문 버튼을 사용할 수 있습니다. 명시적 로그아웃은 해당 휴대폰 저장 연결과 푸시를 해제하며, 계정/기기 해제·비밀번호 변경에 대한 서버 검증은 유지합니다.

APK는 기존 서명과 알림 채널을 유지합니다. PC 관리자 화면과 v1.4.70 지수 등락률 수정은 유지합니다. 전체 Go 테스트, 서버 로그인/로그아웃 경계 race, Linux/Windows vet, Windows GUI 교차 빌드, Android 서명 릴리스·JUnit 19개·lint·동일 서명/버전 검사, 원본 web 자산 57개 해시·전체 소스 ZIP 동일 Windows 재빌드·공개 다운로드 SHA-256을 확인합니다. 지수 관련 테스트는 변경하지 않은 v1.4.70 이력과 현재 전체 테스트에 포함합니다.

제한: 실제 Android 화면 전환·지문·설치·FCM 수신과 Windows 실행은 이 환경에서 확인하지 않았습니다. 회사 운영자료·자격증명·Firebase 설정에 접속하거나 변경하지 않습니다. 비밀키/서명 자료는 공개 소스에 포함하지 않습니다.
