# v1.4.10 사급품 첫 행·첫 줄 및 셀 색상

사용자 정정에 따라 같은 수주번호 여러 행을 합치지 않고 처음 나오는 행 N셀만 사용한다. 그 셀의 첫 줄만 표시한다. 첫 행 또는 첫 줄이 빈 값이면 이후 행/줄로 대체하지 않는다. 기존 저장된 다중 줄도 화면에서는 첫 줄만 표시하고 원본 조회 성공 시 새 규칙으로 저장한다.

같은 N셀의 단색 채우기(RGB/index/theme+tint)와 실제 첨부 시트의 cellIs/equal 문자열 조건부 채우기를 반영한다. workbook 관계로 대상 XML을 찾고 조건부 서식 priority 순서와 StopIfTrue를 적용한다. 임의 수식 실행/평가는 하지 않으며 범용 조건부 서식 엔진은 아니다. 단색 채우기가 없으면 Excel 기본 흰색을 사용한다. 빈 내용은 버튼 없음. 첫 셀의 전체 값으로 조건을 판단한 뒤 표시 문구만 첫 줄로 제한한다. 병합 셀은 실제 원점에서 내용/스타일을 가져온다.

SuppliedMaterialsColor를 상태/정상 원본 필드/확장/백업/금일 완료 상태 JSON에 저장한다. 색만 변경돼도 revision과 변경 건수를 갱신한다. UI는 엄격한 #RRGGBB만 적용하고 배경 대비로 글자색을 고른다. 관리자/작업자/검사/특이사항 상세/금일 완료/미완료 캘린더 버튼에 적용한다. hover가 원본 배경색을 덮지 않게 inline 안전 색상만 지정한다.

material_color_test.go: 첫 행/첫 줄/첫 빈칸/직접 채우기/테마+tint/조건부 색/원본 전체 값 비교/색만 변경/저장 재실행/기존 필드 읽기/잘못된 CSS 거부. 실제 첨부 일정표는 읽기 전용 열 파싱 시험만 하며 파일/값은 배포에 포함하지 않는다. browser-supplied-materials-v1.4.10.json은 합성 자료로 1100/390px 관리자·작업자 배경색/첫 줄/독립 클릭/캘린더 변경을 검증한다. Windows 실기기·실제 OneDrive 다운로드는 여기서 검증하지 못했다.

원본 web57개와 이전 버전 ZIP/커밋은 보존한다. 새 소스 ZIP도 별도 폴더에서 재빌드하여 배포 EXE 해시 일치를 검증하며 기록은 server-builds의 해당 버전 source-rebuild.json에 남긴다. 실제 업무 자료 백업과 복구키는 코드 보관과 별개다.
