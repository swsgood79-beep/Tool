# v1.4.40 — 댓글 삭제 오른쪽 정렬·둥근 토크 아이콘

휴대폰 댓글 입력은 작성자 이름·댓글·등록 버튼의 3열 한 줄로 배치하고 높이는 40px로 맞추고 크기와 간격을 줄였습니다. 이름 입력 힌트도 짧게 표시합니다. 댓글 삭제 버튼은 댓글 아래의 같은 줄 오른쪽 끝으로 정렬했습니다. CSS의 .talk-comment>form에 flex/flex-end만 적용해 기존 댓글·작성자·시간·삭제 폼의 순서와 요청을 유지합니다. 토크 메뉴 아이콘은 둥근 말풍선 두 개의 SVG 경로로 교체했습니다. 읽지 않은 글 배지와 메뉴 주소/동작은 그대로입니다.

표현 자산은 talk-board-v1.4.40.css와 mobile-design-v1.4.40.js를 사용합니다. 서버의 게시판 저장·소유권·삭제/댓글/좋아요·읽음 상태 API·수주·일정·공지·D드라이브 경로 로직은 변경하지 않았습니다. 기존 검증용 게시판 화면 fixture에는 실제 삭제 버튼을 볼 수 있도록 댓글 예시 한 건을 추가했습니다.

검증: 기존 TestTalk 테스트와 TestMobileDesignPreviewPagesAndFragments 통과. Chromium 토크 회귀 12조합(새/기존 화면 × 밝게/어둡게 ×320/390/1100px) 통과. 실제 Go가 렌더링한 댓글에서 320/390/1100px 밝게/어둡게의 버튼 오른쪽 간격 0px 및 둥근 말풍선 SVG를 확인하고 캡처했습니다.
