# v1.4.39 — 토크 게시판과 안 읽은 글 배지

작업 공유의 표시 이름을 토크로 변경했습니다. 호환성을 위해 기존 /community 주소, 소유권 쿠키와 데이터 필드는 유지합니다. 게시글/사진/댓글/좋아요는 그대로입니다.

## 게시판 화면

전체·작업안내·건의사항·일상생활 목록은 작은 썸네일(사진이 없으면 문서 표시), 좋아요 수, 분류, 제목·댓글 수, 작성자·등록 시간으로 정렬합니다. 제목을 누르면 승인한 게시판형 상세로 이동합니다. 상세는 게시판 탭/제목/작성자·일시/본문·사진/좋아요/이전 글·목록·다음 글/댓글 순서이며, 현재 분류·검색·목록 페이지를 돌아가기 링크에 보존합니다. 이전/다음은 같은 분류/검색 결과 안에서 목록 정렬 순서대로 연결하며 끝에서는 비활성화합니다.

## 안 읽은 글

작업자 하단 토크 메뉴에 전체 분류의 안 읽은 글 수를 주황색 배지로 표시합니다. 목록 방문만으로는 읽음 처리하지 않고 상세 페이지가 열리면 해당 글 ID를 읽음으로 기억합니다. 본인 글은 서버의 기존 브라우저 소유권 기준으로 제외합니다. 새 글은 15초 간격 및 화면 복귀 때 확인하고 삭제된 글은 집계에서 빠집니다. 글 수정/댓글/좋아요는 같은 ID이므로 다시 안 읽음으로 만들지 않습니다. 0개일 때 배지를 숨기며 일시 조회 오류에는 마지막 정상 숫자를 유지합니다. 관리자 메뉴에는 배지를 추가하지 않습니다.

읽음 기록은 해당 접속 주소의 브라우저 localStorage에 board별로 저장합니다. 다른 휴대폰/브라우저의 기록과 섞이지 않고 같은 브라우저의 탭끼리는 storage 이벤트로 동기화합니다. 사이트 데이터 삭제·시크릿 창 종료·접속 도메인 변경 시 기록은 초기화될 수 있습니다. 새 기능 전의 과거 열람 내역은 없으므로 처음에는 기존 글도 미열람으로 집계할 수 있습니다. 계정별 읽음 확인/누가 읽었는지 관리자 추적은 추가하지 않습니다. 저장소를 막은 브라우저에서는 현재 페이지 메모리로만 동작할 수 있습니다.

상태 조회는 기존 board capability를 검증한 GET /community/{board}/status에서 글 ID와 본인 글 여부만 제공합니다. 소유권 해시나 글 본문을 노출하지 않고 Cache-Control: no-store를 사용합니다. 읽음 여부를 수주/검사 자료나 엑셀에 쓰지 않습니다. 원본 web/57개와 기존 D드라이브 경로 설정·복사 로직은 변경하지 않았습니다.

## 검증

- 실제 Go HTTP의 board 차단·본인 글 판별·소유권 정보 비노출·삭제 후 상태 제외와 게시판/분류·검색·페이지 복귀 링크를 검사했습니다. 기존 게시글 소유권/사진/백업/경로 이전 테스트도 유지합니다.
- 전체 Go race, Linux/Windows go vet, Windows amd64 GUI 빌드, 원본 자산 해시·ZIP 무결성·소스 ZIP에서 동일 실행 파일 재빌드.
- Chromium 48조합: 토크 목록/상세/읽음 12, 기존 카드 12, 오늘 납기 12, 공지 12. 새/기존 화면·밝게/어둡게·320/390/1100px를 사용했습니다. 독립 브라우저, 새로고침, 여러 탭 동기화, 새 글/삭제/본인 글 제외/오류 유지/0개 숨김과 기존 업무 액션을 확인했습니다.
- Windows 실기기/회사 휴대폰/회사 실자료는 이 Linux 환경에서 실행하지 않았습니다. Go 임시 저장소와 합성 페이지/상태로 검사했습니다.

## 업데이트

기존 프로그램을 트레이에서 종료하고 새 ZIP의 EXE를 실행한 뒤 작업자·관리자 브라우저를 새로고침하세요. 글을 다시 등록하거나 D드라이브 저장 위치를 다시 지정할 필요는 없습니다. 하단 토크 숫자는 전체 게시판 중 해당 브라우저의 안 읽은 글 수입니다.

전체 소스·실행 ZIP·소스 ZIP·검증 기록을 recovery-v2.39.1 브랜치에 보관하고 이전 버전을 유지합니다.
