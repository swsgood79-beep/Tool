# PC v1.4.86 · PC 내 자동 업데이트

Win32 창/트레이 메뉴에서 확인하고 실행 시/5분마다 고정 GitHub 메타데이터를 조회합니다. App.mu와 별도 잠금, 취소 가능한 백그라운드 다운로드를 사용하며 준비 완료 전에 서버를 종료하지 않습니다. ZIP 크기/해시와 EXE 해시/PE x64 GUI 검증 후 원래 EXE 폴더에 staging합니다. 경로가 정확히 일치하는 EXE 하나만 추출하므로 zip slip 경로를 쓰지 않습니다.

도우미는 현재 EXE의 별도 복사본을 --pc-update-helper로 실행합니다. 시작 시 flag.Parse/자료 열기 전에 도우미를 분기합니다. 계획/해시 및 부모 프로세스 실제 경로를 검사하고 readiness를 알립니다. UI가 정상 종료를 요청한 뒤 부모 프로세스 핸들 종료를 기다려 교체합니다. 새 프로세스에는 현재 자료 절대 경로/포트/-no-browser 및 내부 ready 경로만 전달하며 초기화 플래그는 전달하지 않습니다. 앱 시작 완료 시 ready를 기록합니다. 새 프로세스 종료 실패는 이전 EXE 복원/재실행으로 처리하고 살아 있는 프로세스는 timeout에 강제로 죽이지 않습니다. 최근 성공 백업 2개를 유지하고 알려진 파일만 정리합니다. 미완료/다른 대상/알 수 없는 파일에는 재귀 삭제를 사용하지 않습니다.

기존 web 57개 자산과 APK 1.0.11/code12, 수주/사진/설정 저장 코드는 유지합니다. 모의 배포 다운로드/실패·복원·취소·정리·원본 불변 및 race/전체 Go 검사와 Windows 빌드를 확인합니다. 실제 Windows 프로세스 교체/바이너리 잠금/GUI 버튼/백신 정책은 실행하지 않았습니다. 첫 v1.4.86은 수동 설치가 필요하며 이후 더 높은 버전 배포 JSON이 올라오면 PC 내에서 업데이트합니다.
