# v1.3 빠진 기능 추가

원본 소스/실행과 100% 동일한 버전이라는 뜻이 아니라, v1.2 대조표에서 실제 빠진 업무 기능을 추가한 격리 시험판이다. 기존 자료와 외부 운영 서비스의 분리는 유지한다.

| 항목 | v1.3 변경 |
|---|---|
| 수주 엑셀 일괄등록 | 실제 업로드/시트 선택/미리보기/행 선택/연결 수정/일괄 저장/결과 표시 구현. 원본 order-import.html/js 2개를 그대로 사용하고 서버 처리 연결 |
| 직급 없는 이름 매칭 | 공백/NFKC 정리 및 직급 접미어 제거 비교. 정확한 전체 이름 우선. 같은 이름이 여러 명이면 직접 선택 |
| 업체 특이사항 연결 | 업체명 일치 시 명단 ID로 연결. 글·사진 자동 반영, 수주별 메모는 별도. 없는/겹치는 업체는 선택 요구 |
| 중복·검증·재시도 | 기존/파일 내 중복 제외, 수식 거부, 한 시트 1,000건/10MB, 미리보기 소유 로그인/30분/nonce, 확정 재전송 중복 방지. 선택한 행은 한 트랜잭션으로 저장 |
| 작업자 업체 전체 조회 | /client-directory/{board}, /client-photo/{board}/{client}/{photo}. 수주에 연결하지 않은 업체도 검색/읽기/사진 확대. 수정/삭제 API 없음. 3초 갱신 |
| 기존 엑셀 사본 병합 | /report-settings, 5MB. 원본 업로드 사본 보관, 기존 수주/검사구분/완료일자/시간을 기준으로 행 연결. 기존 메모/수식/서식/추가 시트 보존, 새 기록 추가. 프로그램 값이 바뀐 항목만 갱신 |
| 검사 취소 시 병합 엑셀 | 연결된 행의 6개 검사 항목만 비우며 같은 행의 별도 메모는 유지. 연결되지 않은 기존 행은 보존 |
| 문 열림 효과 | 기본 작업자 첫 진입에 연결. sessionStorage로 같은 탭 반복을 피함. 실제 문서 요청 1회로 브라우저 시험. ?entry=gate 재생 / ?entry=skip 생략 |

## 구현 위치

- order_import.go: ImportDraft/ImportRow, 제목/담당자/업체 매칭, 원본 미리보기 템플릿과 모든 import 엔드포인트.
- inspection.go + extras/worker-client-directory*: 작업자 조회용 새 경로/화면/갱신.
- workbook_merge.go + extras/report-settings.html: 원본 파일을 건드리지 않는 사본 기반 엑셀 병합.
- State.WorkbookBase/WorkbookBindings: DPAPI 보호 상태 확장에 템플릿/연결 위치를 저장. 프로그램 재시작에도 유지되며 기존 암호화 portable 백업 상태에도 포함된다.
- main.go + extras/worker-entry-state.js: 원본 자산 57개를 수정하지 않고 버튼/추가 자산/첫 진입 재생 연결.

## 검증

missing_features_test.go는 매칭/동명이인·미리보기·부분 등록 방지·권한/CSRF/만료·중복 재전송·시트/수식/행 제한·업체 전체 조회/보드 키/사진/HTML 이스케이프·엑셀 메모/서식/수식/추가 시트/이름 변경/취소·재시작/오류 보존을 확인한다.

browser-missing-features-v1.3.cjs/json은 Chromium의 업로드 → 매칭/동명이인 선택 → 등록 → 작업자 목록/전체 업체 검색/사진/갱신 → 문 열림/문서 요청 1회 → 통합검사 신청/관리자 승인 → 기존 엑셀 사본 업로드/내려받기를 확인했다. 내려받은 ZIP/XML에서도 메모·수식·추가 시트·새 기록을 확인했다. 화면 사진은 import-preview-v1.3.png, worker-directory-v1.3.png.

모두 생성한 시험 파일로 확인했다. 회사 수주·사진·접속 키·첨부 원본 엑셀을 ZIP/GitHub에 포함하지 않았다. Windows EXE는 GUI 교차 빌드이며 Windows 실기기/회사 DPAPI 자료 실행은 여전히 미검증이다.

## 유지한 제한

- 외부 접속·운영 QR 포인터·휴대폰 푸시/관리자·고정 Pages 패스키·시세/OneDrive·원격 백업은 격리 때문에 차단한다. 이 버전에서 운영 주소나 운영 계정 서비스를 바꾸지 않는다.
- 원본 Documents 엑셀을 직접 덮어쓰거나 외부 Excel에서 수정한 내용을 자동 양방향 동기화하지 않는다. 업로드 사본에만 병합한다. 기존 파일의 고급 Excel 기능 전체를 바이트 단위로 보존한다고 보장하지 않는다.
- 원본 Windows 픽셀/소리/애니메이션 동등성, ngrok 실행, 원본과 동일한 사진 자동 청소와 대용량 백업은 별도 차이로 남는다. 기존 파일을 임의로 삭제하는 정리는 추가하지 않았다.
- 일괄등록 미리보기는 메모리 상태이므로 서버 재시작 시 다시 업로드해야 한다. 완료된 수주는 디스크에 저장된다.
