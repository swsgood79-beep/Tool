# v1.4.70 · 코스피·코스닥 등락률 기준 일치

기존에는 API changeRate/fluctuationRate/percent가 있으면 우선 사용했습니다. 지수를 분봉으로 교체한 경우 원래 응답의 등락률과 시점이 섞일 수 있었습니다. 또한 기준시각이 없을 때 조회 시각을 임의 기준으로 사용하고, 전일 종가와 현재 지수가 같으면 기준일을 이전 일자로 바꾸는 추정이 있었습니다.

이제 표시 지수와 해당 지수 한국 시간 기준일보다 앞선 최신 일봉 종가로 (지수 - 전일 종가) / 전일 종가 × 100을 계산합니다. API 등락률·basePrice를 그대로 채택하지 않습니다. 휴일·장 마감 후 과거 지수는 지수 자체의 기준일을 사용하며 UTC 일봉 시각도 한국 시간으로 변환합니다. 현재 일자의 일봉은 기준 종가로 쓰지 않고, 지수가 전일 종가와 같다는 이유로 기준일을 옮기지 않습니다. 기준시각 또는 전일 종가 확인에 실패하면 percent 필드를 내보내지 않아 기존 화면에서 —로 표시합니다. 가격은 유지하고 조회 상태에 기준 종가 확인 불가를 알립니다. 코인의 UTC 전일 종가 대비 signed_change_rate는 그대로입니다.

종가는 지수/한국 기준일별 기존 메모리 캐시를 사용하고, 운영자료 교체·시세 설정 변경 중 도착한 응답은 캐시에 기록하지 않습니다. 화면·원본 web 57개 자산·APK 1.0.5·로그인·알림은 변경하지 않습니다. 회사 PC 프로그램 v1.4.70을 설치/재시작하면 기존 웹앱은 새 계산 결과를 조회합니다.

검증: 수정 전 부호 반대/분봉 혼합/보합/종가 없음/기준시각 없음 회귀 사례의 실패를 재현했습니다. 수정 후 코스피·코스닥 모두 계산값과 —용 percent 생략을 확인하고, 휴일·UTC 한국 날짜·전일 동일 가격·당일 일봉 제외를 검증했습니다. Go 전체 테스트, 관련 race, Linux/Windows vet, Windows GUI 교차 빌드, 전체 소스 ZIP 체크섬/동일 Windows 재빌드, 공개 파일 SHA-256을 확인합니다. Android 검증과 APK는 변경하지 않은 v1.4.69 기록을 유지합니다.

제한: 회사 PC의 실제 토스 API 응답/토큰과 실시간 시장 데이터는 이 환경에서 확인하지 않았습니다. 테스트는 모의 API 응답으로 수행합니다. Windows 실행/실기기 브라우저는 실행하지 않았습니다. 회사 운영자료·자격증명은 변경하지 않으며 공개 소스에 포함하지 않습니다.
