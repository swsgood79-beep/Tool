# PC v1.4.97 · 벨트텐션 도구 / 토크 매뉴얼 일반 첨부

**전체 → 작업 도구 → 벨트텐션값 확인 프로그램**을 관리자·작업자 공용으로 추가했습니다. 첨부 HTML의 기준표·수식을 유지하고 CSP에 맞춰 CSS/JS를 분리했습니다. 단일 Hz·Polychain MIN/MAX와 AT5 계산 불가 표시를 원본대로 제공합니다. **토크 → 매뉴얼 게시판**에는 PDF·엑셀·한글·ZIP 같은 일반 파일을 제목·설명과 함께 등록/검색/다운로드할 수 있습니다. 파일은 한 개당 20MB, 글당 최대 5개이며 관리자와 작업자 모두 등록합니다. 작업자는 작성한 브라우저의 글을 삭제하고 관리자는 전체 글을 관리합니다. 파일은 회사 PC에서 암호화 저장하고 기존 암호화 백업을 사용할 때 함께 포함합니다. 전송 중에는 업무 잠금을 잡지 않습니다. PC v1.4.97로 업데이트하고 APK 1.0.11은 그대로 사용합니다.

원본 HTML은 docs/belt-tension-original.html로 보존하고 audit/belt-import-v1.4.97.json에 해시를 기록합니다. 기준표와 계산식은 그대로이며 제목/돌아가기/테마와 이벤트 바인딩만 통합합니다. 외부 제조사 매뉴얼의 정확성을 별도로 재검증한 것은 아닙니다.

매뉴얼은 별도 State.Manuals에 보관하여 기존 토크 사진/좋아요/댓글을 유지합니다. 관리자 경로는 세션·CSRF·모바일 권한, 작업자 경로는 board·브라우저 owner·CSRF를 확인합니다. 다운로드는 서버 메타데이터에 연결된 파일 ID만 사용하며 application/octet-stream·attachment·nosniff로 강제하고 조각/해시/용량을 검사합니다. multipart 읽기·4MiB 조각 암호화·다운로드는 App.mu 밖에서 처리하고 epoch/계정을 다시 확인해 atomic commit합니다. 재시도 키로 게시글 중복을 막고 실패 조각은 정리합니다. 다운로드 핀/공용 파일 정리는 삭제와 백업의 경합을 보호합니다. 업로드된 운영 파일을 공개 소스 저장소에 넣지 않습니다. 기존 암호화 v2/v3 백업의 참조 수집·복원 검증·빈 대상 확인에 매뉴얼을 포함합니다. 모바일 PWA iframe 출처는 기존 고정 worker-app 호스트에만 허용합니다. 구매 계정은 기존 호출 전용 권한을 유지합니다.

검증: 5MB 이상의 2조각 파일 등록/동일 키 재시도/원문 바이트 다운로드/출처·CSRF·다른 소유자 삭제 거부/관리자 삭제/재실행/암호화 백업 복원. Chromium 관리자·작업자 PC/모바일 밝게/어둡게 8뷰에서 전체 메뉴 링크·원본 DATA 전부 비교·Hz 계산·MIN/MAX·AT5·토크 매뉴얼 업로드/다운로드를 확인합니다. 전체 Go/race/Linux·Windows vet와 Windows 교차 빌드 및 소스 재빌드 일치. 실제 회사 자료/Windows·Android 기기는 실행하지 않았습니다. 원본 web57개와 APK1.0.11 그대로.

소스 ZIP은 코드·실행 자산·현재 검증 자료를 모두 포함하며 GitHub 크기 제한 때문에 v1.4.90~96의 과거 검증 PNG만 제외합니다. 해당 화면은 GitHub 원본 이력과 각 이전 소스 ZIP에 남아 있습니다.
