# v1.4.57 출고 일정 최초 화면 깜빡임 수정

v1.4.56은 진입 애니메이션만 생략했고 최초 HTML에는 탭 정보가 없어 deferred 디자인 스크립트 실행 전 작업 목록이 노출될 수 있었습니다. 이제 work 요청의 design-tab=calendar를 서버 뷰에 전달하고 현대 화면 렌더링에서 body data-design-tab=calendar와 초기 표시 CSS를 HTML에 포함합니다. 스타일은 탭 속성을 조건으로 하여 이후 작업 메뉴 전환을 막지 않습니다. 기존 캘린더 렌더링·출하 기록·검사·자료 저장 과정 및 최초 진입 화면은 유지합니다.

브라우저 검증은 디자인 스크립트 응답을 붙잡은 상태에서 두 번의 requestAnimationFrame 이후에도 작업 목록과 검색 도구가 숨겨져 있는지 확인하고, 응답 해제 후 캘린더를 확인합니다. 상단/하단/전체 메뉴 × PC/휴대폰 × 밝게/어둡게와 최초 시작 화면 유지 총28개를 검증합니다. 최종 화면만 확인하던 v1.4.56 시험과 달리 초기 화면을 검사합니다. 전체 Go 시험·Linux/Windows vet·Windows 교차 빌드·소스 ZIP 동일 실행 파일 재빌드를 포함하며, 다른 업무의 기존 브라우저 검증은 명시된 이전 버전을 참조합니다. 회사 자료 및 실제 Windows GUI 실행은 하지 않았습니다.
