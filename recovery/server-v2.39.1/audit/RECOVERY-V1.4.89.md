# PC v1.4.89 · 자동 인터넷 연결

main의 provider별 1회 시작 조건을 런타임 감독 루프로 바꿉니다. 활성/수동 중지/복원 보류/시작시각/재시도 시각/실패 횟수는 App 안에만 유지하며 저장 설정/QR은 변경하지 않습니다. 실행 시 초기화하여 업데이트 재시작도 자동 연결합니다. 실패는 5~60초 지연, 주기 5초이며 고정 QR 키 누락은 별도 안내합니다. 2분 준비 시간 초과는 기존 cancel을 호출하고 다음 기회에 시작합니다. 연결 성공 뒤에는 실패 횟수를 초기화합니다.

startTunnel은 감독 context를 사용하고 중지/복원/프로그램 종료 시 신규 프로세스를 시작하지 않습니다. 모든 종료 경로에서 cancel과 활성 포인터를 해제합니다. 검증/주소 게시 실패는 프로세스를 취소하고 원인과 자동 재시도 대기를 유지합니다. 수동 끊기와 수동 재개는 native/web 양쪽에 적용합니다. 새 PC 복원은 기존 터널을 먼저 드레인하고 integration runtime을 교체한 뒤 감독을 재개하여 이전 cleanup이 새 연결을 덮어쓰지 않게 합니다.

자동 시작·프로세스 실패 재시도·수동 중지 후 재실행·설정 누락/설정 추가·격리 모드·2분 timeout·실패 도구 활성 해제·복원 보류/드레인을 Go/race로 확인합니다. 기존 분할/단일 백업 복원 및 전체 Go 회귀, Linux/Windows vet, Windows GUI 교차 빌드를 수행합니다. 실제 Cloudflare 외부 연결·GitHub 주소 게시·Windows GUI 동작은 회사 환경에서 실행하지 않았습니다. 원래 web 57개와 APK 1.0.11 유지.
