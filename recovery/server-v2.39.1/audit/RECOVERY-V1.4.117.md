# PC 1.4.117

사용자 화면에서 미입고 품목은 조회되지만 모든 거래처가 확인 불가로 표시됐습니다. 기존 소스는 발주 헤더 거래처와 동일 사업장 마스터의 직접 조인에 의존합니다. 실제 회사 DB의 어떤 조건이 영향을 미쳤는지는 현장 대조 전입니다.

발주 행 CST_CD가 존재하고 비어 있지 않으면 헤더보다 우선합니다. 해당 수주의 미입고에 실제 사용된 코드만 별도 조회하고, 동일 사업장의 단일 이름을 먼저 사용합니다. 동일 사업장 이름이 없으면 같은 코드의 전체 후보 이름이 하나인 경우에만 공통 이름을 사용합니다. 이름 충돌과 코드 누락은 임의 추정하지 않습니다. 코드의 선행 0과 대소문자를 보존합니다. 마스터 조인을 분리하여 거래처 후보가 품목 행이나 수량을 늘리지 않습니다. 기존 INI/조회 전용 구조를 재사용하며 운영 기록을 수정하지 않습니다.

검증은 합성 코드/사업장/이름 12개 회귀 사례, 실제 ERP JSON 디코딩과 HTTP 응답, Chromium 320/360/390/430/1100px 실제 화면입니다. 실제 업무 자료와 사용자 화면 이미지는 공개 저장소에 추가하지 않습니다. 회사 ERP 결과, Windows GUI/DPAPI 및 실제 휴대폰 동작은 현장 확인 대상입니다. APK v1.0.11 유지.
