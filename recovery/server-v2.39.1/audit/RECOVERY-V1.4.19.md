# v1.4.19 — 검사 신청 전 특이사항 확인

작업 목록 또는 출고 캘린더에서 검사 화면을 열 때 특이사항이 있으면 확인 창을 먼저 표시합니다. 기존 업체 특이사항, 수주별 추가 메모, 선택된 첨부 사진을 같은 ProjectView에서 렌더링합니다. 체크박스를 선택하고 ‘확인하고 검사 화면 열기’를 누르면 기존 세팅·출하·통합 신청 및 비고 화면으로 진행합니다. 취소·Escape는 신청하지 않습니다. 매번 직접 열 때 확인하며, 신청 후 상태 갱신은 이미 열린 신청 화면을 유지합니다. 확인 중 카드 내용이 갱신되면 새 내용을 다시 확인합니다. 특이사항이 없는 수주는 바로 열립니다.

이 확인은 작업자 화면의 안내 절차입니다. 서버의 검사 신청 권한이나 관리자 완료 처리는 변경하지 않았으며, 별도 확인 이력이나 법적 증빙을 기록하는 기능은 아닙니다. 저장 형식·음성 엔진·반복 설정은 유지됩니다. 추출한 원본 57개 파일은 수정하지 않았고 새로운 extras 파일을 사용합니다.

검증: Go 전체 race 테스트, Linux/Windows vet, Windows GUI 교차 빌드. Go가 렌더링한 합성 자료로 Chromium PC(1100px)/모바일(390px)에서 글·메모·사진, 필수 체크, 취소/Escape, 캘린더 진입 이벤트, 재진입, 확인 도중 변경, 신청 후 갱신, 비고 보존, 빈 특이사항 직접 진입을 검증했습니다. 별도 업로드 납기표 경로가 필요한 선택 검사 1건(TestUploadedScheduleIfProvided)은 입력 경로 미지정으로 건너뛰었습니다. 실제 Windows 실행과 삼성 인터넷 실기기는 여기서 검증하지 않았습니다.

사용: 기존 EXE를 트레이의 종료로 완전히 종료한 뒤 새 EXE를 실행합니다. 열려 있는 작업자 브라우저는 새로고침합니다. 기존 운영 자료 폴더와 설정을 그대로 사용합니다.
