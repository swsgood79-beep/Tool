# v1.4.56 출하 기록 → 출고 일정 진입

출하 기록 상단 CalendarURL과 현대 화면 내부 작업/캘린더 메뉴 링크에 entry=skip을 명시합니다. 이 값은 서버의 기존 EntryGate 생략 분기를 사용하며 처음부터 시작 화면 HTML/스크립트를 싣지 않습니다. 캘린더는 기존 design-tab=calendar로 바로 엽니다. 새 화면 자산 URL은 mobile-design-v1.4.56.js입니다. 전체 문서를 가져오는 구조는 유지합니다. QR/고정주소 최초 진입, 인증·수주·검사·보관·사진 데이터는 변경하지 않습니다.

검증: 빈 sessionStorage의 새 브라우저에서 출하 기록 상단 탭/하단 출고 일정/전체 메뉴 출고 일정 각각을 누른 뒤 시작 화면 HTML 미포함과 캘린더 표시를 실제 PC/휴대폰·밝게/어둡게로 확인합니다. 기존 최초 접속의 시작 화면은 유지되는지도 확인합니다. 전체 Go 시험, Linux/Windows vet, Windows GUI 교차 빌드, 소스 ZIP 동일 실행 파일 재빌드 검증을 포함합니다. 변경하지 않은 계정·업무 브라우저 검증은 이전 버전 결과를 명시해 참조합니다. 실제 회사 PC/Windows GUI 실행은 하지 않았습니다.
