# v1.4.58 작업자 모든 메뉴 공용 PC 알람 수신

기존에는 work.html에만 공개 작업장 범위 음성/딩동 수신기가 포함되었습니다. 이제 출하 기록 목록/상세/사진 등록, 토크 목록/작성/상세/수정, 업체 특이사항, 수주 특이사항, 공지 목록/상세 등 작업자 전체 페이지에 동일 수신기를 적용합니다. 공지 화면처럼 CSRF가 없는 뷰도 인증된 작업장 Board를 사용합니다. 관리자용 템플릿과 worker fragment/사진 응답에는 공개 수신기를 주입하지 않습니다. 기존 관리자 음성 수신, 기본 켜짐/명시적 꺼짐, 브라우저 소리 권한, 다른 탭과 중복 방지 및 긴급공지 옵션은 유지합니다.

검증은 임시 Go 서버의 실제 worker-speech poll과 실제 검사 신청 이벤트를 사용하고, 각 화면에서 새 이벤트에 대한 알림음 호출과 음성 오디오 요청이 발생하는지 PC/휴대폰 및 테마에서 검사합니다. 테스트에서 Audio/AudioContext와 음성 오디오 응답은 모의 처리하므로 물리적 스피커/Windows 음량은 검증하지 않습니다. 브라우저가 자동 재생을 차단하면 최초 사용자 조작이 필요하며, 문서 간 이동 시 오디오가 완전히 끊기지 않는 백그라운드 상주 재생 기능은 아닙니다. 전체 Go 시험과 기존 권한/계정·검사·저장 흐름 회귀, Linux/Windows vet, 교차 빌드 및 소스 ZIP 동일 EXE 재빌드를 확인합니다. 다른 기능 브라우저 기록은 이전 버전을 명시해 참조합니다.
