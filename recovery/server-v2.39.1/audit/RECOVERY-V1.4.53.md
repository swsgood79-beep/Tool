# v1.4.53 검사 취소와 사진 필요 상태 연결

문제 재현: 검사 완료→출하사진 등록·보관→보관 사진 삭제→출하사진 필요 복귀→관리자 검사 완료 취소 후에도 사진 필요 기록이 남았습니다.

수정: 현재 수주가 존재하며 검사 완료가 취소/다시 열림 상태이거나 출하 검사 주기가 바뀐 경우, 아직 보관 완료되지 않은 해당 사진 대기 기록을 검사 변경과 같은 저장 작업에서 제거합니다. ‘검사 다시 열기’ 및 세팅/출하 기록의 ‘취소’를 포함합니다. 보관 완료 자료는 이 과정에서 제거하지 않습니다. 이미 열린 사진 필요 목록은 대기 기록 ID 집합 변경을10초 간격으로 확인해 자동 갱신하며, 검색어를 입력 중이면 갱신을 보류해 입력을 보존합니다.

이전 버전에서 이미 검사 취소 후 남아 있는 사진 대기는 프로그램 시작 시 같은 기준으로 정리합니다. 연결 납기표에서 수주가 사라져 현재 수주 자체가 없는 경우는 취소로 간주하지 않고 사진 대기를 유지합니다. 과거 완료 수주를 자동으로 새 사진 대기로 전환하지 않습니다. 특이사항 사진 복사본은 저장 성공 후 더 이상 참조되지 않을 때만 정리하고, 원본 수주/업체/다른 보관 자료 사진은 유지합니다.

검증: 검사 다시 열기/세팅취소/출하취소, 시작 시 기존 잘못된 대기 기록 정리, 원본 시트에서 사라진 수주의 대기 유지, 보관 완료 역사 유지, 저장 실패 롤백, 새 검사 주기 재승인 시 대기1건 생성. 실제 임시 Go 서버와 Chromium PC/휴대폰 밝게·어둡게에서 보관→사진 삭제→사진 대기→관리자 검사 취소→사진 대기에서 제거12개 및 기존 사진 삭제·재등록/누락 복구12개를 검증합니다. 기존 변경하지 않은 추가 사진·기간 목록·일반 전송·재연결은 v1.4.51 결과를 참조합니다.

Windows GUI 교차 빌드와 소스 ZIP의 동일 EXE 재빌드를 확인합니다. 실제 회사 자료·실물 휴대폰·Windows GUI/DPAPI 실행은 확인하지 않았습니다. 기존 D 드라이브 자료 경로 설정은 유지합니다. 전체 소스와 Windows·소스 ZIP, 검증 자료를 recovery-v2.39.1에 배포합니다.
