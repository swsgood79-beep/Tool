# v1.4.72 · 로그인 지속 및 관리자 앱 작업자 화면 전환

APK 1.0.7 / versionCode 8. 사용자의 최종 요구는 한 번 로그인한 뒤 직접 로그아웃할 때까지 지속하는 것입니다. 이전 버전의 onStop 화면 잠금을 제거합니다. 같은 프로세스는 WebView/입력을 유지하고 새 프로세스는 grant + Keystore 암호화 secret을 서버에서 확인하여 동일 account_key로 복원합니다. 저장 연결이 있는 초기 화면은 로그인 폼이 아닌 별도 연결 UI입니다. 통신 장애는 키를 지우지 않고 재시도하며 연결 UI에서도 로그아웃할 수 있습니다. 서버 증명 전에는 업무 화면을 열지 않습니다. 명시적 로그아웃·기기/계정 회수·비밀번호 변경·앱 데이터 삭제는 재로그인이 필요합니다. 이전 비동기 결과는 AuthEpoch로 걸러서 로그아웃 후 다시 열지 못하게 합니다. 자동 지문창은 없습니다.

상단 ⋮와 전체 메뉴에서 작업자 화면을 볼 수 있고 같은 위치에서 관리자 화면으로 돌아옵니다. 인증된 앱 세션에서만 표시 전용 -view 쿠키를 처리합니다. 실제 work/community/shipping/client 페이지는 작업자 메뉴로 렌더링하고 기존 관리자 전환 리다이렉트를 건너뜁니다. 관리자 로그인·CSRF·FCM 기기 연결은 유지하고 일반 PC/작업자 브라우저에는 앱 표시 쿠키를 적용하지 않습니다. 개인 계정은 기존 owner 설정 권한을 얻지 못합니다. 미저장 입력이 있는 네이티브 메뉴 전환은 기존 입력 보호를 사용합니다. 회사 PC 1.4.72 이상이 작업자 보기 기능을 제공합니다.

검증: Android release/JUnit 23개/lint/동일 서명·버전, 전체 Go 테스트, 로그인/로그아웃·단일 기기 격리/화면 전환 권한 race, Linux/Windows vet, Windows GUI 교차 빌드, 원본 web 57개 해시·전체 소스 동일 Windows 재빌드·공개 파일 SHA-256. Chromium에서 임시 Go 서버에 APK UA로 접속해 휴대폰/태블릿·밝게/어둡게의 관리자→작업자→토크→관리자 경로 8개 체크를 수행합니다. 이 검증은 웹 렌더링으로 실제 Android 툴바/앱 수명주기/지문/FCM 수신은 실행하지 않았습니다.

회사 운영자료·자격증명은 변경하지 않았습니다. 업로드된 ERP XLS는 리포지토리 밖에서 읽기만 했으며 회사 자료를 공개 소스/배포 파일에 넣지 않았습니다. v1.4.70 시장 계산과 기존 알림 채널/서명을 유지합니다.
