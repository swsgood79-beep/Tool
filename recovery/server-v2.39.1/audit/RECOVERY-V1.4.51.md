- 보관 완료 목록은 최초 ArchivedAt의 한국 날짜 기준으로 월별 묶음과 전체/이번 달/지난달/기간 지정 조회를 제공합니다. 기본 전체 기간을 유지해 과거 기록을 숨기지 않습니다. 기간 지정은 시작일·종료일 포함이며 잘못된 날짜는 오류로 표시합니다.
- 수주번호·프로젝트명·고객사 검색, 월별 최근 보관순/출고예정일순/수주번호순, 20건 페이지 이동을 제공합니다. 검색·기간·정렬은 페이지 이동 시 유지하고 월별 건수는 해당 조건에 맞는 전체 월 건수입니다.
- 보관 완료 상세에서 사진 추가를 열고 촬영/앨범 선택·신규 선택 취소·저장을 할 수 있습니다. 관리자와 작업자 모두 추가할 수 있으며 기존 사진 삭제/수정 기능은 추가하지 않습니다.
- 기존 사진 포함 최대20장, 한 장당8MB, 기존1600px JPEG 변환·보호 저장 정책을 사용합니다. 최초 보관일·검사 시점 수주 정보·메모를 바꾸지 않고 추가 날짜를 표시하지 않습니다.
- 추가 요청 식별자로 반복 제출을 무해하게 처리하며 오래된 다른 탭의 사진 목록은 저장 전 검증합니다. 저장 실패 시 새 첨부만 정리합니다. 백업은 기존 참조 수집과 저장 폴더를 그대로 사용합니다.
- 정상 초기 사진 저장·추가 사진 저장·검사·비고·토크 전송 시 나가기 경고를 표시하지 않습니다. GET 기간/검색/정렬은 초안으로 취급하지 않고 실제 미저장 POST 입력 이탈 보호는 유지합니다. 사진 추가 취소는 초안을 비웁니다.
