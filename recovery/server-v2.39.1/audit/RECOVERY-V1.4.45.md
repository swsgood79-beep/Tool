# v1.4.45 공용 PC 긴급공지 기본 수신

PC 작업자 화면의 긴급공지 음성 수신 기본값을 켜짐으로 바꿉니다. 이전 v44의 명시적 켜짐만 허용하던 동작을 수정하여 설정이 없으면 자동 수신합니다. 업데이트로 새로운 공개 주소에 접속해 설정이 비어 있어도 수신을 시작하며, 저장소 접근이 불가능한 경우에도 PC 기본 켜짐을 유지합니다.

- 명시적으로 꺼짐을 선택한 경우에는 같은 브라우저 원점에서 그 선택을 유지합니다. 기존 켜짐 설정도 유지합니다.
- 휴대폰·태블릿 감지와 서버의 모바일 방송 거부는 그대로입니다. 관리자 화면 자체를 공용 PC 수신자로 등록하지 않습니다.
- 기존 음성 알림이 꺼져 있거나 브라우저가 소리를 차단한 경우에는 이를 강제 우회하지 않습니다. 공용 PC 작업자 화면이 열려 있고 음성이 활성화되어야 수신할 수 있습니다. 브라우저 소리 차단은 화면 한 번 클릭으로 기존 잠금 해제를 사용합니다.
- 공지 등록·수정만으로 자동 방송하지 않습니다. 관리자 ‘음성 방송’ 버튼을 눌러야 하며 중복 방지·분할 읽기·다시 방송·게시 종료/수정 후 취소 처리는 v44 그대로입니다.
- 서버 방송 권한·수주/검사/납기/사급품/저장 위치와 운영 자료 구조는 바꾸지 않습니다. 브라우저의 긴급공지 수신 초기값만 변경합니다.

## 검증

- Go 전체 race 시험과 Linux/Windows 대상 vet 통과.
- 실제 Go 화면과 Chromium에서 PC/휴대폰 × 밝은/어두운 테마, 관리자 목록/상세 × 390/1100px 총 8개 조합을 확인했습니다. PC는 체크 조작 없이 broadcast_enabled=1로 등록하고 수신·1회 재생·분할 음성 재생을 확인했습니다. 명시적 꺼짐은 새로고침 후에도 유지되며 휴대폰은 등록/재생하지 않습니다.
- 기존 음성 기본 켜짐·자동 재생 잠금 해제·검사 알림·Windows 기본 음성 소유권 관련 브라우저 회귀 시험 통과.
- 오디오와 HTTP 응답을 모의했으며 실제 회사 스피커나 Windows 실행은 검증하지 않았습니다. Windows GUI 교차 빌드와 소스 ZIP 재빌드 일치를 확인하고 이전 배포 ZIP을 보존합니다.
