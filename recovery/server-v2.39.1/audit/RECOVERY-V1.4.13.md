# v1.4.13 PC 검사 신청 효과음과 한국어 TTS

요청 범위는 운영 PC의 새 검사 신청 알림이다. native enqueue에서 기존 중복 팝업 방지를 유지한 뒤 음성 작업에 전달한다. 음성은 프로젝트명, 검사 종류, 신청자만 읽고 비고/수주번호/완료/반려는 읽지 않는다. 기존 비고 알림 효과음/팝업은 유지한다. 세팅·출하 통합은 기존 대표 BatchID 한 건만 읽는다. PC 알림 클릭/관리자 승인·반려/휴대폰 푸시는 변경하지 않는다.

desktop_speech.go는 문장 생성, FIFO 단일 작업자, ID 중복 방지, 시작 시 미확인 항목 프라이밍, 끄기·종료 취소, 상태 표시와 자체 1.1초 22,050Hz mono16bit PCM 띵똥 생성을 담당한다. 최대 대기 256건 초과 시 상태에 표시하며 검사 신청 데이터는 건드리지 않는다. 긴 프로젝트명/이름은 음성에서만 각 200자로 제한한다. 이름은 평문이며 SSML로 해석하지 않는다.

desktop_speech_windows.go는 별도 작업자에서 WinMM 메모리 WAV를 동기 재생한 다음 Windows 기본 PowerShell/System.Speech.Synthesis로 읽는다. 숨김/CREATE_NO_WINDOW, -NoProfile/-NonInteractive/-STA, 절대 시스템 경로를 사용한다. 실행 코드는 고정 UTF16 Base64이며 프로젝트/신청자는 UTF8 JSON stdin 데이터로 전달한다. 문자열을 PowerShell 코드에 보간하지 않는다. 외부 음성 서비스 호출/API 키/추가 요금은 없다. 설치된 활성 ko-KR 여성 음성을 우선 선택하고 없으면 다른 한국어 음성으로, 한국어 음성이 전혀 없으면 실패 상태를 표시한다. 특정 유튜브 상용 음성과 동일하다고 주장하지 않는다. 개별 프로세스는 60초 제한, 끄기/종료 시 취소한다. 창과 HTTP 처리는 음성 완료를 기다리지 않는다.

기존 Windows 창의 연결 상태 아래에 음성 켜기·끄기/미리듣기/상태를 추가했다. 기본 켜짐, Integration.DesktopSpeechMuted를 기존 운영 데이터의 _RecoveredV1 확장에 저장하며 재시작 검증을 포함한다. 격리 모드 실제 신청의 자동 읽기는 막고 수동 미리듣기만 허용한다. 미리듣기는 합성 이름만 사용한다. 일반 알림 미리보기에도 같은 음성을 적용한다.

desktop_speech_test.go는 필드/검사 종류/비신청 제외, 순서와 겹침 방지, ID 중복·시작 전 신청 제외, 끄기 취소와 대기 제거, 다시 켤 때 과거 신청 재생 방지, 음성 오류 후 다음 신청 처리, PCM 구조·진폭, 운영 저장 후 재시작 보존을 합성 runner/임시 데이터로 검증한다. 원래 서버·저장·승인·반려·엑셀·납기 등 전체 race 시험도 다시 수행한다. 원본 web 57개는 수정하지 않는다.

검증 한계: 이 Linux 환경에는 Windows/Wine/PowerShell과 실제 스피커가 없어 System.Speech 스크립트의 실제 실행, 설치 목소리의 음질, PC 오디오 출력, 네이티브 버튼 배치를 실기기로 확인하지 못했다. Windows 교차 빌드/vet와 플랫폼 공통 작업자 시험은 실제 음성 재생 시험을 대신하지 않는다. 회사 정책이 PowerShell/Add-Type을 차단하면 음성 실패가 표시되며 기존 신청 처리와 화면 팝업은 계속된다. 새 버전 설치 후 음성 미리듣기로 확인해야 한다.

기존 소스/ZIP은 삭제하거나 덮어쓰지 않는다. 전체 소스/실행 ZIP/SHA와 소스 ZIP 재빌드 비교 기록을 복구 브랜치에 보관한다. 회사 실제 데이터/사진/비밀키는 포함하지 않으며 이 소스 보관은 업무 데이터 백업 성공을 뜻하지 않는다.
