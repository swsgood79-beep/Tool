# v1.4.11 사급품 버튼 고정 제목 제거

사급품 첫 줄과 셀 색상 정책은 유지한다. 템플릿의 고정 b 제목과 작업자 금일완료/캘린더 JS의 추가 제목 생성만 제거해 원본 셀 내용만 표시한다. 원본 텍스트에 들어 있는 ‘사급품’은 임의 삭제하지 않는다. 관리자/작업자/검사/상세/금일완료/캘린더에 같은 표시를 적용한다. 이전 버전은 보존하며 소스 ZIP 재빌드 해시 검증을 유지한다.

브라우저 시험은 기존 PC/모바일/색상/첫 줄 확인에 버튼 텍스트가 셀 텍스트와 정확히 같은지 확인을 추가한다. 실제 회사 데이터는 변경하지 않는다. Windows는 교차 빌드이며 실기기 렌더 실행은 여기서 확인하지 않았다.
