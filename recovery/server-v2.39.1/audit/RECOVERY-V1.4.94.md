# PC v1.4.94 · 관리자 출하 작업자 이름 정정

보관 완료된 출하 기록의 **세팅 작업자·출하 작업자 이름 수정**을 추가했습니다. 관리자 PC/앱에서 **출하 기록 → 해당 수주 → 작업자 이름 수정 → 작업자 이름 저장**을 사용합니다. 여러 명은 공백/쉼표로 함께 적고 각각 40자 이내로 입력합니다. 이름을 비우면 미기록 표시(—)로 돌아갑니다. 해당 출하 기록과 이후 저장하는 출하 엑셀에 반영하며 검사자·검사 완료 시각·보관일·출하사진·첨부·사급품은 유지합니다. 원래 작업자의 검사 신청 내역과 기존 월별 검사 엑셀 원본은 바꾸지 않습니다. 작업자는 수정할 수 없으며 수정된 이름만 확인합니다. PC v1.4.86 이상은 PC 업데이트 확인으로 v1.4.94를 설치하고 APK 1.0.11은 그대로 사용합니다.

관리자/CSRF를 통과한 /shipping-archive-admin/{id}/edit-workers POST만 허용하고 inspectionActor로 서버의 실제 계정 정보를 얻습니다. 구매 전용 계정 및 공개 작업자 경로는 차단합니다. ArchivedAt이 있는 보관 완료 기록에만 적용하고 trim/UTF8/40자/제어문자 검증을 합니다. WorkerRevision과 현재 이름·보관일·레코드 ID의 해시로 오래된 화면과 ABA 덮어쓰기를 거부합니다. 같은 이름 저장은 별도 수정 이력이나 revision을 더하지 않습니다.

commitAnnouncement의 clone/persist 후 교체를 사용하므로 저장 실패 시 이름/이력이 부분 반영되지 않고 원래 검사 신청 Event·현재 Project·월별 검사 기록 파일과 알림은 건드리지 않습니다. ShippingRecord의 optional WorkerEdits는 수정 전후 이름/실제 처리 계정/시각을 내부에 남기며 화면에서 별도의 보완 시간/계정을 표시하지 않습니다. 조회·특이사항/고객사 프로젝션은 이름 정정을 덮어쓰지 않습니다.

관리자 상세의 접이식 입력을 사용하며 권한/확인 토큰과 기록용 계정은 서버에서 검사합니다. 오류는 입력을 보존한 같은 화면에서 표시하고 최신 revision으로 재확인합니다. 공개 작업자 화면에는 편집 UI를 제공하지 않습니다. 원래 web57개와 APK1.0.11 유지.

시험: 관리자/동료 계정 귀속·클라이언트 위조 처리자 무시·공개 경로/익명/구매/CSRF 차단, 오래된 화면/유효성/동일 값/미보관/저장 실패, 전체 보관 증빙 중 작업자 이름/정정 이력만 변경, 원래 신청/월별 파일 불변, 출하 XLSX I5/K5와 재실행 보존. Chromium PC/모바일 APK user agent 밝게/어둡게 4뷰에서 실제 편집/저장/작업자 읽기 전용·날짜/검사자 불변·나가기 경고 부재를 검증했습니다. 전체 Go/race/Linux·Windows vet와 Windows GUI 교차 빌드/배포 소스 재빌드 일치 확인. 회사 운영 자료 및 실제 Windows/Android/Microsoft Excel 기기 실행은 하지 않았습니다.
