# PC v1.4.92 · 출하 특이사항 중복 표시 수정

출하 기록의 특이사항에서 업체 원본 사진과 기존 복사본이 중복으로 보이던 문제를 수정했습니다. 원본과 복사본의 ID가 달라도 같은 내용이면 화면과 새 출하 엑셀에는 한 번만 표시하고 현재 업체 원본을 우선합니다. 이름이 같아도 내용이 다른 사진은 유지하며 사진 파일·검사 기록·날짜는 삭제하거나 변경하지 않습니다. 출하 기록 상세와 출하 상세 엑셀의 날짜 제목만 **출고일자**로 바꿉니다. 수주 목록·출고 일정의 **출고 예정** 표시는 유지합니다. PC v1.4.86 이상은 PC 업데이트 확인으로 v1.4.92를 설치하며 APK 1.0.11은 그대로 사용합니다.

1.4.91 shippingCurrentNotes는 live.Photos와 selectedClientPhotos를 합칩니다. 예전 materialized 업체 복사본이 live.Photos에 남은 경우 ID가 서로 달라 같은 사진을 두 번 표시할 수 있었습니다. 새 App.shippingCurrentNotes는 원본 스키마 변경 없이 표시/내보내기 복사본에만 중복 제거를 적용합니다. 현재 업체 원본 ID를 우선하고, 보관 당시 MaterializedPhotos 관계 및 제한된 파일 읽기/복호화/정규 JPEG 내용 해시를 비교합니다. 같은 이름/크기/해상도는 동일성 근거로 쓰지 않습니다. 파일을 읽거나 정규화하지 못하면 내용 해시로 숨기지 않습니다. 중복된 ID만은 한 번 표시합니다. 일반 출하사진·첨부는 이 처리에서 제외합니다. 디스크 삭제나 기존 State 수정은 하지 않습니다.

사진 다운로드 권한 확인은 전체 원본 목록을 사용하며 요청마다 중복 제거용 이미지 I/O를 반복하지 않습니다. 관리자/작업자 출하 상세와 엑셀 스냅샷에만 적용하고 수주 목록/출고 일정의 날짜 제목은 그대로 둡니다.

실제 파일이 다른 ID인 PNG원본/JPEG복사본, materialized 관계의 유무, 같은 파일명/해상도의 서로 다른 이미지 보존, 없는 파일 보존, 원본 수정·재시작 후 중복 방지, State/파일/출하사진 보존을 검사합니다. 실제 출하 XLSX를 생성해 중복 없는 export 스냅샷과 출고일자 셀을 검사하고 Chromium PC/모바일 APK user agent 밝게/어둡게의 관리자·작업자 8뷰에서 2장으로 표시되는지 확인합니다. 전체 회귀·race·Linux/Windows vet와 Windows GUI 교차 빌드 및 전체 소스 재빌드 일치를 검증합니다. 실제 회사 자료·Windows/Android 기기·Microsoft Excel 실행은 하지 않았습니다. 기존 web57개와 APK1.0.11은 유지합니다.
