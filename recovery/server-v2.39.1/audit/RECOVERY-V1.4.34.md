# v1.4.34 — 승인한 수주 카드 디자인 적용

관리자·작업자 수주목록, 금일 검사 완료, 출고일정에 승인한 흰색 카드 디자인을 적용합니다. 진한 회색 테두리, 상단 번호·출고 예정일·검사 단계, 큰 프로젝트명, 회색 담당자 버튼, 빨간 특이사항, 오른쪽 아래 파란 검사 열기를 사용합니다. 사급품의 배경색과 대비는 기존 엑셀 셀 색상 처리 그대로입니다. 완료 카드는 기존 녹색 구분을 유지합니다.

## 변경 범위

새 CSS/JS 표현 계층과 해당 자산의 로딩 버전만 변경했습니다. 서버 데이터 스키마·저장 파일·API·검사 승인/반려·알림·납기 동기화·완료/숨김 필터는 변경하지 않았습니다. main.go와 production.go의 변경은 표시 버전입니다. 원래 추출한 web/ 57개 파일은 변경하지 않았습니다.

기존 담당자 전화 링크, 특이사항/사급품 팝업, 검사 신청 진입을 그대로 사용합니다. 관리자 수정·펼침·숨김·삭제 컨트롤도 유지합니다. 완료된 작업자 카드에는 새 검사 버튼을 만들지 않았습니다. 출고일정 검사창 닫기·ESC·특이사항 취소 시 원래 일정으로 돌아가는 v1.4.33 동작을 유지합니다. 기존 화면 선택 시 생성한 디자인 요소를 제거하고 원래 노드를 복원합니다.

## 검증

- 전체 Go race 테스트 통과. 상세: go-test-race-v1.4.34.txt (환경 선택 테스트의 SKIP은 로그에 명시).
- Linux/Windows go vet 통과, Windows amd64 GUI 교차 빌드 성공.
- 승인 디자인 브라우저 12조합: 관리자/작업자 × 밝게/어둡게 × 320/390/1100px. 원본 엑셀 색상, 전화 href, 관리자 원래 컨트롤, 키보드 검사 진입, 완료 녹색, 실제 승인 후 자동 갱신, 기존 화면 복원 확인.
- 일정 복귀 브라우저 12조합: 기존/새 화면, 테마와 폭 조합. 닫기/ESC/확인 취소·진행, 날짜/월/스크롤/URL/히스토리 복원 및 승인 후 갱신 확인.
- 원본 web/ 자산 57개 SHA-256 일치, ZIP 무결성 검사, 소스 ZIP에서 실행 파일 재빌드 비교.
- 실제 Windows 데스크톱 실행 및 휴대폰 OS 전화 앱 실행은 이 Linux 환경에서 수행하지 않았습니다. 브라우저에서 전화 링크와 기존 액션 연결을 검증했습니다.

## 업데이트

회사 PC에서 기존 프로그램을 트레이까지 종료하고 새 ZIP을 풀어 AlphaWorkComplete-Recovered.exe를 실행하세요. 관리자·작업자 화면을 새로고침하세요. 기존 운영 자료 경로와 설정은 그대로 사용하며, 일반 버전 업데이트에는 테스트 자료 승격 스크립트를 실행하지 않습니다.

이 버전의 전체 소스·테스트·화면 캡처와 Windows/소스 ZIP을 recovery-v2.39.1 브랜치에 추가하며 이전 버전 파일은 보존합니다.
