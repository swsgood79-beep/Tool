# v1.4.69 · 관리자 앱 로그인 유지 복원

APK 1.0.5 / versionCode 6. 이전 앱은 저장된 서버 로그인 연결과 별개로 onStop에서 showLock을 호출하고 시작 시 항상 로그인 화면을 표시했습니다. 이는 직접 로그아웃 전까지 계속 사용하려는 요구와 달랐습니다.

이제 앱 전환·화면 끄기 시 인증된 업무 화면을 잠그지 않고 같은 WebView와 입력 상태를 유지합니다. 새 프로세스의 첫 onResume에서 저장된 grant + Android Keystore 암호화 secret을 사용해 기존 서버 복원 프로토콜로 인증하고 account_key가 같은지 확인한 후 업무 화면을 엽니다. 서버 증명 없이 로컬 플래그만으로 열지 않습니다. 일시적인 연결 장애는 키를 지우지 않고 전면 실행 중 재시도합니다. 사용자가 다른 아이디/비밀번호를 입력 중이면 자동 재시도를 보류합니다. 이전 계정 응답은 AuthEpoch로 차단합니다.

명시적 로그아웃·서버 연결 해제·비밀번호 변경·계정 중지 검증은 그대로입니다. 로그아웃 시 현재 기기 키/푸시를 지우며 다음 실행에서 자동 복원하지 않습니다. 지문창은 사용자 버튼으로만 열고 자동 요청하지 않습니다. 상단 담당자 이름과 로그아웃 버튼, 기존 알림 채널/서명/PC 관리자 화면/회사 자료는 유지합니다.

검증: Android 서명 릴리스 빌드, JUnit 21개 (복원 조건·로그아웃 차단·서버 증명 전 비인증·중복 복원 억제 포함), lint, APK 서명/버전 확인. Go 전체 테스트 및 기존 서버의 재시작 복원·로그아웃/계정/기기 경계·단일 기기 해제 race 테스트. Linux/Windows vet, Windows GUI 교차 빌드, 원본 web 자산 57개 해시, 전체 소스 ZIP 체크섬/동일 Windows 재빌드, 공개 다운로드 SHA-256 확인. 변경하지 않은 브라우저 동작의 이력은 v1.4.66입니다.

제한: 실제 Android 앱 전환·프로세스 종료·재실행·설치·FCM 수신과 Windows 실행은 이 환경에서 테스트하지 않았습니다. 회사 PC의 운영자료/저장경로/Firebase 설정을 변경하지 않습니다. 비밀키/서명 자료는 공개 소스에 포함하지 않습니다.
