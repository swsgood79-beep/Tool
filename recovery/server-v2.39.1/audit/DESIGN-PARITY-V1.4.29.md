# 기존 화면과 새 디자인 기능 비교 — v1.4.29

비교 대상은 현재 복구 프로그램에서 선택 가능한 ‘기존 화면’과 ‘새 디자인’입니다. 분실된 최초 원본 프로그램 전체 또는 실제 회사 설치 PC와 동일하다는 검증은 아닙니다. 회사 업무 자료·ERP 첨부파일·자격정보는 사용하지 않고 Go 시험 자료를 실제 렌더링했습니다.

## 확인된 문제

| 항목 | 원인과 영향 | 처리 |
|---|---|---|
| 관리자 수주목록 담당자 전화 | 담당자를 링크가 아닌 span 글자로 출력. 새 디자인에서는 버튼처럼 보여도 전화가 안 됨. 기존 화면에도 있던 공통 누락 | 요청에 따라 수정 |
| 작업자·검사 상세·특이사항의 전화 링크 | 문자열 tel URL이 html/template에서 #ZgotmplZ로 필터링됨. 기존/새 화면 공통 문제이며 새 디자인만의 회귀가 아님 | 전화번호만 정규화하여 서버에서 생성한 tel URL을 출력하도록 수정 |
| PC 작업자 날짜 구분줄 | .due-day-heading이 2열 grid에서 전체 폭을 차지하지 않아 카드 한 칸처럼 커짐. 기존 화면은 정상 가로 줄, 새 디자인 1100px에서 재현 | 발견 내용만 기록. 사용자 요청 없이 레이아웃을 수정하지 않음 |

## 비교·동작 확인 범위

390/1100px × 기존/새 디자인 × 20개 페이지 = 80개 페이지를 검사했습니다. 각 페이지의 기존 form action, method, 필드 이름과 비활성 상태가 새 디자인에서 유지됨을 확인했습니다. 관리자 홈 설정 메뉴의 기존 링크가 전체 메뉴에 있는지 비교했습니다. 전화 링크는 별도로 밝게/어둡게 × 390/1100px × 기존/새 × 관리자/작업자 16조합에서 확인했습니다.

페이지: 관리자 홈, 작업자 목록, 검사 신청 목록, 검사 승인/반려, 수주 등록, 업체 특이사항, 수주 특이사항, 음성 설정, 일반 설정, 인터넷 연결, 납기표 연결, 시장 설정, 엑셀 설정, 백업, 휴대폰 관리자, 담당자 관리, 업체 관리, 엑셀 일괄등록, 수주 수정, 미확인 알림.

직접 조작한 항목:

- 작업자 검색, 사급품 내용 팝업, 신청 전 특이사항 확인 창
- 세팅 단독·세팅/출하 동시 신청의 전송 경로와 작업자 값
- 비고 내용과 신청자 전송. 비고는 기존 방식대로 별도 페이지 접수 흐름이며 모달 유지로 바꾸지 않음
- 관리자 검사 확인·반려 버튼 노출과 검사 상세 연결
- 업체 특이사항 펼치기
- 음성 ON/OFF 제어의 접근 위치: 기존 화면 본문, 새 디자인 전체 메뉴
- 전화 버튼 클릭이 검사 신청창을 열지 않고 정상 tel 주소로 이어짐, 자동 갱신 후 바뀐 번호 반영

실제 POST는 시험 브라우저에서 가로채 요청 내용만 검사했으며 회사 자료는 쓰지 않았습니다. 업무 저장·승인·반려·엑셀·일정 연동의 서버 로직은 전체 Go race 시험으로 별도 검증했습니다. 새 디자인에 없는 기능이 ‘그 외 전혀 없다’는 결론은 아닙니다.

## 확인하지 못한 범위

실제 휴대폰의 전화 앱 실행, Windows 음성 출력·네이티브 팝업, 잠금 상태 푸시, 실제 OneDrive·시세 계정·백업·지문 인증, 삼성 브라우저 강제 다크모드는 이 환경에서 직접 실행하지 않았습니다. 설정 메뉴와 폼이 보존된 것과 외부 서비스가 실제 회사 환경에서 성공하는 것은 구분해야 합니다.

## 이번 변경 범위

실행 코드 변경은 담당자 전화 연결과 버전 표시뿐입니다. 설계담당자 이름·색상·위치, 일정·미정 집계·녹색 완료 표시·동기화 정책, 검사 처리 순서, 음성 설정, 날짜 구분줄과 다른 레이아웃은 변경하지 않았습니다. 원본 57개 web 파일도 변경하지 않았습니다.
