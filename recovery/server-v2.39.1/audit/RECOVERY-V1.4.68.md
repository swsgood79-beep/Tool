# v1.4.68 · 관리자 앱 담당자 이름과 로그아웃

관리자 APK 1.0.4 (versionCode 5)에 상단 담당자 이름과 로그아웃 버튼을 추가합니다. 이름은 서버에서 확인한 account_label이며 전체 메뉴와 같습니다. 다른 계정으로 로그인하면 해당 계정 이름으로 갱신합니다. 로그인 화면에서는 표시하지 않습니다.

로그아웃 시 로컬 저장 로그인/지문 연결, 기존 앱 알림을 지우고 signed_out으로 새 알림을 차단합니다. 정상 로그아웃과 해당 로그인 capability/푸시 기기 해제를 요청합니다. 다른 휴대폰이나 독립된 PC 로그인은 유지합니다. 네트워크가 없을 때 서버 해제는 최선 노력이며 로컬 해제는 즉시 적용합니다. 입력 중인 폼이 있을 때만 로그아웃 확인합니다. 세션 변경 전 비동기 응답은 epoch로 차단합니다. 일반 브라우저·PC 화면과 기존 알림 채널은 변경하지 않습니다.

검증: 전체 Go 테스트, 네이티브 로그인/푸시/단일 휴대폰 로그아웃 격리 race 테스트, Linux/Windows vet, Windows GUI 교차 빌드, Android 서명 릴리스·JUnit 18개·lint, 공개 다운로드 SHA-256 및 소스 ZIP 재빌드를 확인합니다. APK 서명은 이전 버전과 동일합니다. 기존 web 원본 57개 해시를 검증합니다. 변경하지 않은 웹 기능의 브라우저 근거는 v1.4.66 기록입니다.

제한: 실제 휴대폰의 상단 화면 배치·지문 센서·설치·라이브 FCM 수신과 Windows 실행은 이 환경에서 테스트하지 않았습니다. 회사 PC의 기존 운영자료/저장경로/비밀번호/Firebase 설정을 변경하지 않습니다. 비밀키와 서명 자료는 공개 소스에 포함하지 않습니다.
