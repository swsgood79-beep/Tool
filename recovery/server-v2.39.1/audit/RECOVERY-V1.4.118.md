# PC 1.4.118

v1.4.117에서 ERP 스크립트를 UTF-16 Base64로 전체 실행 인자에 넣으면 스크립트만 34,284자로 Windows CreateProcess 한도 32,767자를 초과합니다. 기존 cmd.Start 오류가 단순 failed로만 전달되던 회귀를 수정했습니다. 사용자 첨부 자료는 소스나 공개 배포에 포함하지 않습니다.

전체 스크립트는 UTF-8 표준입력으로 보내고, 고정된 짧은 부트스트랩만 -EncodedCommand로 전달합니다. 같은 Windows PowerShell/INI/SQL과 프로세스 종료 관리, 취소/시간 제한 구조를 사용합니다. 임시 스크립트 파일을 쓰지 않습니다. 시작/관리/종료/응답 해석 실패와 Windows 시작 오류 번호를 안전한 고정 필드로 보관합니다. 원문 오류/접속 문자열/비밀번호를 화면이나 결과 파일에 추가하지 않습니다.

실제 크기 스크립트의 기존 실행 한도 초과와 새 인자 2,048자 미만, 한글/따옴표 경로·모드 보존, 자식 프로세스 표준입력 완전 전달 및 실패 단계 디코딩을 검증합니다. 합성 실패/조회 결과를 사용한 실제 Chromium 320/390/430/1100px 경고 화면과 정상 재시도, 기존 목록/수량/설정 보존을 확인합니다. 실제 회사 Windows PowerShell/DB 실행은 현장 확인이 필요합니다. APK 1.0.11 유지.
