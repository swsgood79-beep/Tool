# PC v1.4.116 복구 메모

기준은 공개 브랜치 recovery-v2.39.1의 dce5c037b7b9389ca6f1915cbb371e9e8eace0e6, PC v1.4.115 / APK v1.0.11입니다. 기존 /workspace/Tool의 v1.4.94는 보존하고 별도 작업공간에서 진행했습니다. 이전 v1.4.116 작업 파일은 발견되지 않았습니다.

## 기능 1 소스 저장 단계

대표 관리자 전용 /machining-admin/test-reset에서 계정 ID 선택, 기록 미리보기, 확인 체크, 로컬 백업 검증 후 초기화를 구현했습니다. 후속 타 작업자 및 ERP 입고 확인 기록은 보류합니다. DPAPI protect/unprotect를 사용하며 초기화 이력을 상태에 보관합니다. 실제 업무 자료 초기화는 실행하지 않았습니다.

현재 배포본은 여전히 v1.4.115입니다. 이 커밋은 작업 중간 저장입니다. 합성 권한/CSRF/동시변경/백업 실패/보존 테스트, 모바일 스크린샷, 전체 Go 테스트, Windows 빌드, 소스 ZIP 재빌드, 배포 검증은 이후 단계입니다.

미입고 조회 화면 연결은 준비 중이며 아직 완료되지 않았습니다. 다음 단계는 기존 ERP INI 경로를 재사용하여 수주별 전체 거래처 읽기 전용 조회를 구현하는 것입니다. APK v1.0.11 유지. 사용자 업무 자료, 업로드, DB 결과, 비밀번호는 커밋하지 않습니다.

사용자 지시에 따라 기능별 소스와 복구 메모를 먼저 커밋·푸시한 후 빌드·배포합니다. 중단되면 이 문서와 최신 커밋을 먼저 확인합니다.

## 기능 2 소스 저장 단계

수주카드의 미입고 현황 보기와 전체 폭 로봇품번 + 품명/잔량/거래처/예정일 4열 팝업을 추가했습니다. 기존 INI 연결을 재사용하며 수주 매개변수로 전체 거래처/품목의 발주-입고 잔량만 조회합니다. 발주/가공의뢰 복합 키 및 행별 수주 우선 연결을 적용했습니다. 로봇품번은 가공의뢰의 단일 식별값만 사용하며 불명확하면 확인 불가로 표시합니다. 실패/결과 잘림은 오류로 표시합니다. 회사 ERP 실제 결과 대조와 Windows 실기 확인은 남아 있습니다. 이후 합성 검증과 배포를 계속해야 합니다.

## 지속 작업 기준 및 브랜치

사용자 추가 지시에 따라 미완성 작업 브랜치는 work-pc-v1.4.116입니다. recovery-v2.39.1에는 중간 소스 커밋을 되돌리는 커밋을 올려 v1.4.115로 유지했습니다. 최종 배포 시 작업 브랜치의 기능 변경을 다시 적용해야 합니다. 업데이트 메타데이터는 아직 v1.4.115입니다. 루트 AGENTS.md에 사용자 지속 작업 기준을 저장했습니다.

수정 파일은 machining_reset.go, model.go, machining_http.go, order_outstanding.go, erp_db_probe.go, erp_db_probe_windows.go, erp-db-probe.ps1, extras/machining*.html/js, extras/order-outstanding-v1.4.116.css/js입니다. 초기 구현 전 전체 Go 테스트는 통과했습니다. 신규 기능 테스트는 작성 중입니다.

## 합성 단위 검증

초기화 대표 관리자/CSRF/명시 확인, 백업 실패 시 불변, 미리보기 이후 revision 변경 거부, 동명이인 ID 구분, 다른 작업자 후속 공정/입고 확인 보류, 대상 외 계정/로그인/수주/수량 보존, 백업 복호화 일치 및 재시작 후 이력 보존 테스트가 통과했습니다. 미입고 조회의 수주 범위/소수 잔량/읽기 전용/실패/잘림 처리가 통과했습니다. ERP 원본 입고 수량이 있는 작업도 초기화를 보류하도록 강화했습니다.

추가 파일은 machining_reset_test.go, order_outstanding_test.go, release116_browser_test.go, audit/browser-release-v1.4.116.cjs입니다. 백업 emptiness 판정에 초기화 이력도 포함합니다. Chromium 320/360/390/430/1100px 검증 및 실제 구현 캡처를 실행 중입니다. 다음 단계는 화면 확인, 전체 Go 테스트/race/vet, Windows 빌드, 패키징 및 ZIP 소스 재빌드입니다. 정식 업데이트는 아직 v1.4.115입니다.

## 화면 검증 완료 및 작은 보정

실제 Chromium 화면에서 320/360/390/430/1100px 미입고 팝업 및 390/1100px 초기화 미리보기, 합성 자료 초기화 후 이력을 확인했습니다. 모든 7개 브라우저 사례가 통과했습니다. 화면 확인 후 320px 수량 열 너비와 버튼 높이를 보정했고 상단 버전 표시가 이전 1.4.105로 고정된 부분을 releaseVersion 기반으로 고쳤습니다. 최종 화면 재촬영 및 전체 검증을 진행합니다. 테스트 캡처는 모두 가상 계정/가상 ERP 응답입니다.

휴대폰 푸시가 이전 알림 목록을 복사해 둔 경우에도 전송 직전에 해당 완료 알림이 현재 상태에 남아 있는지 확인하도록 team_native_push.go를 수정했습니다. 초기화로 제거된 대기 알림의 재전송을 방지합니다. 전체 검증/최종 Windows 빌드는 이 소스 상태로 다시 확인해야 합니다.
