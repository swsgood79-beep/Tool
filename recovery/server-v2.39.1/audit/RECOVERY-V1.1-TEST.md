# v1.1 격리 테스트판

v1.0의 기본 실행이 원본 자료 폴더에 직접 쓰던 동작을 사용자 요청에 따라 교체했습니다. 기존 v1.0 ZIP과 증거 기록은 삭제하지 않습니다.

- 기본값 `%AppData%\AlphaWorkRecoveryTest-v1.1`, `127.0.0.1:28791`. 원본/이전 복구판 자동 탐색 제거.
- 표시 없는 기존 자료 폴더와 예약된 운영 폴더 이름은 읽기/백업/저장 전에 거부. 새 빈 폴더에만 테스트 표시를 생성.
- 첫 실행에 예시 수주 2개 생성. 테스트 키·비밀번호·기록·사진은 테스트 폴더에만 보관.
- 별도 Windows 뮤텍스 `Local\AlphaWorkRecoveryTest-v1`, 클래스 `AlphaWorkRecoveryTestMain` 및 팝업/배지 클래스. 기존 원본을 종료시키거나 기존 창을 찾아 조작하지 않음.
- 세션/로그인 nonce 쿠키도 테스트 전용 이름으로 분리. 포트만 달라도 쿠키는 겹칠 수 있어 별도 처리.
- 원격 접속·휴대폰·지문·백업 경로 차단, HTTP 전송 계층에서 모든 외부 요청 차단. Native ‘인터넷 연결’도 시작하지 않음. 연동 설정은 테스트 폴더에서만 초기화.
- Linux에서 기존 버전을 모사한 서버(18791)와 테스트판(28791)을 동시 실행해 브라우저 신청/승인, 쿠키 유지, 기존 서버 폴더의 모든 파일 해시 불변을 확인. 실제 회사 PC나 Windows 트레이 동시 실행을 검증한 것은 아님.

기존 폴더 전체를 채팅/GitHub에 올리지 않습니다. 실제 자료 복사본 시험이 필요하면 같은 Windows 계정 안에서 별도 설계해야 합니다. 이 버전은 기본 예시 데이터로 시작합니다.
