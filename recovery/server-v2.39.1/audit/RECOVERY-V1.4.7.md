# v1.4.7 작업자 전체 업체 특이사항 진입 개선

기존 읽기 전용 업체 전체 조회 기능을 작업자가 찾기 쉽게 수주 검색창 위의 붉은 안내 카드로 강조한다. 링크에는 현재 등록 업체 수와 내용/사진 조회 안내를 표시한다. 업체 페이지는 수주 미연결 업체도 포함하며 검색/사진/3초 갱신을 유지한다. 페이지에 업체를 누르면 펼쳐진다는 설명을 추가했다. 관리자 원본 수정/삭제는 기존 관리 기능에 한정한다.

기존 TestWorkerClientDirectoryReadOnlyBoardPhotosAndEscaping으로 board 인증/사진/HTML 이스케이프/POST405/명단 변경을 확인한다. 합성 자료의 HTML/JPEG를 환경변수로 선택해 테스트용 임시 폴더에 내보내 브라우저로 검증했다. 실제 회사 자료는 쓰지 않았다. browser-worker-directory-v1.4.7.json: 1100/390px 진입 버튼, 미연결 업체, 사진, 검색, 자동 갱신 후 검색/펼침 유지, 가로 넘침 없음/JS 오류 없음. 스크린샷은 합성 자료다. Windows 실제 실행은 교차 빌드만 확인했다.

이전 알림·캘린더 완료 수주 제외·엑셀 폴더 수정은 유지한다. 운영 자료 재가져오기 없이 EXE만 교체한다.
