# v1.2 기존 자료 복사 기능

격리 시험판에서 기존 데이터로 비교할 수 있도록 명시적인 `-copy-original` 시작 옵션을 추가했습니다. 자동으로 원본을 가져오거나 원본 폴더를 저장 위치로 사용하지 않습니다.

- `copy-existing-data.cmd`: 같은 폴더의 AlphaWorkRecoveryTest.exe를 -copy-original로 실행. 기존 테스트판이 열려 있으면 테스트 뮤텍스에서 거부하며 원본 프로그램을 종료하지 않음.
- 원본 UserConfigDir/WanryoTalk의 기존 6개 .dat 및 project-photos의 일반 .dat 파일만 읽어 새로운 테스트 복사본 생성. 실행 파일·접속 도구·원본 백업/저널/잠금 파일은 복사하지 않음.
- 원본 목록/바이트 해시를 확인하고 복사된 바이트와 비교. 복사 후 원본 해시를 다시 확인하며 바뀌면 중단. 중간 실패 복사본을 삭제하지 않으며 기존 활성 복사본을 유지.
- 같은 Windows 계정에서 DPAPI 복호화/재저장. 설정·원격 연동을 비우고 외부 네트워크 차단은 유지. 작업장 접근 키·신청 폼 토큰도 복사본에서 새로 생성.
- 성공적으로 자료를 읽고 저장한 뒤에만 테스트 루트의 active-test-copy.json에 상대 폴더 이름을 기록. 정상 실행/continue-test.cmd는 같은 복사본을 재개. 폴더 경로 탈출·심볼릭 링크로 다른 위치 선택 방지.
- 원본의 별도 Documents 엑셀 및 수동 엑셀 변경 내용은 가져오지 않음. 복사된 검사 기록으로 테스트용 엑셀을 생성.

원본 스키마의 생성 시험 파일로 데이터/사진 복사·변경·재시작·원본 바이트 불변·원본 변경 감지·선택 정보 보존·잘못된 경로 거부를 Go 시험했습니다. Linux CLI -copy-original의 복사→브라우저 로그인/신청/승인→옵션 없는 재실행도 확인했습니다. 회사 자료를 받거나 GitHub에 올리지 않았습니다. Windows 실기기/회사 DPAPI 실행은 여전히 미검증입니다.
