# v1.4.75 / APK 1.0.8 · 앱 테마와 사용자 안내

사용자가 제시한 설계담당자 입력 묶음의 밝은 고정 배경과 네이티브 상단 흰색을 확인했습니다. 앱 전용 CSS를 마지막에 적용해 fieldset/담당자/업체 원본/검사 상태/일정/백업/음성 설정/표/대화상자/위험 버튼을 기존 ui 테마 변수로 표시합니다. 일반 PC·작업자 브라우저의 원본 web 57개 자산과 기존 자산은 보존합니다. APK 관리 화면과 그 앱의 작업자 보기에서만 적용합니다.

APK 1.0.8/versionCode 9는 AppPalette 및 Light/Dark 리소스로 상단·본문 루트·로그인·연결·버튼·상태/탐색바와 새 대화상자 테마를 적용합니다. 밝게/어둡게는 OS보다 우선하고 system은 OS를 따릅니다. 재실행/다른 접속 주소에서도 앱에 저장한 선호를 웹에 전달합니다. JavascriptInterface는 theme get/set만 노출하고 set 값 3종과 WebView의 회사 origin을 확인합니다. 인증·파일·키 접근은 노출하지 않습니다. 로그인 유지와 기존 FCM 채널/서명은 유지합니다.

README와 START-HERE를 실제 사용 절차로 다시 작성했습니다. 다운로드, 검사 단계, 로그인/개인 계정, 알림, 업체 원본, 출하사진/보관, 공지/토크, 납기/사급품/엑셀/시세, D드라이브 저장 및 백업, 문제 확인, 소스·검증 범위를 설명합니다. 기존 README 내용은 CHANGELOG에, 기존 시작 안내는 docs/history에 보존합니다. GitHub 기본 main에는 이 사용 안내의 링크를 맞춘 사본을 별도 README 변경으로 게시하며 현재 접속 포인터나 실행파일을 수정하지 않습니다.

Chromium APK UA로 24개 경로·전체 메뉴·작업자 보기와 수동 테마 변경/이동을 휴대폰/태블릿 × OS/명시 테마 4조합으로 점검합니다. 기록 224개 중 로컬 PC 전용 자료 경로의 403 8개는 권한 제한으로 유지하고, 나머지 216개 렌더링에서 큰 밝은 배경 및 정량 점검 대상 텍스트 대비 문제 0개를 확인했습니다. 그라데이션/이미지/비활성 요소는 일반 텍스트 대비 계산에서 제외하며 전체 WCAG 적합성 인증을 뜻하지 않습니다. 웹 테스트의 네이티브 브리지는 모의입니다.
