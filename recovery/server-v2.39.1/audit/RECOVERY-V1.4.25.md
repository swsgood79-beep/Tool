# v1.4.25 — 최근 기록에서 반려 제외

관리자 하단 ‘검사 신청·완료·비고 · 최근 100건’에 반려 기록을 표시하지 않습니다. 반려 기록을 제외하고 최근 100건을 채우므로 반려 항목이 많아도 정상 완료·비고 등의 최근 소식이 밀려 사라지지 않습니다. 페이지 건수·검색·검사/비고 필터는 실제 표시 대상만 계산합니다.

CSV는 기존 completedEvents에서 이미 반려를 제외했습니다. 해당 동작을 회귀 검증하여 정상 완료 기록만 유지함을 확인했습니다. 저장된 반려 이벤트나 수주의 반려 상태는 삭제하지 않습니다. 기존 신청 토큰 차단·반려 후 재신청·완료/비고·월별 엑셀·관리자/작업자 디자인은 그대로 유지합니다.

검증: 실제 반려 후 정상 세팅/출하 완료·비고·추가 반려 120건을 합성 자료로 구성했습니다. 화면용 목록은 정상 완료 2건과 비고 1건만 표시, CSV는 머리글과 정상 완료 2건만 출력, 조회/내보내기에 저장 자료 변화 없음, 재시작 후 반려 상태와 재신청 유지 확인. 브라우저 390/1100px에서 행·페이지 건수·검색·검사/비고 필터·CSV 연결을 확인했습니다. 전체 Go race, Linux/Windows vet, Windows GUI 교차 빌드 및 소스 ZIP 동일 재빌드 검증을 수행합니다. 별도 경로가 필요한 선택 납기표 시험 1건은 경로 미지정으로 건너뛰었습니다. 실제 회사 Windows 실행은 여기서 검증하지 않았습니다.

이전 프로그램을 트레이에서 종료하고 새 EXE를 실행한 뒤 관리자 화면을 새로고침합니다. 전체 소스·실행 ZIP·검증 자료와 이전 버전은 GitHub 복구 브랜치에 보존합니다.
