# v1.4.23 — 새 디자인 기본 적용, 카드 고정 배열, 일반 출고 일정, 다크모드

## 화면 변경

- 새 디자인을 기본 적용합니다. 기존 미리보기 v1 선택과 별도인 브라우저 설정 v2를 사용하므로 예전에 기존 화면을 선택했던 브라우저도 새 디자인이 기본입니다. 상단 미리보기/기존 화면 버튼을 제거하고, 필요 시 전체 → 화면 설정에서 이전 화면으로 돌아갈 수 있습니다.
- 작업자 및 관리자 수주에 담당자/사급품/특이사항의 3개 고정 칸을 만듭니다. 없는 항목은 해당 자리를 유지하며, 긴 내용은 줄임 표시·전체 내용 안내를 사용합니다. 실제 기존 링크와 버튼을 옮겨 전화/사급품 안내/특이사항 기능을 유지합니다. 제목은 2줄 영역을 확보하고, 세팅 작업자 정보는 하단에 유지합니다.
- 담당자는 파란 계열, 출고 예정일은 보라 계열, 특이사항은 붉은 계열로 표시합니다. 사급품은 원본 납기표 색상을 유지하며 검정/흰색 중 높은 대비 글자를 선택합니다.
- 작업 화면의 오늘의 작업 제목과 중복 출고 일정 바로가기 카드를 제거합니다. 오늘 납기/다음 출고 필터는 유지합니다.
- 코스피·코스닥·비트코인·이더리움은 2×2 배열로, 환율은 별도 한 줄로 항상 표시합니다. 가로로 밀려 가려지지 않습니다. 기준시각 등 세부 정보 펼치기는 유지합니다.
- 새 디자인의 출고 일정은 본문 내 일반 화면입니다. 모달 backdrop·포커스 잠금 없이 앱 헤더와 하단 메뉴가 유지되며, 월/날짜 선택·미정·실시간 갱신·수주 열기를 기존 데이터와 연결합니다. 관리자도 동일하게 일반 일정 화면을 사용합니다. 특이사항 확인/검사 신청/사급품 안내는 기존의 팝업 동작을 유지합니다.
- 기기의 prefers-color-scheme에 맞춰 밝음/어두움 테마를 적용합니다. 전체 → 화면 밝기에서 기기 설정/밝게/어둡게를 직접 선택할 수도 있습니다. 버튼·텍스트·입력·날짜·달력·알림·팝업 색상을 함께 변경합니다. 브라우저의 자체 강제 색상 변환 엔진까지 제어하거나 실기기로 검증한 것은 아닙니다.

## 검증

실제 Go 렌더링과 합성 수주를 사용한 Chromium에서 320/390/1100px × light/dark의 6가지 조합을 확인했습니다. 카드별 담당자·사급품·특이사항 칸의 좌표와 높이 일치, 누락 항목 자리 유지, 버튼·날짜·주말 숫자 대비 4.5 이상, 시장 4종과 환율의 가림 없는 표시, 일반 일정 페이지와 하단 메뉴, 관리자 일정 진입, 이전 화면 복귀, 실제 신청 원본 폼의 전송 주소/종류, 입력 및 선택 보존, 테마 수동 전환을 검증했습니다. POST는 합성 HTTP503 캡처로 업무 자료에 쓰지 않았습니다. 실제 적용 이미지는 이 브라우저 검증 화면이며 AI 생성 시안이 아닙니다.

전체 Go race 검사, Linux/Windows vet, Windows GUI 교차 빌드 및 소스 ZIP 동일 재빌드 검증을 수행합니다. 별도 납기표 경로가 필요한 선택 시험 1건은 입력 경로 미지정으로 건너뛰었습니다. 회사 Windows 실행·삼성 인터넷 실기기·실제 회사 자료는 이 환경에서 확인하지 못했습니다.

## 업데이트

이전 프로그램을 트레이에서 완전히 종료하고 새 EXE를 실행한 뒤 휴대폰/PC 웹 화면을 새로고침합니다. 새 디자인이 바로 적용됩니다. 목소리·반복·기본 음성 ON·로그인·수주·검사 처리·설정 및 저장 위치는 유지합니다. 실제 신청/완료/반려/수정은 운영 자료에 반영됩니다. 원본 web 57개 파일과 이전 배포 ZIP은 보존합니다. 최신 Go 소스·추가 CSS/JS·이미지·검증 자료·전체 소스 ZIP·실행 ZIP을 GitHub 복구 브랜치에 함께 저장합니다.
