# v1.4.74 · 기존 업체 특이사항 메뉴를 원본 관리로 변경

관리자 앱 전체 메뉴의 업무 그룹에 있던 업체 특이사항 조회 항목을 업체 특이사항 관리로 바꾸고 /client-notes에 연결합니다. v1.4.73에서 관리 그룹에 별도로 추가했던 동일 관리 항목은 제거하여 한 곳만 표시합니다. 업체 원본 편집·저장·연결 수주 반영·권한은 기존 기능입니다. 일반 작업자 메뉴의 조회 기능은 변경하지 않습니다.

APK용 디자인 JS를 v1.4.74으로 버전 분리하고 이전 자산을 유지합니다. 회사 PC v1.4.74 업데이트로 반영하며 APK/알림 채널/로그인 유지/작업자 화면 전환과 회사 운영자료는 유지합니다.

검증: 임시 Go 서버/Chromium APK UA의 대표/개인 관리자 × 휴대폰/태블릿 4개 흐름에서 기존 업무 위치의 관리 메뉴 1개·이전 조회 이름 없음·원본 관리 연결을 확인하고 실제 원본 수정/저장/작업자 조회/연결 수주 반영을 확인합니다. 전체 Go 테스트, Linux/Windows vet, Windows GUI 교차 빌드, 원본 web 57개 해시·전체 소스 동일 Windows 재빌드·공개 다운로드 SHA-256을 확인합니다. Android 빌드/23 JUnit/서명·로그인/전환 race 근거는 변경하지 않은 v1.4.72 이력입니다.

실제 Android 기기 및 Windows 실행은 수행하지 않았습니다. 회사 자료/자격증명은 테스트나 공개 배포에 사용하지 않습니다.
