# 검사자 자동 기록과 기존 기록 보완 · PC v1.4.91

## 대표 관리자 이름

전체 → 관리자 계정 관리 → 계정 목록의 wssong 행에서 **이름 수정**을 열고 실제 이름을 저장합니다. 처음에는 기존 이름 ‘관리자’를 표시합니다. 로그인 아이디 wssong과 비밀번호는 그대로이며 이름 변경으로 다른 PC/휴대폰의 로그인 연결을 해제하지 않습니다. 대표 관리자 메뉴/앱 표시에도 저장한 이름을 사용합니다. 동료 계정은 등록된 이름을 사용합니다. 회사 사용자 이름을 개발 환경에서 임의로 정해 넣지 않습니다.

## 앞으로 완료하는 검사

작업자는 기존처럼 이름을 확인하고 검사 신청만 합니다. 관리자 완료 화면은 **검사 완료 시 기록될 검사자**로 현재 로그인 이름을 보여줍니다. 완료 버튼 POST 시 서버가 실제 인증 계정을 다시 확인해 이름·아이디·계정 ID와 시각을 스냅샷으로 저장합니다. 신청 작업자 이름과 검사자 이름은 별개입니다. 세팅/출하검사를 다른 관리자가 마치면 서로 다른 이름이 남으며 통합 승인/세팅만 승인도 실제 처리한 단계만 기록합니다. 이후 계정 이름 변경·사용 중지로 과거 기록 이름을 덮어쓰지 않습니다.

## 기존 검사자 직접 보완

대표 관리자만 계정 관리의 **기존 검사자 기록 보완**을 엽니다. 완료된 세팅/출하검사 중 이름이 미기록인 항목을 표시합니다. 동일 검사의 이벤트·현재 수주·보관 스냅샷을 중복 세지 않습니다. 검사 단계별 완료 정보가 없는 예전 자료의 단계나 날짜를 추정하지 않습니다.

실제 검사자 이름을 입력하고 **선택한 검사만** 또는 **미기록 전체**를 지정합니다. 검색어가 있으면 검색 조건에 해당하는 미기록 전체에 적용합니다. 세팅/출하 각각 1건으로 표시하며 표는 50건씩 보여줍니다. 전체 범위는 다른 페이지의 해당 항목도 포함하므로 표시된 총수를 확인합니다. ‘실제 검사자를 확인했다’에 체크하고 저장합니다. 다른 사람이 검사한 건이 섞여 있으면 실제 검사별로 선택해 보완하세요.

원래 검사 완료 날짜·작업자·수주 상태·최초 보관 날짜는 유지합니다. 검사자 이름과 **과거 기록 보완** 표시, 누가/언제/어떤 검사를 보완했는지를 내부 이력에 저장합니다. 내부 이력에는 보완 방식과 처리 주체/시각을 구분해 보존하며 일반 완료 카드에는 표시하지 않습니다. 이미 이름이 있는 기록은 이 화면에서 덮어쓰지 않으며 낡은 목록 제출은 거부합니다. 로그인하지 않은 작업자·구매 계정·동료 검사 관리자는 이 보완 화면을 사용할 수 없습니다. 실제 회사 자료의 일괄 보완은 관리자 본인이 화면에서 확인하고 눌렀을 때만 수행합니다.

## 어디에서 확인하나요

검사 완료 화면과 출하 기록 상세의 **검사 완료 기록**에서 세팅/출하 검사자·완료 일시를 각각 확인합니다. 화면에는 이름과 원래 완료 일시만 표시하고 보완 방식·보완 처리 시각/계정 안내는 숨깁니다. 수주별/월별 출하 상세 XLSX에도 같은 항목을 넣습니다. 사진·파일/영상 전달 방식은 유지합니다.

월별 검사 완료 엑셀은 기존 6개 열과 연결 원본 배치를 유지하고 **검사자 기록** 시트를 별도로 제공합니다. 이름/시간/자동·보완/보완 처리 계정을 확인할 수 있습니다. 같은 이름의 사용자 시트는 덮어쓰지 않고 다른 이름으로 만들며 이 프로그램의 고유 제목을 가진 시트만 갱신합니다. 기존에 내려받은 엑셀은 자동 변경되지 않으므로 다시 저장합니다.

## 검증

합성 계정으로 서로 다른 검사자 부분 승인·통합 승인·위조 이름 무시·수동 보완의 권한/CSRF·중복/이미 기록 보호·원래 날짜/보관일·대표 이름과 비밀번호/로그인 유지·기존 저장 형식 재실행·백업 복원·엑셀 문자열/검사자 표시를 검사합니다. Chromium PC/휴대폰 크기 및 APK 사용자 에이전트의 밝게/어둡게에서 실제 이름 수정·보완·검사 완료와 나가기 경고 부재를 확인했습니다. XLSX는 LibreOffice로 열어 배치도 확인합니다. 회사 운영 자료 변경·실제 Windows/Android 및 Microsoft Excel 기기 실행은 하지 않았습니다. 서버 PC만 업데이트하며 APK 1.0.11은 그대로 사용합니다.

신규 검사 완료 시각은 관리자가 완료 버튼을 눌러 서버가 승인 처리한 시각입니다. 신청 시각과 구분하며 세팅/출하를 따로 완료하면 각각의 실제 처리 시각, 통합 완료면 같은 처리 시각을 저장합니다. 완료된 요청의 재제출과 이름 보완으로 기존 완료 시각을 갱신하지 않습니다. PC 시간은 회사 PC 시계를 기준으로 하며 화면과 엑셀은 한국 시간으로 표시합니다.

PC 프로그램에서 관리자 화면을 다시 열 때 같은 유효 로컬 대표 세션은 유지합니다. 이미 오류 페이지에 머물러 있다면 업데이트 후 관리자 계정 관리에서 보완 화면을 다시 여세요. 저장되지 않은 오류 요청은 자동 재실행하지 않습니다.
