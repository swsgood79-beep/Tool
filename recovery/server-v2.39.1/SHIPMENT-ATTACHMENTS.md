# 출하 기록 · 파일과 동영상

PC v1.4.82부터 사용할 수 있습니다. 관리자 APK는 1.0.11 그대로 사용합니다.

## 휴대폰에서 등록

1. 휴대폰 카메라로 영상을 촬영합니다. 일반 MP4 촬영을 권장합니다.
2. 출하 기록에서 수주를 열고 **파일·동영상 → 촬영한 동영상 선택**에서 영상을 고릅니다. 파일 선택기는 휴대폰의 갤러리/파일 제공 앱을 사용합니다.
3. 파라미터는 **파라미터·파일 선택**에서 고릅니다. 전용 파라미터 확장자도 원본 그대로 저장합니다.
4. 사진 등록 전이라면 사진과 첨부를 모두 선택한 뒤 **사진 등록 후 완료·보관**을 누릅니다. 파일·영상을 먼저 저장하고 사진을 등록합니다. 파일·영상만 올렸다는 이유로 사진 필요 의무가 완료되지는 않습니다.
5. 이미 보관한 수주는 **파일·동영상 저장**으로 추가합니다. 기존 사진·보관 날짜·작업자·사급품 정보는 유지됩니다.

영상 준비와 전송 중 진행률을 표시합니다. 압축 중에는 앱을 화면에 둔 채 기다려 주세요. 홈으로 나가거나 화면을 꺼서 중단되면 원본은 유지되며 다시 저장할 수 있습니다. 완료된 첨부는 다시 보내지 않고 나머지부터 계속합니다. 취소 시 이미 저장한 첨부는 유지합니다. 압축 결과를 확인하지 못하면 오류를 표시합니다.

## 자동 압축과 형식

- 20MB 이하 영상은 그대로 사용합니다. 큰 영상은 긴 변 최대 1280px, 약 1.8Mbps 영상·128kbps 음성으로 업로드용 사본을 만듭니다. 가로·세로 방향과 소리를 유지합니다. 정확한 절약량은 영상 내용에 따라 다릅니다.
- 휴대폰 원본은 수정/삭제하지 않습니다. 파라미터 파일은 압축·변환하지 않습니다.
- 브라우저 지원에 따라 MP4를 우선하고 WebM으로도 저장합니다. 실제 파일명에 확장자를 표시합니다. 작은 원본이거나 압축 결과가 더 크면 원본을 사용합니다.
- 압축은 보통 영상 재생시간 정도가 필요하며 기기 성능에 따라 더 걸릴 수 있습니다. 지원되지 않는 코덱/브라우저는 오류를 표시합니다. 최신 Android Chrome 또는 Android WebView로 시도하거나 카메라의 일반 MP4 설정을 사용하세요.

## 나중에 찾기와 삭제

출하 기록에서 수주번호·프로젝트명으로 검색하여 상세 화면을 엽니다. 영상은 재생·일시정지·탐색할 수 있고 다운로드로 업체에 전달할 수 있습니다. 해당 기기가 원본 코덱을 재생하지 못하면 다운로드해 지원 플레이어에서 확인하세요. 파라미터는 원래 파일명과 내용으로 다운로드합니다.

작업자는 등록·조회·다운로드, 관리자는 개별 삭제까지 할 수 있습니다. 출하사진 재등록으로 되돌릴 때 파일·영상은 유지합니다. 전체 보관 기록을 완전히 삭제하거나 사진 대기 중 검사를 취소해 그 기록이 없어지면 해당 첨부도 정리됩니다.

## 용량·보관·백업

파일당 100MB, 동영상은 압축 후 300MB, 수주당 첨부 20개·총 1GB입니다. 기존 회사 PC 자료 저장 위치(D드라이브 설정 포함)에 보호 저장합니다. 자료 폴더나 보관 데이터를 GitHub의 공개 전체 소스에 포함하지 않습니다.

원격 암호화 백업에는 파일·영상도 포함합니다. **PC v1.4.88부터 전체 256MB 한도 대신 200MiB 조각 백업을 사용합니다.** 전체 조각이 검증되기 전에는 성공으로 등록하지 않고 직전 정상 백업을 유지합니다. 새 PC 복원은 v1.4.88 이상에서 모든 조각을 검증한 뒤 적용합니다. 실제 자동 백업은 설정을 켜야 실행됩니다. [분할 백업 안내](BACKUP-SETS.md)를 참고하세요. 자료 저장 위치의 전체 폴더 복사에도 파일·영상이 포함됩니다.
