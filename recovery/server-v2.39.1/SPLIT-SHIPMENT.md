# 분할 출고 · PC 1.4.105

## 엑셀 갱신으로 자동 구성

연결된 조립일정의 **같은 수주번호**에 서로 다른 유효한 발송예정일이 있으면 수주 카드 한 개 안에 차수별 출하검사를 만듭니다. 최초 구성은 날짜순입니다. 예를 들어 2026-11-30과 2026-12-02는 1차·2차가 됩니다. 같은 날짜가 여러 행/병합 셀에 반복돼도 한 차수로 묶습니다. 유효한 날짜가 세 개면 세 차수입니다. 미정/빈칸은 날짜로 생성하지 않으며 잘못된 날짜는 기존 일정을 유지하고 확인 대상으로 남깁니다. 한 칸의 여러 날짜는 연도까지 명시한 완전한 날짜를 쉼표·줄바꿈 등으로 구분한 경우만 읽습니다. 범위나 연도 없는 임의 문자열을 추측하지 않습니다.

출고일이 하나인 수주는 기존 검사 흐름을 유지합니다. 여러 날짜가 있는 수주만 **세팅검사 공통 1회 + 차수별 출하검사·사진**으로 표시합니다. 엑셀에 없는 출고 수량/로봇 배분은 추측해서 채우지 않습니다.

## 실제 사용 순서

1. 작업자가 기존처럼 세팅검사를 신청하고 관리자가 완료합니다. 분할 수주에서는 세팅·출하 통합 신청을 제공하지 않습니다.
2. 작업자가 수주 카드의 **검사 화면 열기**를 누릅니다. 세팅검사 아래에 날짜와 함께 **1차 출하검사 신청**, **2차 출하검사 신청**이 표시됩니다. 비고는 그 아래에 있습니다.
3. 준비된 차수의 작업자 이름을 입력하고 신청합니다. 같은 차수의 중복 신청이나 세팅검사 전 출하 신청은 서버가 차단합니다.
4. 관리자 검사 신청 목록/검사 상세에서 **1차 검사 완료**처럼 차수를 확인하고 실제 검사 후 완료합니다. 검사자 계정 이름과 완료 버튼을 누른 실제 서버 시간을 차수별로 기록합니다. 반려하면 그 차수만 다시 신청하며 공통 세팅이나 다른 차수는 유지합니다.
5. 작업자는 해당 차수의 **출하사진 등록**을 눌러 사진을 저장합니다. 기존 촬영·앨범 선택·사진 압축과 파일/영상 첨부 기능을 재사용합니다. 차수별 사진은 별도 저장합니다.
6. 1차 사진 저장 후에도 수주는 진행 목록에 남습니다. **다음 차수 신청하러 가기**를 눌러 돌아옵니다.
7. 모든 차수의 검사와 사진이 완료되면 전체 완료·보관됩니다. 최종 출하 기록 목록은 수주 한 건으로 표시하며 안에서 차수별 기록·검사자·완료시각·사진을 엽니다. 일부 차수만 처리한 기록은 ‘진행 중인 분할 출고 기록’에서 확인합니다.

예정일이 지났다는 이유로 검사나 출고를 자동 완료하지 않습니다. 사진 저장은 이 프로그램의 완료·보관 처리이며 실제 운송/ERP 출고 등록을 자동 실행하지 않습니다.

## 작업 도중 엑셀 일정이 바뀔 때

- 처음에는 날짜가 하나였다가 추가되면 같은 수주에 차수가 생성됩니다. 기존 신청/검사 완료가 있다면 첫 차수로 이어받고 기존 사진·신청 ID·검사자·완료시간을 유지합니다. 세팅검사는 다시 요구하지 않습니다.
- 신청 전 차수는 변경된 일정에 맞춰 날짜/최초 순서를 갱신할 수 있습니다. 바뀐 날짜의 이전 신청 토큰은 무효화하며 다른 차수의 정상 토큰은 유지합니다.
- 이미 신청된 차수의 ID와 번호는 바꾸지 않습니다. 새로운 날짜는 새 차수로 추가합니다. 완료한 검사를 초기화하거나 다른 차수로 옮기지 않습니다.
- 한 차수라도 신청한 뒤 일정이 줄어들면 기존 차수를 지우거나 수주를 자동 완료하지 않습니다. 제외된 일정에는 ‘현재 엑셀 일정에서 제외됨 · 기존 기록 유지’를 표시합니다.
- 엑셀에서 수주 전체가 없어져도 기존 수주·차수·기록을 유지합니다. 기존 수주번호 중복 등록은 하지 않습니다.
- 수주를 명시적으로 ‘검사 다시 열기’ 하면 새 검사 주기로 구성하고 과거 차수별 보관 자료는 이전 기록으로 보존합니다.

차수 일정은 연결된 엑셀에서 수정합니다. 관리자 수주 수정의 단일 날짜 입력으로 진행 중인 분할 출고 계획을 덮어쓰지 못하게 차단합니다. 출하 기록에서 보관 날짜를 별도로 정정하는 기존 기능은 유지됩니다.

## 달력·기록·엑셀·백업

수주 카드에는 날짜 목록과 분할 출고 표시, 검사 차수 진행 수가 나옵니다. 출고 달력에서는 해당 날짜마다 같은 수주와 차수별 상태가 표시됩니다. 오늘 납기/다음 출고 필터는 첫 날짜뿐 아니라 모든 날짜를 확인합니다. 기본 수주 목록의 카드를 복제하지 않습니다.

출하 기록에서 **이 수주 엑셀 저장**을 누르면 같은 분할 출고 그룹의 보관된 차수들을 한 XLSX 안에 차수별 상세 시트로 저장합니다. 날짜·검사자·사진이 섞이지 않도록 시트 제목/목차에도 차수를 표시합니다. 일반 전체 보관 내보내기의 월별 묶음은 유지합니다. 검사 완료 기록/CSV에도 1차·2차 구분을 남깁니다.

출하사진을 삭제·재등록하면 해당 차수만 사진 대기로 돌아가고 다른 차수의 검사·사진은 유지됩니다. 전체 완료 상태도 필요한 사진이 다시 등록될 때까지 해제됩니다. 검사 기록 자체를 삭제하지 않습니다.

차수·신청·검사자·사진 연결은 기존 운영 저장 파일 확장 상태와 백업에 포함됩니다. Windows 프로그램 종료·재시작, 백업 복원 후에도 유지됩니다. PC 1.4.105 업데이트가 필요하고 관리자 APK 1.0.11은 그대로 사용합니다.

## 검증

날짜 중복·병합 셀·두 달의 날짜, 일반 수주에서 진행 중/완료 후 분할 전환, 동시 차수 신청·반려·오래된 승인 거부, 세 번째 일정 추가, 일정 제외 후 기록 보존, 변경된 신청 화면 차단, 사진 삭제·재등록, 재시작·백업, 한 파일의 차수별 XLSX 출력을 합성 자료로 검증합니다. Chromium 360/390/430px 밝은 화면/어두운 화면과 실제 신청→승인→사진→최종 기록/달력 흐름을 시험합니다. 실제 회사 운영 데이터 변경이나 Windows/Android 실기기 실행은 하지 않았습니다.
