# ERP 수주별 검사성적서 목록 엑셀

대표 관리자 기본 화면→ERP 검사성적서 엑셀. 수주번호 입력→조회→엑셀 받기(.xlsx). 기존 ERP DB 자동연결 설치폴더를 재사용하고 없으면 자동찾기. 비밀번호 재입력 불필요. 필요할 때만 설치폴더 직접 지정. 기존 관리자 권한은 변경하지 않으며 현재 기능은 대표관리자 전용.

생산지시MST의 RCV_ORDNO를 수주번호와 정확히 비교하고 사업장/생산지시일/생산지시번호/SEQ로 HIS와 INSCER_MST를 연결합니다. 수주헤더는 사업장/수주일/수주번호로 연결합니다. 최초 제공받은 스키마를 기준으로 작성했으며 실제 ERP 메뉴와 수주별 행 수/품번/시리얼 대조는 현장 확인 대상입니다. 검사일 제한 없음, 사업장전체, 성적서 미등록 생산지시도 구분 표시합니다. 검사 측정값/인쇄 원본 양식은 포함하지 않습니다. 판정코드는 의미를 임의 변환하지 않습니다.

읽기전용 parameterized SELECT 최대5000행. 초과/조회실패/중복키/수주불일치는 다운로드 금지.10분간 해당 조회token의 메모리snapshot만 내보냅니다. 새 조회 시 이전 결과를 재사용하지 않습니다. 재시작 시 조회캐시 소멸. 업무State/출하/검사/작업자료와 기존 엑셀에는 결과를 추가하지 않습니다. 실제 ERP Excel/DB결과/다운로드는 공개GitHub에 업로드하지 않습니다.

문자열 셀로 품번/시리얼 앞0 보존, 수식 실행 방지. 조회정보시트에 수주번호/조회시각(KST)/조건을 저장합니다. 데이터는 회사PC에서 조회하고 사용자 직접XLSX다운로드만 제공합니다.
