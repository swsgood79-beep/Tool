# PC 1.4.113 추가 안내

자동 연결은 [ERP DB 자동 연결](ERP-DB-AUTO.md)을 사용합니다. 발주 미리보기 결과에는 원본 가공의뢰 키로 연결한 로봇품번과 일치 건수도 포함됩니다. 미리보기 자체는 작업 목록을 변경하지 않습니다.

# DB 발주 미리보기 · PC 1.4.112

DB 연결·구조 확인에 성공한 뒤 실제 발주 항목의 필드 연결을 검증하는 기능입니다. ERP 화면을 조작하지 않으며 작업 목록에 자동 반영하지 않습니다. 기존 작업 기록·완료·입고 확인 상태를 변경하지 않습니다.

대표 관리자 → 가공 작업 · 입고 확인 → ERP 자동 연결 → **DB 발주 미리보기 · 검증용**에서 ERP 엑셀과 같은 입고예정일 범위를 지정하고 **DB 발주 미리보기**를 누릅니다. 폴더는 기존 DB 연결 확인과 같이 자동 찾기를 우선 사용합니다. 완료 후 같은 **진단 결과 받기**로 ERP-db-check.json을 받습니다.

미리보기는 가공사업부 거래처 코드로 제한합니다. 발주번호·순번·수주번호·프로젝트·품번 후보·품명·예정일·수량·입고수·입고 상태와 품번 연결에 필요한 항목만 읽습니다. 금액·직원·연락처 열은 읽지 않습니다. 결과 파일에는 실제 발주 항목이 들어 있으므로 업무 자료로 관리합니다. 외부에 자동 업로드하지 않으며 계정·비밀번호·INI 원문은 포함하지 않습니다.

최대 370일 범위와 2,000행으로 제한하고 SQL 날짜·거래처는 파라미터로 전달합니다. 읽기 SELECT만 실행합니다. 현재 후보 조회는 PURORD_MST/PURORD_HIS를 전체 기본 키로 연결하고 ITMMST_INFO도 품번·부품구분 복합 키로 연결합니다. 예정일은 현재 SCH_DATE 후보 기준입니다. 로봇품번·BASE 품번과 미입고 수량이 ERP 보고서와 정확히 일치하는지는 검증 전입니다. 아직 BASE만 확정해 가져오는 운영용 자동 조회가 아닙니다.

원본 행 순번을 유지하며 같은 품번의 실제 여러 발주 행을 제거하거나 합산하지 않습니다. ERP 기준 엑셀과 비교한 뒤 필요한 판별·수량·조인 규칙을 확정합니다. 엑셀의 BASE 필터 및 발주/수주/품번별 합산은 기존 작업 목록 반영 규칙을 따릅니다. 검증되기 전에는 이 결과를 업무 목록으로 저장하지 않습니다.

이 기능의 성공은 SQL 실행과 미리보기 반환 성공을 뜻하며 ERP 보고서와의 일치나 DB 자동 수집 전환 완료를 뜻하지 않습니다. Windows/회사 DB에서 실제 업무 조회는 현장 확인 전입니다. 테스트 화면은 가상 발주 자료입니다. 실제 자료와 결과 파일은 공개 GitHub에 넣지 않습니다.
