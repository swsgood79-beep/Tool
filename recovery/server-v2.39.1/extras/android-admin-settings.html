Firebase 프로젝트를 처음 한 번 준비한 뒤 아래 두 파일을 등록하세요. 비밀키는 회사 PC의 보호된 자료 폴더에 저장하며 화면이나 APK에 표시하지 않습니다.

  1. Firebase 콘솔에서 프로젝트를 만듭니다. 알림용 FCM은 무료 서비스입니다.
  2. Android 앱 추가 → 패키지명 {{.Package}} → google-services.json을 내려받습니다.
  3. 프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성으로 서비스 계정 JSON을 내려받습니다.
  4. 아래에 두 파일을 등록한 뒤 관리자 APK에 로그인하고 알림을 허용합니다.
