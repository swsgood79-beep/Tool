# 출하 기록 엑셀 저장

PC v1.4.83부터 사용할 수 있습니다. 관리자 앱 APK는 1.0.11 그대로 사용합니다. 구매팀 전용 계정과 작업자 화면에는 이 내보내기 기능을 제공하지 않습니다.

## 전체 보관용

1. 관리자 화면에서 **출하 기록 → 보관 완료**로 이동합니다.
2. **전체 보관 엑셀 저장**을 누릅니다. 검색/기간 조건과 별개로 보관 완료된 전체 기록을 대상으로 합니다. 사진 필요 목록의 미완료 기록은 포함하지 않습니다.
3. 준비 진행률 후 ZIP 다운로드를 요청합니다. 시작되지 않으면 **준비된 파일 다운로드**를 누릅니다.
4. ZIP을 **전체 압축 해제**한 뒤 `출하목록.xlsx`를 엽니다.
5. 목록의 검색/필터 및 **상세 보기**로 해당 월별 파일의 수주 상세를 엽니다. 상세 시트의 **전체 목록으로**로 돌아옵니다.

월은 **보관 날짜의 한국 시간** 기준입니다. 같은 달도 수주 40건 또는 엑셀용 사진 합계 약 24MiB를 기준으로 파일을 더 나눕니다. 파일명은 `2026-11_출하상세_01.xlsx` 같은 형식입니다. 모든 엑셀을 같은 폴더에 두고 이름을 유지해야 파일 간 링크가 이어집니다. PC용 Excel 사용을 권장하며 외부 파일 열기 확인 여부는 Excel 설정에 따릅니다.

## 고객사에 한 수주만 전달

해당 보관 기록의 상세 화면에서 **이 수주 엑셀 저장**을 누릅니다. 해당 수주의 상세와 사진만 담은 XLSX 한 파일입니다. 다른 고객사나 다른 수주 시트는 들어가지 않습니다. 엑셀은 해당 상세 시트부터 열립니다. 이 파일 하나만 전달해도 수주 정보와 포함된 사진을 확인할 수 있습니다.

## 포함하는 내용

- 수주번호·프로젝트명·고객사·출고 예정일·검사 완료일·보관 완료일
- 설계담당자 이름·세팅 작업자와 완료 날짜·출하 작업자와 완료 날짜
- 사급품 상태와 종류·제조사·품번·수량의 수령내역
- 업체 특이사항·수주별 추가 메모·출하 메모
- 출하사진과 특이사항 사진: 긴 변 최대 960px의 JPEG 미리보기로 엑셀 안에 포함합니다. 원본 사진은 변경하지 않습니다. 사진의 내용에 따라 압축률은 다릅니다.
- 파일·동영상의 이름·종류·용량과 **원본 별도 전달** 안내

**파일·동영상 원본은 엑셀과 ZIP에 넣지 않습니다.** 필요한 경우 기존 출하 기록에서 내려받아 엑셀과 별도로 고객사에 전달합니다. 사진 설명을 자동 추측하지 않고 사진 번호와 기존 파일명만 표시합니다.

사진을 읽지 못한 경우 그 자리에 확인 안내를 넣고 **내보내기 확인** 시트에도 수주/사진 이름을 표시합니다. 준비 완료 메시지의 사진 확인 필요 건수를 확인하세요.

## 기본 정보와 상세 배치 · PC 1.4.84

기본 정보는 왼쪽, 설계담당자·세팅 작업자·출하 작업자는 오른쪽 같은 폭의 세 열로 표시합니다. 사급품 표와 특이사항/메모 아래에 사진을 두 장씩 배치합니다. 기본 정보 셀은 실제 날짜/문자열로 저장하며 테두리와 줄 높이를 맞춥니다.

고객사와 출고 예정일은 보관된 값을 우선합니다. 빈 항목에 한해 현재 수주의 ID·수주번호·출하검사 이벤트와 완료시각이 모두 같을 때만 현재 연결된 업체 원본의 업체명 및 출고 예정일을 보완합니다. 기존 날짜를 최신 일정으로 덮어쓰지 않습니다. 원자료가 없으면 **미등록**으로 표시합니다. 프로젝트명에서 고객사를 추측하지 않습니다. 보완한 항목 및 원자료 미등록 항목은 상세 하단에 표시하며 준비 완료 메시지에도 기본 정보 확인 필요 건수가 표시됩니다.

처음 사진을 저장해 보관 완료로 전환할 때에도 같은 기준으로 확인되는 빈 기본 정보를 함께 저장합니다. 기존 보관 자료의 내보내기는 읽기 전용이며 보관값을 수정하지 않습니다. 이미 내려받은 엑셀은 자동으로 바뀌지 않습니다. **PC 1.4.84로 업데이트한 뒤 다시 엑셀 저장**을 누르세요.

## 준비와 다운로드

내보내기 시작 시점의 자료를 사용합니다. 준비 중에 수주나 사진이 변경돼도 해당 내보내기는 시작 시점의 사진을 보존해 만듭니다. 파일 준비와 전송은 검사 신청·알림 처리를 막지 않도록 분리합니다.

준비 작업은 한 번에 하나이며 완료된 임시 다운로드는 최대 3개, 약 2시간 보관합니다. 진행 중인 다운로드는 만료로 지우지 않습니다. 다운로드가 너무 늦거나 만료되면 다시 내보내기 하세요. 프로그램을 종료/업데이트하면 준비 중인 작업은 다시 시작해야 할 수 있습니다. 앱을 재설치하거나 로그인 설정을 바꿀 필요는 없습니다.

이 기능은 사진이 포함된 업무용 엑셀 사본을 만드는 기능입니다. 파라미터·동영상·로그인 설정 전체를 복원하는 백업과는 별개입니다. 기존 파일·영상 보관과 원격 백업 상한은 변경하지 않습니다.

임시 서버·Chromium PC/휴대폰 크기 다운로드·OOXML·LibreOffice 열기/인쇄 너비를 검증했습니다. Windows 실행 및 실제 Microsoft Excel·삼성 휴대폰 실행은 이 작업환경에서 하지 못했습니다.
