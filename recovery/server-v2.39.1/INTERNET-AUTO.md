# 실행 시 인터넷 자동 연결 · PC v1.4.89

프로그램 실행과 PC 업데이트 재시작마다 저장된 인터넷 연결 설정을 사용해 자동 연결을 시작합니다. 회사 PC의 실제 인터넷이 준비되어야 외부 연결이 완료되며 처음 실패해도 백그라운드에서 다시 시도합니다. 고정 QR, 수주 자료, 자료 저장 위치, GitHub 연결키는 바꾸지 않습니다.

PC 창의 연결됨 표시와 외부 접속 연결됨 상태가 완료를 뜻합니다. 단순히 창이 열렸거나 주소 문자열이 남아 있다는 것만으로 성공 표시하지 않습니다. 연결이 준비되지 않거나 주소 검증/게시가 실패하면 약 5~60초 지연 뒤 다시 시도합니다. 확인 주기 때문에 최대 약 5초 정도 더 걸릴 수 있습니다. 준비 단계가 2분을 넘으면 기존 시도를 취소하고 새 시도를 준비합니다. 외부 도구/인터넷/권한/연결키의 실제 문제가 있으면 자동 시도로 해결되지 않을 수 있으므로 상태 문구를 확인합니다. 연결키가 없는 고정 QR 설정은 안내 후 설정을 기다립니다.

인터넷 끊기를 직접 누르면 이번 실행 중에는 연결을 멈추고 자동 재연결하지 않습니다. 인터넷 연결 버튼을 누르면 재개합니다. 다음에 프로그램을 켜거나 업데이트 재시작하면 자동 연결이 다시 활성화됩니다. 프로세스를 중복 실행하지 않으며 종료 context가 기존 연결에 전달됩니다. 테스트 전용 모드에서는 외부 연결을 시작하지 않습니다.

새 PC 백업 복원 중에는 연결을 잠시 보류하고 이전 터널이 종료될 때까지 최대 30초 기다립니다. 종료가 확인되지 않으면 복원을 적용하지 않고 재시도 안내를 표시합니다. 복원이 끝나면 복원된 연결 설정으로 다시 연결할 수 있습니다. 테스트 환경의 모의 연결/race와 기존 복원 시험으로 확인했으며 실제 회사 네트워크/Cloudflare 터널과 Windows GUI 실행은 이 작업환경에서 수행하지 않았습니다.
