# 알파작업완료확인 v1.4.47 · 복구 운영판

**v1.4.47 토크 읽음 기록 유지:** 읽음 기록을 기기별 비밀 식별값으로 회사 프로그램에도 보관합니다. 공개 접속 주소가 바뀌면 고정 연결 페이지를 잠시 거쳐 같은 브라우저의 읽음 기록을 이어받으며 다른 브라우저의 기록과 섞지 않습니다. 새 글은 계속 새 글로 표시합니다. 기존 주소에서 남아 있는 로컬 읽음 기록은 합치지만 이미 주소 변경으로 잃은 기록은 복원할 수 없습니다. 이번 버전부터 저장되는 기록을 유지하며 브라우저 데이터 삭제·시크릿 모드는 별도입니다.

**v1.4.46 토크 공유 시 나가기 경고 수정:** 토크 글쓰기에서 사진을 첨부하고 공유하기를 누를 때 자동 재접속의 미저장 글 보호가 정상 업로드를 막던 문제를 수정했습니다. 정상 공유·수정 저장은 경고 없이 기존 방식대로 업로드하고 목록으로 이동합니다. 필수 항목 누락·사진 조건 오류로 제출이 취소된 경우와 글을 쓰다가 다른 화면으로 나가는 경우에는 보호 경고를 유지합니다.

**v1.4.45 공용 PC 긴급공지 기본 수신:** PC 작업자 화면은 긴급공지 음성 수신을 기본으로 켭니다. 처음 접속하거나 업데이트로 주소가 달라져도 별도로 체크할 필요가 없습니다. 사용자가 명시적으로 수신을 끈 경우에는 해당 브라우저 주소에서 꺼짐을 유지합니다. 휴대폰은 계속 방송 대상에서 제외하며 기존 음성 알림 켜기/끄기와 브라우저 소리 허용 정책을 따릅니다.

**v1.4.44 긴급공지 음성 방송:** 관리자 공지사항 관리의 게시 중인 긴급공지에 ‘음성 방송’ 버튼을 추가했습니다. 수신을 선택한 공용 PC 작업자 화면에서 ‘긴급 공지입니다’와 제목·내용을 선택된 AI 음성으로 읽습니다. 공용 PC 작업자 화면 → 전체 → 음성 알림 켜짐 상태에서 ‘이 공용 PC에서 긴급공지 음성 수신’을 선택하세요. 휴대폰은 수신 대상에서 제외합니다. 공지 등록·수정만으로 자동 방송하지 않으며 다시 방송을 눌러 재생할 수 있습니다. 접수 결과는 실제 스피커 재생 확인과 구분하여 표시합니다.

**v1.4.43 사급품 수령 상세 표:** ‘사급품 수령’ 버튼을 누르면 연결된 납기표의 ‘사급품 수령 내역’ 시트에서 같은 수주번호의 종류·제조사·품번·수량을 표로 표시합니다. 기존 납기표 자동 조회가 켜져 있으면 5분 간격으로 함께 갱신합니다. 항목이 많으면 제목·닫기 버튼을 고정하고 표 내부만 스크롤합니다. 관리자·작업자·특이사항·출고일정에 공통 적용하며 기존 엑셀 사급품 색상과 다른 사급 상태 안내는 유지합니다. 설치 후 첫 납기표 조회가 완료되면 상세가 표시됩니다.

**v1.4.42 업데이트 후 자동 재접속:** 열린 작업자 화면이 서버 재시작·주소 변경을 감지하면 최신 주소로 자동 연결합니다. 이전 주소에서 새로고침해도 복구하며 연결 대기 중에는 20초마다 다시 확인합니다. 검사창이나 작성 중인 글은 자동 이동하지 않고 새 탭 연결을 안내합니다. **이번 버전 설치 후 공용 PC마다 저장된 북마크로 한 번 접속해야 자동 복구 기능이 설치됩니다.** 이후 업데이트부터 적용됩니다. 보안 브라우저의 Service Worker 지원이 필요하며 회사 PC와 프로그램은 켜져 있어야 합니다. 수주·검사·저장 위치는 변경하지 않았습니다.

**v1.4.41 검사 화면 버튼으로만 열기:** 작업자 수주 카드와 출고일정 카드의 배경·제목·상태를 눌러서는 검사 화면이 열리지 않고 ‘검사 화면 열기’ 버튼으로만 열립니다. 버튼의 Enter/Space 조작과 특이사항 확인·일정 복귀는 유지합니다. 긴 ‘02 출하검사 확인 대기’ 표시도 새 디자인에서 폭 제한을 풀어 한 줄로 표시합니다. 수주/검사 저장 및 신청·승인·반려, 전화·사급품·특이사항 동작은 그대로입니다.

**v1.4.40 댓글 삭제·토크 아이콘:** 휴대폰의 이름·댓글·등록 입력란을 한 줄로 배치하고 댓글 삭제 버튼을 오른쪽 끝으로 정렬했습니다. 하단 토크 아이콘을 둥근 말풍선 두 개가 겹친 모양으로 바꿨습니다. 삭제 권한·동작, 안 읽은 글 배지, 게시판과 수주 기능 및 저장 위치는 그대로입니다.

**v1.4.39 토크 게시판·안 읽은 글 숫자:** 작업 공유 메뉴 이름을 토크로 변경하고 승인한 썸네일·분류·제목·댓글 수·작성자·시간의 게시판 목록과 제목/메타/본문/사진/좋아요/이전·목록·다음/댓글 상세 배치를 적용했습니다. 작업자 하단 토크에는 해당 브라우저가 열어보지 않은 전체 분류의 글 수를 주황색 배지로 표시합니다. 상세를 열면 읽음으로 기억하며 본인 글은 제외합니다. 새 글은 15초 간격으로 확인하고 0개면 숨깁니다. 기존 수주·공지·D드라이브 저장 설정은 유지합니다.

**v1.4.38 작업 공유·자료 저장 위치:** 작업자 하단에 업체 특이사항 → 작업 공유 → 전체 순서로 메뉴를 추가했습니다. 전체·작업안내·건의사항·일상생활 피드에서 이름·글·사진을 올리고 댓글·좋아요로 소통할 수 있습니다. 사진은 최대 5장/각 8MB, 긴 변 1,600px 이내 JPEG로 줄여 저장합니다. 관리자 전체 → 자료 저장 위치에서 D:\AlphaWorkCompleteData 같은 새 폴더를 예약하면 다음 실행 시 운영 자료 전체를 복사·검증한 뒤 새 경로로 전환합니다. 기존 C 복사본은 보존되며 정상 확인 후 별도로 정리해야 C 여유 공간이 늘어납니다.

**v1.4.37 일반 공지 보라색 디자인:** 일반 공지 카드에 보라색 테두리·왼쪽 강조선·연한 보라 배경·흰 글자 배지를 적용했습니다. 다크모드에서는 어두운 보라 바탕과 밝은 보라 테두리/링크로 표시합니다. 긴급 공지의 빨간 테두리와 공지 등록·사진·게시 방식, 기존 수주·검사 기능은 유지합니다.

**v1.4.36 공지사항·사진 첨부:** 관리자 전체 메뉴 → 공지사항 관리에서 일반/긴급 공지와 사진(최대 5장, 각 8MB)을 등록·수정·게시 종료할 수 있습니다. 작업자 화면의 시장정보 아래·검색창 위에 상단 공지가 표시되고 전체 공지 목록·상세·사진 확대를 지원합니다. 긴급 공지가 먼저 표시되며 상단에는 최대 3건, 나머지는 전체 공지에서 볼 수 있습니다. 열린 작업 화면은 15초 간격으로 공지 변경을 확인합니다. 공지가 없으면 해당 영역을 숨깁니다. 공지는 재실행 후 보존되며 기존 암호화 백업에도 사진과 함께 포함됩니다. 수주·검사·오늘 납기·알림 동작은 유지합니다.

**v1.4.35 작업자 오늘 납기 완료 포함:** 작업 메뉴의 오늘 납기 건수·목록에 검사 완료 수주도 포함합니다. 오늘보다 먼저 검사를 마쳤더라도 출고 예정일이 오늘이면 출고일정과 동일하게 표시하며 완료 카드는 녹색입니다. 검사 승인 후 자동 갱신과 납기 변경도 반영됩니다. 일반 전체·세팅·출하, 금일 검사 완료, 다음 출고 및 관리자 필터는 기존 기준을 유지합니다.

**v1.4.34 승인한 수주 카드 디자인 적용:** 관리자·작업자 수주목록, 금일 검사 완료, 출고일정의 수주 카드를 흰 바탕·진한 회색 테두리로 통일했습니다. 번호/출고일/단계는 상단, 프로젝트명은 그 아래, 담당자는 회색 사람 아이콘 버튼, 특이사항은 빨간 버튼, 기존 검사 열기는 오른쪽 아래 파란 버튼으로 배치했습니다. 사급품은 엑셀 원본 셀 색상을 그대로 사용합니다. 완료 녹색과 기존 전화 연결·검사·수정·숨김·삭제·일정 복귀 동작은 유지하며 데이터 스키마와 업무 처리 방식은 변경하지 않았습니다.

**v1.4.33 출고일정 검사창 복귀 수정:** 출고일정에서 검사 화면을 열었다가 닫기·ESC·특이사항 확인 취소를 하면 원래 달·선택 날짜·미정 보기·스크롤로 돌아옵니다. 완료 갱신으로 검사창이 사라져도 출고일정을 유지합니다. 작업 메뉴에서 직접 연 창은 기존대로 작업 메뉴에 남으며, 일정·검사 처리 방식과 카드 디자인은 변경하지 않았습니다.

**v1.4.32 출고일정 목록의 겹친 프레임 정리:** 출고일정의 바깥 박스와 날짜별 목록의 회색 박스·테두리·안쪽 여백을 제거했습니다. 날짜와 건수는 카드 위 한 줄로 표시하고, 수주목록을 본문 전체 폭에 펼쳐 작업 메뉴와 카드 폭·시작선·간격을 맞췄습니다. 달력 날짜 칸의 구분선과 기존 카드/완료 녹색은 유지합니다.

**v1.4.31 작업·출고일정 카드 디자인 통일:** 승인한 시장정보 느낌의 진한 남색 제목 영역을 작업 메뉴 수주 카드에 적용하고, 출고일정도 같은 카드 배치로 맞췄습니다. 수주번호·프로젝트명·검사 단계, 담당자/사급품/특이사항 3칸, 출고일/작업 열기 위치를 통일했습니다. 완료 녹색과 작업자, 기존 일정·검사 처리 방식은 유지합니다.

**v1.4.30 특이사항 화면 배치 적용:** 관리자·작업자 특이사항 화면에서 출고 예정일을 단독 줄에 놓고, 다음 줄에 수주목록과 같은 파란 ‘☎ 담당자 이름’ 버튼과 사급품 버튼을 24px 간격으로 배치했습니다. 출고일과 담당자 버튼의 왼쪽 시작선을 맞췄고, 담당자를 누르면 등록된 번호로 전화 앱이 열립니다. 전화번호·‘설계담당자’ 접두어는 버튼 문구에서 제외했습니다.

**v1.4.29 담당자 전화 연결 수정:** 관리자 수주목록의 담당자를 전화 링크로 연결하고, 작업자·상세 화면의 tel 주소가 잘못 출력되던 공통 오류를 수정했습니다. 기존/새 디자인 기능 비교 결과는 audit/DESIGN-PARITY-V1.4.29.md에 기록했습니다. 전화 연결 외 업무 흐름과 레이아웃은 변경하지 않았습니다.

**v1.4.28 캘린더 미정 집계 수정:** 출고일도 없고 납기표에도 연결되지 않은 자료를 캘린더·미정 건수에서 제외합니다. 납기표에 남은 검사 완료 수주는 해당 출고일에 녹색으로 표시하고, 납기표에서 빠진 수주는 일정에서 제외하는 기존 방식은 유지합니다.

**v1.4.27 검사 완료와 출고 일정 분리:** 세팅·출하검사를 모두 완료해도 출고 캘린더의 예정일·건수·목록에 계속 표시합니다. 완료 수주는 녹색 카드와 ‘✓ 검사 완료’, 세팅·출하 작업자로 구분합니다. 일반 수주목록 필터는 그대로 유지합니다.

**v1.4.26 시장정보·캘린더 구분 개선:** 작업자 시장정보 왼쪽 위에 ‘시장정보’를 표시하고 기존 남색 배경·흰색 가격·코랄 상승·하늘색 하락을 적용했습니다. 시장 4종과 환율은 한 화면에 유지합니다. 관리자·작업자 출고 캘린더에 날짜 구분선과 출고일 연한 파랑·선택일 진한 파랑·오늘 노랑을 적용했습니다.

이전 기능 안내와 검증은 audit/RECOVERY-V1.3-TEST.md 및 audit/RECOVERY-V1.3.1-TEST.md, 이번 통합 실행 변경은 audit/RECOVERY-V1.4.1.md, 운영 모드 검증은 audit/RECOVERY-V1.4.md와 build-manifest-v1.4.5.json을 참고하세요. 과거 보고서는 당시 상태로 보존했습니다. 원본 웹 자산 57개는 기존 SHA-256 그대로 유지합니다.

남은 제한: Windows GUI/DPAPI·회사 실제 자료/계정·삼성 인터넷의 실제 수신/지문은 개발 환경에서 미검증입니다. ngrok 실행·원본과 같은 사진 자동 청소·256MB 초과 백업·원본과 픽셀/소리/애니메이션까지 같은 동작은 구현/검증하지 않았습니다. 엑셀 원본에 대한 자동 양방향 동기화 대신 업로드 사본에 병합합니다.

Go 1.27.3 이상에서 build-windows.ps1 또는 다음 명령으로 빌드합니다.

```powershell
$env:GOOS='windows'; $env:GOARCH='amd64'; $env:CGO_ENABLED='0'
go build -trimpath -buildvcs=false -ldflags='-s -w -H=windowsgui' -o AlphaWorkComplete-Recovered.exe .
```

Linux는 암호화 없는 검증용입니다. --headless --no-browser로 시험할 수 있지만 실제 회사 자료 운영은 Windows 현재 계정의 DPAPI를 전제로 합니다.
