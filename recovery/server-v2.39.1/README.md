# 알파작업완료확인 v1.4.26 · 복구 운영판

**v1.4.26 시장정보·캘린더 구분 개선:** 작업자 시장정보 왼쪽 위에 ‘시장정보’를 표시하고 기존 남색 배경·흰색 가격·코랄 상승·하늘색 하락을 적용했습니다. 시장 4종과 환율은 한 화면에 유지합니다. 관리자·작업자 출고 캘린더에 날짜 구분선과 출고일 연한 파랑·선택일 진한 파랑·오늘 노랑을 적용했습니다.

**v1.4.25 최근 기록에서 반려 제외:** 관리자 하단 최근 기록·건수·검색·필터에서 반려 기록을 제외합니다. CSV는 기존처럼 정상 검사 완료 기록만 내보냅니다. 반려 상태·재신청 기능과 기존 저장 자료는 유지합니다.

**v1.4.24 관리자 메뉴 통합:** 홈은 기존 관리 도구 화면(QR·엑셀·수주 등록/목록·최근 기록)으로 열립니다. 이전 홈의 검사 요약·출고 일정 바로가기·신청 목록은 하단 검사 메뉴에 통합했습니다. 기존 검사 알림 주소도 통합 화면을 사용합니다. 작업자 화면은 변경하지 않았습니다.

**v1.4.23 새 디자인 정식 기본 적용:** 별도 미리보기 클릭 없이 새 화면으로 열립니다. 수주 카드의 담당자·사급품·특이사항을 3칸으로 고정하고, 담당자와 출고 예정일에 색상을 적용했습니다. 오늘의 작업 제목과 작업 화면의 중복 일정 버튼을 제거했으며, 시장 4종과 환율을 모두 표시합니다. 하단 출고 일정은 팝업이 아닌 일반 화면입니다. 기기 다크모드에 자동 대응하고 전체 메뉴에서 기기 설정/밝게/어둡게를 선택할 수 있습니다. 이전 화면 선택은 전체 메뉴의 화면 설정에 남겨 두었습니다.

**v1.4.22 음성 기본 켜짐:** 관리자·작업자 브라우저 화면의 음성 알림이 기본 ON으로 시작합니다. 자동 재생이 막히면 ON 상태로 대기하다 화면을 한 번 터치할 때 소리를 활성화합니다. 사용자가 브라우저에서 직접 끄면 그 선택을 기억합니다. 새로고침할 때 과거 알림이나 테스트 문장을 자동으로 읽지 않습니다. PC 프로그램이 이미 재생을 맡고 있으면 중복 재생하지 않습니다.

**v1.4.21 새 모바일 디자인 미리보기:** 기본은 기존 화면입니다. 화면 상단의 **새 디자인 미리보기**를 누르면 밝은 카드·하단 메뉴 방식으로 전환합니다. 관리자 홈/수주/검사/전체 메뉴, 작업자 목록/검사 신청/출고 일정/업체 특이사항을 새 디자인으로 볼 수 있습니다. 상단 **기존 화면**으로 즉시 되돌릴 수 있습니다. 각 브라우저에만 저장하며 회사 수주 자료·로그인·검사 승인 방식은 변경하지 않습니다.

**v1.4.20 수정:** 회사 PC 음성 설정에서 ON을 저장하면 PC 프로그램으로 재생을 전환합니다. 이미 열려 있는 브라우저의 자동 갱신이 재생을 다시 가져가지 않으며, 테스트 요청 오류가 상태 갱신에 가려지지 않습니다. 구글·선희·인준은 인터넷이 필요하며 실패 시 선택 음성을 유지하고 오류를 표시합니다.

**v1.4.19 변경:** 작업자가 특이사항이 있는 수주를 열면 글·추가 메모·첨부 사진을 먼저 보여줍니다. 확인 체크 후 검사 화면으로 진행합니다. 목록과 캘린더 모두 적용하며 특이사항이 없으면 바로 열립니다. 기존 프로그램을 트레이에서 종료한 뒤 새 EXE를 실행하고, 열려 있는 작업자 화면은 새로고침하세요.

**v1.4.18 변경:** 현재 목소리·읽는 문장은 유지하고 알림 효과음을 음성 생성보다 먼저 재생합니다. 음성 준비와 띵똥을 병행해 추가 대기를 줄였으며, 음성이 켜진 브라우저의 내부 신청 확인 주기는 0.5초입니다. ‘음성 설정·테스트 → 반복 말하기’에서 1회/2회를 선택해 저장합니다. 기본1회이며 2회는 한 번 만든 음성을 이어 읽습니다.

서버 PC의 프로그램을 완전히 종료하고 새 EXE를 실행한 뒤 관리자/공용 화면도 새로고침하세요. 브라우저 음성을 쓰면 해당 화면의 음성 알림을 다시 켭니다. 음성 자체는 인터넷·제공사 준비 시간이 남을 수 있습니다.

**v1.4.17 음성 설정·테스트:** 프로그램 창의 ‘음성 설정·테스트’를 누르면 설정 화면이 열립니다. 음성 알림 체크박스, 구글 전자녀/gTTS·MS 선희·MS 인준·윈도우 기본 내장 선택, 0.80~1.50배속(0.05 간격), 테스트 재생을 제공합니다. 설정이 없을 때는 ON·gTTS·1.10배속이며 기존 OFF 설정은 유지합니다. 선택은 운영 자료 폴더의 tts_config.json에 자동 저장됩니다.

테스트 문장은 “아리아니 공구14님이 테스트 완료”이며 선택한 엔진과 배속으로 서버 PC에서 재생합니다. 실제 검사 완료 알림을 새로 만드는 기능은 아닙니다. 다른 엔진으로 자동 대체하지 않고 엔진 이름·HTTP/COM 오류를 상태창에 표시합니다. 배포 EXE에 모든 라이브러리가 포함되어 별도 pip 설치가 필요 없습니다.

v1.4.16에서 gTTS를 도입했고 v1.4.17부터 gTTS·선희·인준·SAPI를 선택할 수 있습니다. EXE에 공식 Python x64 런타임과 gTTS/pygame을 포함해 별도 Python 설치 없이 실행합니다. 관리자/공용 PC/휴대폰은 서버가 만든 MP3를 받아 같은 Google 한국어 합성 음성을 사용합니다. 인터넷 연결이 필요하며 크롬 내장 Google 음성과 완전히 같다고 보장하지 않습니다.

브라우저는 MP3 playbackRate=1.1과 preservesPitch로, PC 직접 음성은 pygame 26400Hz 출력에 별도 WSOLA 1.1배 시간 조정으로 재생합니다. 출력 주파수만 바꿔 배속이 된다고 처리하지 않습니다. MP3는 임시 생성 후 재생/전달 완료 또는 오류 시 삭제합니다. FIFO·끄기·미리듣기·실패 후 다음 알림 처리를 유지합니다.

아래 v1.4.14~15의 브라우저별 목소리 선택 설명은 이전 버전 동작입니다. 현재 기본은 gTTS이며 다른 엔진도 선택할 수 있고 공용 화면의 검사 신청 전용/관리자 비고 제한은 유지합니다.

공용 컴퓨터의 작업자 화면에 ‘🔊 공용 PC 신청 알림 켜기/끄기’와 미리듣기를 추가했습니다. 관리자 로그인 없이 다른 휴대폰 작업자의 새 검사 신청을 띵똥 후 한국어로 읽습니다. 공유 화면은 검사 신청만 읽고 관리자에게 보낸 비고/완료/반려/숨김 수주는 읽지 않습니다. 기본 꺼짐이며 공용 컴퓨터에서만 직접 켜두면 됩니다. 기존 관리자 음성은 유지합니다.

관리자 웹 화면에 ‘🔊 전자녀 알람 켜기/끄기’와 미리듣기를 추가했습니다. 기존 검사 신청·비고만 “홍길동님이 프로젝트명의 세팅검사를 신청했습니다.”처럼 읽으며 완료 알림은 새로 만들지 않습니다. Google 한국의 → Microsoft SunHi Online (Natural) → Microsoft Heami → 다른 한국어 음성 순으로 선택하며 rate=1.1, pitch=1.0입니다. 브라우저에 없는 음성을 설치하거나 위플랩과 동일한 목소리를 제공하는 기능은 아닙니다.

회사 PC의 로컬 관리자 화면에서 웹 음성을 선택하면 기존 PC 기본 음성은 꺼짐으로 저장해 이중 재생을 막습니다. 웹 음성을 껐을 때 기본 음성이 갑자기 다시 켜지지 않습니다. 기본 음성으로 돌아가려면 웹 음성을 끄고 Windows 프로그램의 음성 알림을 직접 켜세요. 웹 음성은 해당 관리자 페이지를 열고 켜기를 눌러야 동작합니다.

PC 검사 신청 알림에 띵똥 두 음과 한국어 TTS를 추가했습니다. “신청자님이 프로젝트명의 검사 종류를 신청했습니다.” 순서로 읽고 세팅·출하 통합 신청은 한 번만 읽습니다. 비고 알림은 작성자와 내용을 읽습니다. 프로그램 창의 음성 알림 버튼으로 켜고 끄며, 음성 미리듣기로 확인합니다. 인터넷 음성 서비스/별도 API 키 없이 Windows에 설치된 한국어 여성 음성을 우선 사용합니다. 한국어 음성이 없거나 실행 정책으로 차단되면 창에 음성 실패를 표시하며 신청 팝업/관리자 처리는 유지합니다.

관리자 검사 화면에 반려 버튼을 제공합니다. 세팅 반려는 세팅 대기, 출하 반려는 세팅 완료를 유지하고 출하 대기, 통합 반려는 두 단계 재신청으로 돌아갑니다. 반려 이력은 보관하며 완료 엑셀에는 포함하지 않습니다. PC 알림 버튼은 변경하지 않습니다.

조립일정 N열 ‘사급 관련’을 수주번호로 연결합니다. 고정 ‘사급품’ 접두어 없이 같은 수주의 첫 행 N셀에서 첫 줄만 표시하며, 해당 셀의 채우기 색(현재 시트의 문구별 조건부 서식 포함)을 버튼에 반영합니다. 사급품 내용을 특이사항 앞에 표시하고 누르면 전체 내용을 확인합니다. 날짜 변경이 없어도 사급품 수정/빈칸은 갱신하며 기존 특이사항은 덮어쓰지 않습니다.

OneDrive 납기표 직접 다운로드/API 재시도와 Microsoft 저장소 이동을 보완했습니다. 시장 설정의 연결 확인은 실제 캐시 시세와 같은 상태를 표시하며 잘못된 주소/응답 항목을 수정했습니다. 실제 OneDrive 공유 파일 다운로드는 개발 환경의 접속 제한으로 확인하지 못했습니다.

작업자 수주 검색 위의 ‘업체별 특이사항 전체 보기’ 카드로 모든 등록 업체의 글/사진을 조회합니다. 업체명·내용 검색과 자동 갱신을 지원하며 작업자는 수정할 수 없습니다.

엑셀 폴더 버튼은 Windows 탐색기로 운영 폴더를 열며 실패하면 오류와 경로를 표시합니다.

PC 창과 알림 카드를 정돈하고 검사 종류/수주번호/프로젝트/신청자를 구분해 표시합니다. 검사 완료 알림은 보내지 않으며 기존 비고 알림은 유지합니다. 일반 목록·오늘 납기·다음 출고·출고 캘린더에서는 완료 수주를 제외합니다. 오늘 완료 수주는 금일 검사 완료에서만 표시하며 기록/엑셀은 보존합니다.

중복 수주 안내에서 기존 수주의 이름·상태와 검사/수정/삭제 확인 화면을 열 수 있습니다. 관리자 로그인 후 `/projects/find?number=test`로 번호를 조회할 수 있습니다.

출고 캘린더의 관리자·작업자 수주에 설계담당자 이름과 전화 연결을 표시합니다.

수주·검사 신청/승인·동시 검사·담당자/업체 특이사항·캘린더·엑셀 일괄등록/병합·알림·외부 접속·시세·납기·백업 코드를 연결한 운영 전환용 배포본입니다. **원본과 100% 같은 소스를 복구한 것은 아니며 실제 Windows/회사 계정/휴대폰 확인이 남아 있습니다.**

먼저 **[START-HERE.md](START-HERE.md)**를 읽으세요. **EXE 하나만 실행합니다.** 기존 운영 자료가 있으면 이어서 열고, 최초 실행에만 창에서 가져올 자료를 선택합니다. 실행 파일은 `AlphaWorkComplete-Recovered.exe`입니다. 기존 프로그램 폴더를 덮어쓰거나 원본 데이터를 삭제하지 않습니다.

아래 CMD는 소스에만 호환용으로 남아 있습니다. Windows ZIP은 EXE 하나로 사용합니다.

| 실행 파일 | 용도 |
|---|---|
| start-production.cmd | 기본 운영 시작. 최초 원본을 새 운영 폴더로 복사, 다음부터 운영 자료 재개 |
| promote-test-to-production.cmd | 최초에만 테스트 업무 자료로 운영 전환. 원본 접속/인증 설정 복구 |
| start-empty-for-restore.cmd | 새 PC의 빈 운영 자료/암호화 백업 복원용 |
| start-test.cmd / continue-test.cmd | 외부 연동을 막은 격리 테스트 |
| copy-existing-data.cmd | 최신 업무 자료의 새 테스트 복사본 생성 |

운영 자료는 `%AppData%\AlphaWorkCompleteRecovered`, 로컬 주소는 `http://127.0.0.1:18791/`입니다. 테스트 자료는 기존 `%AppData%\AlphaWorkRecoveryTest-v1.1`, 포트는 28791을 유지합니다. Windows 운영 뮤텍스는 원본과 같아 동시 운영을 막고 테스트는 별도 뮤텍스·클래스·쿠키를 사용합니다.

운영 모드는 설정을 지우거나 외부 전송을 강제로 차단하지 않습니다. 기존 설정에 따라 시세/일정/암호화 백업을 갱신합니다. 준비된 Pages/Cloudflare 설정은 실행 시 연결을 시작하며 수동 연결 버튼도 유지합니다. **개발 검증 중 운영 GitHub 포인터를 게시하거나 실제 계정/휴대폰에 메시지를 보내지 않았습니다.**

파일 직접 저장/최초 .bak/다중 파일 저널 복구는 운영 복사본 안에서 작동합니다. 원본 WanryoTalk는 읽기 전용으로 복사하며 정상 운영 중 다시 덮어쓰지 않습니다. 테스트에서 운영 전환은 명시적으로 선택하며 이미 시작한 운영 자료를 대체하지 않습니다.

Go 1.27.3 이상에서 build-windows.ps1 또는 다음 명령으로 빌드합니다.

```powershell
$env:GOOS='windows'; $env:GOARCH='amd64'; $env:CGO_ENABLED='0'
go build -trimpath -buildvcs=false -ldflags='-s -w -H=windowsgui' -o AlphaWorkComplete-Recovered.exe .
```
