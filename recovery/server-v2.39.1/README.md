# 알파 복구 테스트판 v1.1 · 기존 프로그램과 분리

이번 ZIP은 기존 프로그램과 함께 켜서 확인하는 **격리 테스트판**입니다. 이전 v1.0 ZIP은 원본 폴더에 직접 저장하므로 테스트 용도로 사용하지 마세요. v1.0 파일은 이력 보존을 위해 남겨 두었습니다.

## 실행

압축을 풀고 **AlphaWorkRecoveryTest.exe**를 실행합니다. 기존 알파 프로그램을 종료할 필요가 없습니다.

- 자료: `%AppData%\AlphaWorkRecoveryTest-v1.1`
- 관리자: `http://127.0.0.1:28791/`
- 창/트레이 이름: **알파 복구 테스트판**
- 테스트 전용 Windows 단일 실행 뮤텍스와 창 클래스, 브라우저 로그인 쿠키 사용
- 기존 `%AppData%\WanryoTalk`, 이전 복구판 폴더를 자동 탐색·가져오기하지 않음
- 비어 있지 않은 표시 없는 기존 폴더를 `-data`로 지정해도 자료를 읽거나 쓰기 전에 거부
- 첫 실행: 새 관리자 비밀번호 설정, 예시 수주 TEST-001·TEST-002 제공
- 테스트한 수주와 기록은 테스트 폴더에만 저장. 재실행해도 예시 수주를 중복 생성하지 않음

관리 창에서 ‘수주 · 메시지 관리’를 누르고 새 비밀번호를 설정합니다. 관리자 화면의 ‘작업자 화면’으로 이동해 검사 신청을 한 뒤 관리자에서 승인해 보세요. 팝업·미확인 숫자·특이사항·출고 캘린더도 시험할 수 있습니다.

## 외부 연동

기존 운영 서비스에 영향을 주지 않도록 이 시험판은 **외부 네트워크 전송을 차단**합니다. 운영 QR 접속 주소 게시·Cloudflare 터널·휴대폰 알림·모바일 관리자·고정 Pages 지문·GitHub 원격 백업을 사용하지 않습니다. 관련 메뉴에는 차단 안내가 표시됩니다. 시세나 OneDrive의 실제 조회도 하지 않습니다. 수동 로컬 일정 파일 읽기는 테스트 자료에만 반영합니다.

테스트 폴더에 저장된 외부 연동 설정은 시작 시 비워집니다. 운영 설정과 접속 키를 이 시험판에 넣을 필요가 없습니다. PC 자체 팝업은 외부 서버를 사용하지 않습니다.

## 기존 자료에 관하여

`%AppData%\WanryoTalk`에는 수주·기록·사진·설정 등 주요 데이터가 있지만 프로그램 소스 코드는 없습니다. DPAPI 파일은 같은 Windows 계정에서 읽어야 합니다. 접속 키가 있을 수 있으므로 폴더 전체를 채팅이나 GitHub에 올리지 마세요.

이 시험판은 기존 자료를 자동으로 복사하지 않습니다. 기본값은 별도 예시 데이터입니다. 현재 원본 스키마 저장 구현은 테스트 폴더 안에서만 사용하며, 이전 v1.0의 ‘원본 직접 저장’ 설명은 운영 자료에 적용되지 않습니다. 이전 보고서는 `audit/RECOVERY-V1.0.md`에 이력으로 남아 있습니다.

## 검증과 제한

자동 시험으로 기존 자료 폴더 거부·원본 바이트 불변·테스트 재시작·독립 검사 신청/승인·별도 로그인 쿠키·외부 요청 차단을 확인합니다. Linux 로컬 동시 실행 및 브라우저 시험 결과와 Windows GUI 교차 빌드 결과는 `audit/build-manifest-v1.1-test.json`을 확인하세요.

실제 Windows 창·트레이·DPAPI와 회사 자료로 실행한 검증은 아직 없습니다. 원본 100% 동등성을 보장하지 않으며, 엑셀 일괄등록 등 기존 미구현 항목은 남아 있습니다.

## 소스 빌드

Go 1.27.3 이상에서 `build-windows.ps1`을 실행합니다. 출력은 `AlphaWorkRecoveryTest.exe`입니다.

테스트 자료 폴더를 바꾸려면 비어 있는 폴더를 지정하세요.

```powershell
.\AlphaWorkRecoveryTest.exe -data "D:\AlphaRecoveryTest"
```

Linux는 암호화를 적용하지 않는 시험용이며 `-headless -no-browser`로 GUI 없는 로컬 시험을 실행할 수 있습니다.
