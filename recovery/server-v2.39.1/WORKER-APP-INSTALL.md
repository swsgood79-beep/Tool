# 작업자 앱 설치

작업자용은 브라우저에서 홈 화면에 설치하는 웹앱입니다. 관리자 APK와 별도이며 설치하려는 휴대폰에서 처음 한 번 설치해야 합니다.

1. 원래 회사 작업자 QR 주소를 Chrome 또는 삼성 인터넷의 일반 모드에서 엽니다.
2. 전체 → 알파 앱 설치를 누릅니다. 설치 페이지에서 앱 설치를 누릅니다.
3. 설치 창이 나오면 설치합니다. 창을 제공하지 않는 브라우저는 안내창의 방법을 따릅니다. Chrome은 메뉴 ⋮ → 앱 설치 또는 홈 화면에 추가, 삼성 인터넷은 메뉴 ☰ → 현재 페이지 추가 → 홈 화면을 사용합니다.
4. 네이버 안에서 열렸다면 안내창의 **Chrome에서 열기** 또는 **설치 주소 복사**를 사용합니다. 복사한 주소는 Chrome 주소창에 붙여넣습니다. Chrome 실행 버튼은 Android의 브라우저/앱 정책에 영향을 받으므로 실행되지 않으면 주소 복사를 사용합니다.

브라우저를 바꾸면 기존 브라우저에 저장된 작업장 정보가 자동으로 옮겨지지 않습니다. 설치 주소 복사는 연결된 작업장 키만 주소의 # 뒤에 포함합니다. 작성자·개인 브라우저 소유자 키는 복사하지 않습니다. 연결 정보가 없다고 나오면 원래 작업자 QR 주소를 새 브라우저에서 열어 주세요.

Web v1.4.101은 연결 코드의 조기 종료와 설치 안내를 분리해 연결 정보가 없어도 버튼이 반응합니다. 설치 취소·실패·미지원에는 수동 메뉴 안내를 제공하고 클립보드 실패 시 직접 복사할 주소를 표시합니다. 브라우저의 시스템 설치 창 자체를 강제로 열거나 사용자 승인 없이 설치할 수는 없습니다.

회사 PC v1.4.100과 관리자 APK v1.0.11을 다시 설치할 필요는 없습니다. 작업자 설치 화면을 닫았다 다시 열거나 새로고침하세요. Pages 배포 직후에는 반영까지 잠시 걸릴 수 있습니다. 기존 설치 앱의 연결·작성자·테마를 유지하며 서비스워커는 앱 껍데기만 새 캐시로 전환합니다.
