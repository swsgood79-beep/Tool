# 빠른 시작 · PC v1.4.88 / 관리자 앱 v1.0.11

전체 기능과 사용 순서는 [README.md](README.md)에 있습니다. 관리자 앱 Firebase 설정은 [ANDROID-ADMIN-SETUP.md](ANDROID-ADMIN-SETUP.md)를 참고하세요.

## 이미 사용 중인 회사 PC

**이미 PC v1.4.86 이상을 사용 중이면 PC 창 아래 업데이트 버튼으로 v1.4.88을 설치합니다.** 아래 ZIP 절차는 이전 버전에서 처음 전환할 때만 필요합니다.

1. v1.4.85 이하에서는 처음 한 번 [Windows ZIP](https://raw.githubusercontent.com/swsgood79-beep/Tool/recovery-v2.39.1/recovery/server-builds/AlphaWorkComplete-Recovered-Windows-x64-v1.4.88.zip)을 내려받아 쓰기 가능한 폴더에 풉니다.
2. 기존 프로그램을 종료 버튼/트레이에서 완전히 끝내고 새 EXE를 실행합니다. 기존 운영 자료와 지정한 저장 경로를 이어서 사용합니다.
3. **이후 새 버전은 PC 창 아래 ‘v버전 업데이트’를 누릅니다.** 시작 시와 5분마다 자동 확인하며 ‘PC 업데이트 확인’으로 수동 확인할 수도 있습니다.
4. 검증된 다운로드가 완료되면 정상 종료·교체·재실행합니다. 재시작 동안 접속/알림이 잠시 중단됩니다. [자세한 안내](PC-AUTO-UPDATE.md).

창 X는 트레이로 숨기는 동작일 수 있습니다. 자료 폴더를 삭제하거나 빈 자료로 다시 시작하지 마세요.

## 처음 운영판을 실행하는 PC

1. 원래 자료를 사용하는 같은 Windows 계정에서 기존 자료 전체와 완료 엑셀을 별도 보관합니다.
2. 원래 프로그램을 완전히 종료하고 새 ZIP을 별도 폴더에 풉니다.
3. EXE를 실행하고 처음 선택창에서 가져올 기존 운영 자료/테스트 자료를 선택합니다. 원본은 보존하고 운영 복사본으로 시작합니다.
4. 이후에는 이 운영 자료를 이어서 사용합니다. 새 PC로 서버를 이전하려면 지원하는 암호화 백업/복원 절차를 사용합니다.

과거 전환용 CMD·시험 모드 안내는 [이전 시작 안내](docs/history/START-HERE-v1.4.74.md)에 이력으로 보존했습니다. 현재 일반 실행은 EXE 하나를 사용합니다.

## 작업자 접속

회사 PC 프로그램을 실행하고 인터넷 연결을 켠 뒤 현재 작업자 QR/접속 주소를 사용합니다. Android 작업자는 브라우저에서 홈 화면에 추가해 앱처럼 실행할 수 있습니다.

검사 신청은 **수주 → 검사 화면 열기 → 이름 확인 → 세팅/출하검사 신청** 순서입니다. 신청 후 관리자가 검사 완료를 처리해야 다음 단계로 진행합니다.

## 관리자 휴대폰

1. [관리자 APK v1.0.11](https://raw.githubusercontent.com/swsgood79-beep/Tool/recovery-v2.39.1/recovery/server-builds/AlphaAdmin-Android-v1.0.11.apk)을 설치합니다. 기존 앱은 ⋮ → 앱 업데이트 확인을 사용합니다.
2. 대표 관리자 wssong 또는 개인 관리자 아이디·비밀번호로 로그인합니다.
3. 한 번 로그인하면 직접 로그아웃할 때까지 유지합니다. 다른 앱 복귀는 기존 화면을, 재실행은 저장된 계정을 사용합니다.
4. 최초 Firebase 설정과 앱 알림 권한을 확인하고 시험 알림을 보냅니다.
5. 전체 메뉴에서 화면 밝기, 업체 특이사항 관리, 작업자 화면 보기 등을 사용합니다.

## 실행 직후 확인

- 실제 수주와 최근 검사 기록이 맞는지 확인합니다.
- 회사 PC의 전체 → 자료 저장 위치에서 현재 경로를 확인합니다. D드라이브 설정을 이미 사용 중이면 그대로 유지합니다.
- 시험 수주로 신청 → 관리자 확인 → 검사 완료 흐름과 PC/휴대폰 알림을 확인합니다.
- 출하사진 필요/보관 완료 목록에서 사진과 수주 정보를 확인합니다.
- 백업 설정과 복구키 보관 상태를 확인합니다.

구매팀 호출을 사용하려면 PC v1.4.82과 같은 관리자 앱 v1.0.11을 함께 적용하세요. 구매팀용 별도 앱은 없습니다. 대표 관리자에서 구매팀 권한 계정을 만들고 담당자를 지정합니다. [구매팀 호출 시작하기](PURCHASING-SETUP.md)를 참고하세요.

앱 v1.0.11의 업데이트 다운로드 개선은 앱만 업데이트하면 적용됩니다. PC v1.4.82은 그대로 사용해도 됩니다. 기존 앱에서 다운로드가 실패하면 상단 APK 링크로 받아 삭제 없이 덮어 설치하세요.

PC v1.4.81에서 수정한 기능도 유지합니다: 업체 원본에서 선택한 사진만 합산해 수주 전용 추가 사진을 저장합니다. 수주 수정 → 이 수주에만 사진 추가 → 수주 수정 저장 순서로 사용하며, 업체 사진과 수주 사진의 합계는 최대 5장입니다. APK 재설치는 필요 없습니다.

## 출하 파일·동영상

출하 기록 상세 → 파일·동영상에서 파라미터 파일이나 촬영한 영상을 선택합니다. 사진과 함께 선택한 첨부는 ‘사진 등록 후 완료·보관’을 누르면 먼저 저장됩니다. 이미 보관된 수주는 ‘파일·동영상 저장’을 누르세요. 20MB 초과 영상은 업로드 전에 자동 압축하며 화면을 켜 두어야 합니다. 원본 영상과 파라미터 파일 내용은 휴대폰에서 변경하지 않습니다. APK 재설치는 필요 없습니다. [첨부 안내](SHIPMENT-ATTACHMENTS.md)를 참고하세요.

## 출하 기록 엑셀 저장

관리자 출하 기록의 보관 완료 목록에서 **전체 보관 엑셀 저장**을 누르면 전체 목록과 월별 상세 엑셀을 ZIP으로 받습니다. ZIP은 전체 압축을 풀고 같은 폴더에서 사용합니다. 고객사에 한 수주만 전달하려면 해당 상세 화면의 **이 수주 엑셀 저장**을 사용합니다. 사진은 엑셀에 들어 있고, 파일·영상 원본은 별도 전달입니다. [엑셀 사용 안내](SHIPMENT-EXCEL.md)를 참고하세요. 회사 PC만 업데이트하며 APK 1.0.11은 그대로 사용합니다.

## 분할 백업 · PC v1.4.88

기존 자동 백업 설정과 복구키를 유지합니다. 회사 PC의 관리자 백업 메뉴에서 **지금 전체 백업**을 누르고 마지막 성공 시각·조각 수·전체 용량을 확인하세요. GitHub Releases에 암호화한 조각과 완료 정보가 보관됩니다. 복구키는 USB 등 PC 밖에 보관합니다. 다시 받기는 같은 키입니다. 새 PC 복원은 v1.4.88 이상에서 진행하며 [분할 백업 안내](BACKUP-SETS.md)를 참고하세요.
