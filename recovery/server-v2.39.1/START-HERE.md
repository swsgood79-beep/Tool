# 빠른 시작 · PC v1.4.124 / 관리자 앱 v1.0.11

업체 특이사항의 내용·사진 수정은 이미 보관 완료된 출하 기록과 새로 저장하는 출하 엑셀에도 반영합니다. 수주별 추가 메모·사진은 별도로 유지하고 명시적으로 수주 특이사항을 수정하면 동일 검사 건의 출하 상세도 갱신합니다. 출하사진·첨부·사급품·담당자·검사 완료일·보관일은 변경하지 않습니다. 업체 원본을 삭제하면 마지막 내용을 보관합니다.

가공팀은 [가공팀 사용법](MACHINING.md)에 따라 계정을 만들고 ERP XLSX를 가져옵니다. 정기 자동 수집은 아직 연결하지 않습니다.

같은 수주에 여러 출고 예정일이 있으면 갱신 후 수주 카드에서 차수별 출하검사를 진행합니다. [분할 출고 안내](SPLIT-SHIPMENT.md).

전체 기능과 사용 순서는 [README.md](README.md)에 있습니다. 관리자 앱 Firebase 설정은 [ANDROID-ADMIN-SETUP.md](ANDROID-ADMIN-SETUP.md)를 참고하세요.

## 이미 사용 중인 회사 PC

**이미 PC v1.4.86 이상을 사용 중이면 PC 창 아래 업데이트 버튼의 PC 업데이트 확인으로 v1.4.124를 설치합니다.** 아래 ZIP 절차는 이전 버전에서 처음 전환할 때만 필요합니다.

1. v1.4.85 이하에서는 처음 한 번 [Windows ZIP](https://raw.githubusercontent.com/swsgood79-beep/Tool/recovery-v2.39.1/recovery/server-builds/AlphaWorkComplete-Recovered-Windows-x64-v1.4.105.zip)을 내려받아 쓰기 가능한 폴더에 풉니다.
2. 기존 프로그램을 종료 버튼/트레이에서 완전히 끝내고 새 EXE를 실행합니다. 기존 운영 자료와 지정한 저장 경로를 이어서 사용합니다.
3. **이후 새 버전은 PC 창 아래 ‘v버전 업데이트’를 누릅니다.** 시작 시와 5분마다 자동 확인하며 ‘PC 업데이트 확인’으로 수동 확인할 수도 있습니다.
4. 검증된 다운로드가 완료되면 정상 종료·교체·재실행합니다. 재시작 동안 접속/알림이 잠시 중단됩니다. [자세한 안내](PC-AUTO-UPDATE.md).

창 X는 트레이로 숨기는 동작일 수 있습니다. 자료 폴더를 삭제하거나 빈 자료로 다시 시작하지 마세요.

## 처음 운영판을 실행하는 PC

1. 원래 자료를 사용하는 같은 Windows 계정에서 기존 자료 전체와 완료 엑셀을 별도 보관합니다.
2. 원래 프로그램을 완전히 종료하고 새 ZIP을 별도 폴더에 풉니다.
3. EXE를 실행하고 처음 선택창에서 가져올 기존 운영 자료/테스트 자료를 선택합니다. 원본은 보존하고 운영 복사본으로 시작합니다.
4. 이후에는 이 운영 자료를 이어서 사용합니다. 새 PC로 서버를 이전하려면 지원하는 암호화 백업/복원 절차를 사용합니다.

과거 전환용 CMD·시험 모드 안내는 [이전 시작 안내](docs/history/START-HERE-v1.4.74.md)에 이력으로 보존했습니다. 현재 일반 실행은 EXE 하나를 사용합니다.

## 작업자 접속

회사 PC 프로그램을 실행해 인터넷 자동 연결이 완료된 뒤 현재 작업자 QR/접속 주소를 사용합니다. Android 작업자는 브라우저에서 홈 화면에 추가해 앱처럼 실행할 수 있습니다.

검사 신청은 **수주 → 검사 화면 열기 → 이름 확인 → 세팅/출하검사 신청** 순서입니다. 신청 후 관리자가 검사 완료를 처리해야 다음 단계로 진행합니다.

## 관리자 휴대폰

1. [관리자 APK v1.0.11](https://raw.githubusercontent.com/swsgood79-beep/Tool/recovery-v2.39.1/recovery/server-builds/AlphaAdmin-Android-v1.0.11.apk)을 설치합니다. 기존 앱은 ⋮ → 앱 업데이트 확인을 사용합니다.
2. 대표 관리자 wssong 또는 개인 관리자 아이디·비밀번호로 로그인합니다.
3. 한 번 로그인하면 직접 로그아웃할 때까지 유지합니다. 다른 앱 복귀는 기존 화면을, 재실행은 저장된 계정을 사용합니다.
4. 최초 Firebase 설정과 앱 알림 권한을 확인하고 시험 알림을 보냅니다.
5. 전체 메뉴에서 화면 밝기, 업체 특이사항 관리, 작업자 화면 보기 등을 사용합니다.

## 실행 직후 확인

- 실제 수주와 최근 검사 기록이 맞는지 확인합니다.
- 회사 PC의 전체 → 자료 저장 위치에서 현재 경로를 확인합니다. D드라이브 설정을 이미 사용 중이면 그대로 유지합니다.
- 시험 수주로 신청 → 관리자 확인 → 검사 완료 흐름과 PC/휴대폰 알림을 확인합니다.
- 출하사진 필요/보관 완료 목록에서 사진과 수주 정보를 확인합니다.
- 백업 설정과 복구키 보관 상태를 확인합니다.

구매팀 호출을 사용하려면 PC v1.4.82과 같은 관리자 앱 v1.0.11을 함께 적용하세요. 구매팀용 별도 앱은 없습니다. 대표 관리자에서 구매팀 권한 계정을 만들고 담당자를 지정합니다. [구매팀 호출 시작하기](PURCHASING-SETUP.md)를 참고하세요.

앱 v1.0.11의 업데이트 다운로드 개선은 앱만 업데이트하면 적용됩니다. PC v1.4.82은 그대로 사용해도 됩니다. 기존 앱에서 다운로드가 실패하면 상단 APK 링크로 받아 삭제 없이 덮어 설치하세요.

PC v1.4.81에서 수정한 기능도 유지합니다: 업체 원본에서 선택한 사진만 합산해 수주 전용 추가 사진을 저장합니다. 수주 수정 → 이 수주에만 사진 추가 → 수주 수정 저장 순서로 사용하며, 업체 사진과 수주 사진의 합계는 최대 5장입니다. APK 재설치는 필요 없습니다.

## 출하 파일·동영상

출하 기록 상세 → 파일·동영상에서 파라미터 파일이나 촬영한 영상을 선택합니다. 사진과 함께 선택한 첨부는 ‘사진 등록 후 완료·보관’을 누르면 먼저 저장됩니다. 이미 보관된 수주는 ‘파일·동영상 저장’을 누르세요. 20MB 초과 영상은 업로드 전에 자동 압축하며 화면을 켜 두어야 합니다. 원본 영상과 파라미터 파일 내용은 휴대폰에서 변경하지 않습니다. APK 재설치는 필요 없습니다. [첨부 안내](SHIPMENT-ATTACHMENTS.md)를 참고하세요.

## 출하 기록 엑셀 저장

관리자 출하 기록의 보관 완료 목록에서 **전체 보관 엑셀 저장**을 누르면 전체 목록과 월별 상세 엑셀을 ZIP으로 받습니다. ZIP은 전체 압축을 풀고 같은 폴더에서 사용합니다. 고객사에 한 수주만 전달하려면 해당 상세 화면의 **이 수주 엑셀 저장**을 사용합니다. 사진은 엑셀에 들어 있고, 파일·영상 원본은 별도 전달입니다. [엑셀 사용 안내](SHIPMENT-EXCEL.md)를 참고하세요. 회사 PC만 업데이트하며 APK 1.0.11은 그대로 사용합니다.

## 분할 백업 · PC v1.4.88

기존 자동 백업 설정과 복구키를 유지합니다. 회사 PC의 관리자 백업 메뉴에서 **지금 전체 백업**을 누르고 마지막 성공 시각·조각 수·전체 용량을 확인하세요. GitHub Releases에 암호화한 조각과 완료 정보가 보관됩니다. 복구키는 USB 등 PC 밖에 보관합니다. 다시 받기는 같은 키입니다. 새 PC 복원은 v1.4.88 이상에서 진행하며 [분할 백업 안내](BACKUP-SETS.md)를 참고하세요.

## 실행 시 인터넷 자동 연결 · PC v1.4.89

프로그램 실행/업데이트 재시작 시 저장된 설정으로 연결합니다. 첫 연결 실패는 자동 재시도하며, 고정 QR 연결키가 없으면 설정 안내가 표시됩니다. 인터넷 끊기는 이번 실행 중 자동 재연결을 멈추며 다음 실행 때 자동 연결이 다시 켜집니다. 새 PC 복원 동안은 자동 연결을 보류합니다. [자세히](INTERNET-AUTO.md).

## 검사자 기록 · PC v1.4.91

1. 대표 관리자라면 전체 → 관리자 계정 관리 → wssong 행 ‘이름 수정’에서 실제 이름을 저장합니다. 아이디/비밀번호는 바뀌지 않습니다.
2. 기존 검사를 보완하려면 같은 화면의 ‘기존 검사자 기록 보완’으로 이동해 실제 이름·범위·확인 항목을 지정하고 저장합니다. 이미 검사자가 있는 건은 제외됩니다.
3. 이후 검사 완료는 현재 로그인한 관리자 이름으로 자동 기록됩니다. 작업자 신청 절차는 그대로입니다. [자세히](INSPECTION-INSPECTORS.md).

## 검사자 표시와 완료 시각 · PC v1.4.91

검사 완료 화면과 출하 상세에는 검사자 이름·실제 완료 일시만 표시합니다. 하단의 자동/과거 보완 방식·보완 처리 시각/계정 표시는 빼고 출하 상세 엑셀도 같은 방식으로 정리했습니다. 내부 보완 이력은 유지합니다. 신규 검사는 관리자 완료 버튼을 서버가 처리한 시각을 저장하며 신청 시각과 구분합니다. 기존 완료 시각은 바꾸지 않습니다. PC에서 관리자 화면을 다시 열 때 유효한 로컬 대표 관리자 세션을 재사용해 기존 탭의 CSRF가 바뀌지 않도록 했습니다. 일회용 접속 티켓·계정 권한·CSRF 검증은 유지합니다. APK 1.0.11은 그대로 사용합니다.

## 특이사항 중복 표시 수정 · PC v1.4.92

출하 기록의 특이사항에서 업체 원본 사진과 기존 복사본이 중복으로 보이던 문제를 수정했습니다. 원본과 복사본의 ID가 달라도 같은 내용이면 화면과 새 출하 엑셀에는 한 번만 표시하고 현재 업체 원본을 우선합니다. 이름이 같아도 내용이 다른 사진은 유지하며 사진 파일·검사 기록·날짜는 삭제하거나 변경하지 않습니다. 출하 기록 상세와 출하 상세 엑셀의 날짜 제목만 **출고일자**로 바꿉니다. 수주 목록·출고 일정의 **출고 예정** 표시는 유지합니다. PC v1.4.86 이상은 PC 업데이트 확인으로 v1.4.92를 설치하며 APK 1.0.11은 그대로 사용합니다.
업데이트 후 출하 기록 화면을 새로고침하세요. 이미 내려받은 엑셀은 다시 저장하면 적용됩니다.

## 출하 고객사 표시 통일 · PC v1.4.93

출하 기록의 고객사 표시를 화면·목록·고객사 검색·출하 엑셀에서 통일했습니다. 수주명에서 띄어쓰기 뒤 숫자+축 앞부분을 고객사로 사용합니다. **은일 12축 → 은일**, **쿼드메디슨 3축, 긴급건 → 쿼드메디슨**입니다. 업체 특이사항 연결 여부와 관계없이 적용하며 고객사가 비어 있는 기존 보관 건도 다시 열면 표시합니다. 숫자+축 형식이 없으면 저장된 고객사, 명시적으로 연결된 업체 이름을 사용하고 확인할 수 없으면 항목을 숨기지 않고 미등록으로 표시합니다. 신규 검사/사진 보관 때도 같은 기준으로 고객사를 저장합니다. 기존 특이사항 연결·사진·검사일·보관일은 유지합니다. PC v1.4.86 이상은 PC 업데이트 확인으로 v1.4.93을 설치하고 APK 1.0.11은 그대로 사용합니다.
업데이트 후 출하 기록을 새로고침하세요. 이미 받은 엑셀은 다시 다운로드해야 적용됩니다.

## 출하 기록 작업자 이름 수정 · PC v1.4.94

보관 완료된 출하 기록의 **세팅 작업자·출하 작업자 이름 수정**을 추가했습니다. 관리자 PC/앱에서 **출하 기록 → 해당 수주 → 작업자 이름 수정 → 작업자 이름 저장**을 사용합니다. 여러 명은 공백/쉼표로 함께 적고 각각 40자 이내로 입력합니다. 이름을 비우면 미기록 표시(—)로 돌아갑니다. 해당 출하 기록과 이후 저장하는 출하 엑셀에 반영하며 검사자·검사 완료 시각·보관일·출하사진·첨부·사급품은 유지합니다. 원래 작업자의 검사 신청 내역과 기존 월별 검사 엑셀 원본은 바꾸지 않습니다. 작업자는 수정할 수 없으며 수정된 이름만 확인합니다. PC v1.4.86 이상은 PC 업데이트 확인으로 v1.4.94를 설치하고 APK 1.0.11은 그대로 사용합니다.
관리자 앱에서는 전체 → 출하 기록을 사용합니다. 작업자 화면 보기로 전환한 상태라면 관리자 화면으로 돌아와 수정하세요. 이미 내려받은 출하 엑셀은 다시 저장해야 바뀐 이름이 반영됩니다.

## 사진 수 계산과 미완료 수주 보존 · PC v1.4.95

업체 사진 삭제 저장 시 기존 업체 복사본을 수주별 추가 사진으로 중복 계산하던 문제를 수정했습니다. 업체 사진과 구분된 실제 수주 사진으로 합계 5장 한도를 확인하고 원본 파일은 삭제하지 않습니다. 오류가 있으면 흰 오류 화면 대신 수정 화면에 안내합니다. 엑셀에서 미완료 수주 행이 빠지면 마지막 납기·검사 신청·수주 정보·사급품 수령 내역을 유지하고 **엑셀에서 제외됨 · 미완료 수주 유지**를 표시합니다. 같은 수주가 시트에 돌아오면 표시를 해제하고 새 납기를 반영합니다. 관리자 완료/숨김/삭제 기능은 유지합니다. PC 업데이트 확인으로 v1.4.95를 설치하며 APK 1.0.11은 그대로 사용합니다.

## 출하 기록 출고일자 입력 · PC v1.4.96

관리자 출하 기록 상세에 **출고일자 입력·수정**을 추가했습니다. 사진 대기와 보관 완료 모두 **출하 기록 → 해당 수주 → 출고일자 입력·수정 → 날짜 선택 → 출고일자 저장**을 사용합니다. 미정인 기존 건도 직접 날짜를 입력할 수 있고, 작업자 조회와 새로 내려받는 출하 엑셀에 반영됩니다. 사진 등록 후에도 입력 날짜를 유지합니다. 검사자·검사 완료일·보관일·사진·첨부는 바꾸지 않으며 연결된 엑셀 원본과 수주 목록의 예정일을 수정하지 않습니다. PC v1.4.96을 업데이트하고 APK 1.0.11은 그대로 사용합니다.

## 작업 도구와 매뉴얼 · PC v1.4.97

**전체 → 작업 도구 → 벨트텐션값 확인 프로그램**을 관리자·작업자 공용으로 추가했습니다. 첨부 HTML의 기준표·수식을 유지하고 CSP에 맞춰 CSS/JS를 분리했습니다. 단일 Hz·Polychain MIN/MAX와 AT5 계산 불가 표시를 원본대로 제공합니다. **토크 → 매뉴얼 게시판**에는 PDF·엑셀·한글·ZIP 같은 일반 파일을 제목·설명과 함께 등록/검색/다운로드할 수 있습니다. 파일은 한 개당 20MB, 글당 최대 5개이며 관리자와 작업자 모두 등록합니다. 작업자는 작성한 브라우저의 글을 삭제하고 관리자는 전체 글을 관리합니다. 파일은 회사 PC에서 암호화 저장하고 기존 암호화 백업을 사용할 때 함께 포함합니다. 전송 중에는 업무 잠금을 잡지 않습니다. PC v1.4.97로 업데이트하고 APK 1.0.11은 그대로 사용합니다.

## 매뉴얼 일반 게시판 / 300MB 첨부 · PC v1.4.105

매뉴얼을 **목록 → 글 상세 → 글쓰기** 형태의 일반 게시판으로 바꿨습니다. 목록에서 제목·작성자·등록일·첨부 개수를 확인하고 글을 눌러 내용을 보거나 파일을 받습니다. 글쓰기 내용 칸은 전체 폭으로 표시합니다. 첨부 한도는 **파일당 300MB, 글당 5개**입니다. 작은 조각으로 업로드하고 진행률을 표시하며 같은 조각 재전송은 중복 저장하지 않습니다. 다운로드는 큰 파일 전체를 메모리에 모으지 않고 구간 다운로드를 지원합니다. 기존 매뉴얼/첨부/권한·암호화 백업은 유지하고 APK 1.0.11은 그대로 사용합니다. PC v1.4.105을 업데이트한 뒤 매뉴얼 화면을 새로고침하세요. 업로드가 완료될 때까지 화면을 열어두세요.

## 작업자 앱 설치

작업자용 웹앱은 작업자 화면의 전체 → 앱 설치에서 시작합니다. 네이버 앱 안에서 열렸다면 설치 안내의 Chrome에서 열기/설치 주소 복사를 사용하세요. [자세한 설치 안내](WORKER-APP-INSTALL.md). Web v1.4.101 설치 화면 개선은 PC v1.4.100/관리자 APK v1.0.11 재설치 없이 적용합니다.
