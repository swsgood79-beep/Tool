# 구매팀 호출 시작하기 · PC v1.4.78 / 같은 앱 v1.0.10

별도 앱 없이 현재 관리자 앱을 사용합니다. 검사 관리자 계정은 기존 화면, 구매팀 계정은 호출 목록·완료 내역·전체만 표시합니다. 검사·수주 관리 권한도 서버에서 차단합니다.

## 처음 한 번 준비

1. 회사 PC 프로그램을 v1.4.80으로 교체합니다. 기존 자료와 같은 Windows 계정·자료 저장 위치를 사용합니다.
2. 휴대폰의 기존 앱에서 자동 업데이트 안내로 v1.0.11을 설치합니다. 같은 패키지와 서명을 유지하므로 기존 로그인/알림 설정은 이어집니다.
3. 대표 관리자 wssong으로 **전체 → 관리자 계정 관리**에서 동료 계정을 만듭니다. ‘계정 권한’을 **구매팀 · 호출 전용**으로 선택하고 실제 담당자의 이름·아이디·8자 이상 비밀번호를 지정합니다. 기존 검사자 계정은 그대로 둡니다.
4. 같은 화면의 **구매팀 호출·알림 설정**에서 호출 받을 계정을 지정합니다. 첫 구매팀 계정은 자동으로 지정되며, 필요하면 여기에서 변경하거나 사용 안 함으로 바꿀 수 있습니다. 담당자를 바꿔도 기존 호출은 원래 담당자에게 남습니다.
5. 구매 담당자는 같은 앱에 자기 구매팀 아이디로 로그인하고 알림을 허용합니다. 기존 Firebase 연결을 그대로 사용하며 프로젝트/Android 앱/서비스 계정을 추가할 필요가 없습니다.

구매팀 계정이나 Firebase는 이 개발 환경에서 회사 자료에 임의로 등록하지 않았습니다. 실제 사용자 정보는 위 설정에서 지정합니다. 회사 PC와 프로그램·인터넷 연결은 켜져 있어야 합니다.

## 작업자가 호출할 때

작업 수주카드의 **구매팀 호출**을 누르고 이름을 확인한 뒤 **구매팀에 호출 보내기**를 누릅니다. 수주번호·프로젝트명·접수시간은 자동으로 전달합니다. 요청 종류·요청 내용·작업자 호출 내역 화면은 없습니다. 호출한 휴대폰의 수주카드에 작업자 이름·접수시간과 **호출 접수 완료**가 표시됩니다. 다른 휴대폰에는 표시하지 않습니다. 구매팀이 완료하면 **호출 처리 완료**로 바뀌고 완료 시점부터 1분 뒤 사라집니다. 화면을 보고 있을 때 약 5초마다 상태를 확인하며, 같은 수주에서 여러 이름으로 호출해도 각각 표시합니다. 호출 버튼은 계속 사용할 수 있습니다. 이 표시는 서버 접수·처리 상태이며 휴대폰 알림 도착이나 열람 확인을 뜻하지 않습니다. 브라우저의 사이트 자료를 지우거나 다른 접속 주소로 변경하면 이 휴대폰의 표시 연결은 초기화될 수 있습니다. 같은 사람·수주·담당자에게 처리 전 다시 누르면 중복 호출을 만들지 않습니다.

## 구매 담당자가 처리할 때

- 알림을 누르면 해당 호출이 열립니다. 앱을 직접 열면 **호출 목록**을 표시합니다.
- 미완료 호출은 먼저 접수된 순서이며, **첫 호출 확인**으로 시작합니다.
- **완료하고 다음 호출 보기**를 누르면 완료 내역에 저장하고 가장 오래된 미완료 호출로 이동합니다.
- **완료 내역**에서는 처리한 호출을 접수 최신순으로 확인합니다. 목록은 한 페이지 20건이며 이전·다음으로 이동합니다.
- **전체**에는 로그인 이름·아이디, 호출 알림 설정/테스트/켜기·끄기, 화면 밝기, 앱 업데이트 확인, 로그아웃을 표시합니다. 검사·수주 관리 메뉴는 없습니다.

한 번 로그인하면 앱 종료·휴대폰 재시작·덮어쓰기 업데이트 후에도 저장된 앱 로그인 연결로 복구합니다. 직접 로그아웃하면 해당 기기의 연결을 해제합니다. 계정 중지·비밀번호 재설정·관리자의 기기 연결 해제 시에는 다시 로그인해야 합니다.

## 알림과 저장

구매팀 호출은 지정된 구매팀 계정으로 로그인한 기기에만 보냅니다. 검사 신청·비고는 기존 관리자 기기에만 보냅니다. 구매팀은 별도 ‘구매팀 호출’ 알림 채널을 사용하며 **전체 → 호출 알림 소리·진동 설정**에서 바꿀 수 있습니다. 기존 검사 알림 채널은 바꾸지 않습니다. 안드로이드의 알림/잠금화면/배터리 설정에 따라 표시·수신이 달라질 수 있습니다.

같은 APK이므로 관리자 기능만 바뀐 APK도 공통 업데이트 안내가 뜹니다. 화면·서버 기능만 변경한 경우에는 APK 설치가 필요하지 않습니다.

호출·완료 내역·계정 권한은 기존 회사 PC 자료 파일의 확장 상태에 함께 저장·백업됩니다. 연결된 수주가 시트에서 사라져도 호출 당시 수주번호·제품명과 완료 기록은 남습니다. 앱 비밀번호 자체를 휴대폰에 저장하지 않고 기존 기기별 로그인 연결을 보호 저장합니다.

## 검증 범위

임시 서버·PC/휴대폰 크기 Chromium·APK 사용자 에이전트로 호출/목록/완료/다음 이동·테마·권한 차단·오류 재시도·출처/CSRF를 검증했습니다. 로그인 복구와 푸시 라우팅은 서버/모의 FCM·Android 단위시험으로 확인했습니다. 실제 삼성폰의 잠금화면/FCM·설치·지문 및 Windows 실행은 별도 기기 확인이 필요합니다.
