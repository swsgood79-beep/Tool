# 관리자 팀별 메뉴 권한 · PC 1.4.115

대표 관리자 → 관리자 계정 관리 → 각 일반 관리자 행의 **메뉴 권한**에서 구매팀·생산팀·가공팀 메뉴를 체크하고 저장합니다. 저장한 계정에만 적용되며 아이디·이름·비밀번호·계정 역할·로그인은 그대로 유지합니다. 구매팀/가공팀 전용 작업 계정의 역할은 변경하지 않습니다. 대표 관리자는 모든 메뉴를 사용합니다.

## 기존 계정 보존

업데이트가 기존 계정 레코드를 자동 변경하거나 일괄 권한을 부여/회수하지 않습니다. 별도 메뉴 설정이 없는 기존 관리자는 종전의 생산/가공 접근을 유지하며 구매팀 조회는 직접 허용할 때 추가됩니다. 메뉴 권한 저장은 인증 리비전이나 비밀번호를 변경하지 않으므로 기존 로그인과 앱 등록이 유지됩니다. 권한은 요청마다 서버에서 확인합니다.

## 메뉴

관리자 화면 및 팀 메뉴에서 허용된 메뉴만 표시됩니다. 생산팀 메뉴는 기존 수주/검사 화면, 가공팀 메뉴는 기존 가공 작업 관리 화면입니다. 새 구매팀 관리자 메뉴는 호출 목록의 조회 전용 화면입니다. 기존 구매 담당자의 호출 완료 업무는 담당자 계정에 유지됩니다. 생산 메뉴가 없는 관리자의 기본 화면은 팀 메뉴로 연결됩니다.

## 가공 완료 알림

가공 2차의 실제 완료 저장과 같은 트랜잭션에서만 알림을 생성합니다. 절단·가공1차는 알림 없이 기록과 진행 수량을 유지합니다. 전체 20개 중 10개만 2차 완료해도 해당 10개에 대해 알립니다. 수주/품번/공정/작업자/이번 완료량/누적량/남은량을 표시합니다. 완료 시점에 가공 메뉴 권한이 있는 사용 중인 일반 관리자와 대표 관리자가 수신합니다. 새 권한을 부여받아도 과거 다른 수신자 알림을 소급해서 받지 않습니다.

관리자마다 확인 상태를 별도 저장합니다. 한 관리자가 확인해도 다른 관리자 알림은 남습니다. 중복 완료 요청에는 새 알림을 만들지 않고, 권한이 회수되면 기존 수신 알림도 조회할 수 없습니다. 서버 재시작 후에도 미확인 알림을 유지합니다. 부분 완료마다 실제 수량·시작/완료 시각·작업자와 남은 수량을 보존합니다. 검사 완료 기록이나 검사 엑셀에는 섞지 않습니다.

- 서버 PC의 대표 관리자: 기존 Windows 팝업과 안 읽은 알림 숫자에 표시합니다. 팝업에서 열면 해당 알림을 확인할 수 있습니다.
- 다른 관리자 PC: 본인 계정으로 관리자 화면을 열어둡니다. 약 3초마다 새 완료 알림을 확인해 화면 안에 팝업을 표시합니다. **PC 팝업 알림 켜기**를 누르고 브라우저 알림을 허용하면 다른 창을 보고 있을 때도 OS 알림을 사용할 수 있습니다. 브라우저나 PC를 종료하면 즉시 알림은 표시할 수 없으며 다음 접속 시 미확인 알림을 확인합니다. 브라우저 정책에 따라 배경 탭 확인이 지연될 수 있습니다.
- 기존 관리자 Android 앱: 등록된 관리자 기기로 같은 2차 완료 내용을 푸시합니다. 기기별 전송 위치를 별도 저장하고 실패 시 재시도합니다. 기존 앱 1.0.11의 관리자 알림 채널을 사용하며 알림 권한과 회사 서버의 외부 연결이 필요합니다.
- 가공팀 작업자와 권한 없는 관리자는 관리자 완료 알림을 받지 않습니다.

기존 생산 검사 신청/음성 알림 흐름은 유지합니다. 생산 메뉴 권한을 직접 회수한 계정에는 생산 관련 알림·화면을 제공하지 않습니다. 실제 Windows 팝업 및 브라우저 OS 알림 권한 동작은 해당 회사 PC에서 확인합니다. Chromium 테스트는 합성 계정과 작업 자료만 사용합니다.
