# ERP DB 자동 연결 · PC 1.4.113

대표 관리자 → 가공 작업 관리 → **ERP DB 자동 연결**에서 입고예정일 시작·종료를 지정하고 **DB 자동 연결 시작**을 누릅니다. 최초 회사 PC 실행 후 정상/보류 상태를 확인합니다. 설정 적용 버튼으로 즉시 다시 조회할 수 있습니다.

- 기존 ERP의 DB_Information 설정을 회사 PC에서만 읽습니다. 비밀번호 입력·업로드나 ERP 실행은 필요하지 않습니다. 프로그램과 회사 네트워크는 켜져 있어야 합니다.
- 설정한 기간은 고정입니다. 기간을 바꾸면 다시 적용합니다. 370일 이내이며 프로그램 재시작과 업데이트 후에도 저장됩니다.
- 거래처 00530의 정확한 BASE 미입고 행만 SELECT로 읽습니다. ERP 입고/수정은 수행하지 않습니다. 관리자가 ERP에서 입고 처리합니다.
- 5분마다 갱신합니다. 실패 시 기존 목록을 유지하며 다음 주기에 재시도합니다.
- 동일 발주·수주·가공품번을 합치되, 원본 행별 수량과 로봇품번을 보존합니다. 같은 품번의 서로 다른 발주 행을 임의로 제거하지 않습니다.
- 로봇품번은 발주 행의 가공의뢰 복합 키(사업장/의뢰일/의뢰번호/의뢰순번)로 DEMREQ_HIS.MITM_CD를 연결합니다. 품번/수주 일치도 함께 확인합니다. 연결이 없거나 여러 개이면 전체 반영을 보류합니다. 임의의 로봇품번을 채우지 않습니다.
- 조회가 잘리거나 필수 정보/수량/상태가 모호하면 기존 작업을 유지합니다. 미입고 0행도 목록 전체를 비우지 않습니다.
- 기존 작업 시작·완료·입고 확인 기록은 초기화하지 않습니다. 진행 이력이 있는 품목의 미입고 수량이 달라지면 관리자 확인 대상으로 둡니다. 조회에서 빠진 품목은 아래 제외 목록으로 옮깁니다.
- DB 자동 연결을 시작하면 기존 화면 수집 설정을 해제합니다. 두 방식이 동시에 목록을 갱신하지 않습니다. DB 연결을 끄더라도 과거 화면 수집이 자동으로 다시 켜지지 않습니다.
- DB 진단·발주 미리보기는 아래 접힌 메뉴에 있습니다. 보류 시 새 ERP-db-check.json을 내려받아 확인할 수 있습니다. 업무 정보가 포함되므로 공개 저장소에 올리지 않습니다.

## 검증 범위

회사 DB의 기본 발주·품번·수량 조회는 사용자 제공 미리보기와 ERP XLSX 대조로 확인했습니다. 새 로봇품번 조인과 자동 갱신은 합성 데이터 단위/Chromium 테스트 및 Windows 교차 빌드로 검증합니다. 실제 회사 Windows SQL 실행은 배포 후 상태로 확인해야 합니다. 연결이 불명확하면 실제 자료에 반영하지 않습니다.
