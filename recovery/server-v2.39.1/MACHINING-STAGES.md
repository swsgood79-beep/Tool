# 가공 3공정 · PC 1.4.109

작업 표는 **로봇품번/가공품번 · 수량 · 절단 · 가공 1차 · 가공 2차**로 구성합니다. 팝업 너비와 최대 높이는 유지하며 열 너비·글자·여백을 조정합니다. 360/390/430px 화면의 밝은/어두운 모드에서 가로 넘침과 2품목 팝업 높이를 검증합니다. 품목이 많아지면 기존처럼 팝업 안에서 스크롤합니다.

절단 완료 수량만큼 가공 1차를 시작할 수 있고, 가공 1차 완료 수량만큼 가공 2차를 시작할 수 있습니다. 일부 수량씩 진행할 수 있습니다. 각 공정에서 시작한 계정이 완료하며 실제 시작·완료 시각과 작업자를 따로 기록합니다. 가공 2차 완료분만 관리자 ERP 입고 확인 대상으로 집계합니다. 실제 ERP 입고는 담당자가 직접 처리합니다.

작업자 화면에는 공정 상태·수량·시작/완료 버튼을 표시하고 작업 시각과 상세 시간 이력은 숨깁니다. 관리자 화면에서는 절단/1차/2차별 작업자·시작·완료 시각을 확인하고 CSV에도 공정을 구분해 저장합니다.

## 기존 자료

이전 버전의 단일 가공 완료 기록은 최종 가공 이력으로 보존합니다. 이미 완료·입고 확인한 건을 다시 미완료로 만들지 않습니다. 기존 진행 중 가공도 원래 시작 기록과 작업자를 유지한 채 완료할 수 있습니다. 새 가공 시작부터 1차와 2차를 구분합니다.

기존 단일 가공 수량은 새 선행 공정의 중복 작업을 요구하지 않도록 수량만 승계합니다. 실제로 하지 않은 가공 1차의 시작/완료 시각·작업자 기록을 만들어 넣지 않습니다. 화면에는 ‘기존 가공 ○개 · 기록 유지’, 공통 승계 완료는 ‘기존 기록’으로 표시하고 관리자 상세 이력·CSV에는 ‘기존 가공’으로 남깁니다. 승계는 과거 작업 ID에만 적용하며 새 2차 완료분이 다시 1차 선행 수량으로 중복 계산되지 않습니다.

PC 업데이트 후 작업자 화면을 새로고침합니다. 이전 화면에서 새 단일 가공을 시작하려고 하면 새로고침 안내가 표시됩니다. 기존 진행 중 가공 완료는 계속 가능합니다. APK 1.0.11은 유지합니다.
