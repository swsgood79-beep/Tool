# 실제 ERP 입고 관찰

대표 관리자 → 가공 작업 관리 → DB 진단·발주 미리보기 → 실제 입고 과정 관찰. ERP 실행/로그인 상태에서 관찰 시작, ‘관찰 중’ 표시 후 정상 업무 입고1건, 관찰 종료, 결과 받기. 준비/권한 실패 때 입고를 분석용으로 진행하지 마세요.

기존 INI 재사용. ALTER ANY EVENT SESSION와 VIEW SERVER STATE 또는 대응 SQL2022 세분 권한을 확인합니다. 자동 GRANT/계정변경은 하지 않습니다. 권한 부족/SQL 버전 미지원 시 실패 결과를 제공합니다. 임시 서버 XE 세션만 CREATE/START/DROP하며 ERP 행은 수정하지 않습니다. 고정2MiB ring buffer, 최대90초, 클라이언트 PID/호스트/DB 필터입니다. STARTUP_STATE OFF. PC 강제종료/통신단절로 세션 정리가 실패할 수 있으며 DPAPI 저널을 보존하고 새 시작을 차단합니다. ‘이전 관찰 정리’는 해당 저널의 정확한 소유 세션만 삭제합니다. 서버 재시작은 자동 실행하지 않습니다.

RPC/배치/저장 프로시저 문장 완료 이벤트를 수집합니다. 관찰 종료 후1.5초 전달 대기 후 활성 ring buffer 스냅샷을 읽고 세션을 제거합니다. 이벤트 수/텍스트/출력 한도와 SQL dropped 이벤트를 표시합니다. 일부 호출은 매개변수 값이나 동적 SQL 연결이 완전하지 않을 수 있습니다. 호출 완료는 트랜잭션 커밋이나 재고일치 증거가 아니므로 후속 대조가 필요합니다. 입고 전후 업무 행 스냅샷을 수집한다고 주장하지 않습니다.

결과에는 업무 SQL/품목/금액 등이 포함될 수 있어 비공개로 취급합니다. 인증 관련 SQL은 알려진 키워드로 제외하지만 모든 업무 비밀을 식별하는 보장은 없습니다. 회사PC 운영폴더에 DPAPI 암호화 .dat를 저장/복호 검증하고, 대표 관리자가 직접 JSON 다운로드합니다. JSON은 평문이므로 공유 범위를 제한하고 공개GitHub에 올리지 않습니다. 프로그램은 자동 외부 전송하지 않습니다. 출력 보호저장 실패 시 다운로드를 허용하지 않습니다. 파일 보관기간/삭제는 별도 관리 대상입니다.

네이티브 Windows/회사 SQL 실행은 현장 확인 전입니다. 합성자료 Go/API/Chromium과 Windows 교차빌드, Linux PowerShell7 AST 구문 검사를 검증합니다.
