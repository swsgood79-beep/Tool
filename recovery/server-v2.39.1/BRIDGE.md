# ERP 자동 연결 · PC 1.4.107 통합판

본 프로그램이 수집 구성요소를 포함하고 직접 실행·종료합니다. 별도 ERP 연결 도구를 내려받거나 매번 실행하지 않습니다. 관리자 APK 1.0.11은 그대로 사용합니다.

## 처음 한 번

1. PC 프로그램을 1.4.107로 업데이트합니다. 이전 별도 `Alpha-ERP-Auto-Bridge` 도구가 실행 중이면 그 도구만 종료합니다.
2. ERP를 펼치고 구매관리 → 발주대비미입고현황 → 거래처 가공사업부(00530)로 검색해 둡니다. 입고예정일 범위는 필요한 작업을 포함하도록 직접 지정합니다.
3. 대표 관리자 → 전체 → 가공 작업 · 입고 확인 → ERP 자동 연결 → **ERP 최초 설정**을 누릅니다. 자동 반영도 함께 켜집니다.
4. PC에 열린 안내에 따라 ERP Excel 버튼 위에서 F8, 같은 도구 모음의 검색 버튼 위에서 F7을 누릅니다. 실제 클릭하지 않습니다. 다음 안내 확인 후 Chrome 등으로 ERP 버튼을 가리고 F9를 누릅니다.
5. 최초 저장 성공 후 설정 저장 완료 안내를 확인합니다. 이후 별도 실행·반복 단축키 조작은 필요하지 않습니다. ERP 목록과 가공 목록의 BASE 수량을 처음 한 번 비교합니다.

## 이후 사용

자동 반영을 켜둔 상태면 본 프로그램 실행 시 저장 설정으로 ERP 연결을 시도합니다. 정상 수집은 약 5분 간격입니다. 오류·ERP 미실행·최소화 상태는 약 30초 간격으로 재확인하며 기존 작업 기록은 유지합니다. 프로그램을 종료하면 본 프로그램이 실행한 수집 프로세스도 종료합니다. 자동 반영 끄기도 수집 중지와 연결됩니다. 껐다 켜도 저장 설정은 유지됩니다.

ERP가 켜져 있고 해당 보고서가 조회된 상태여야 합니다. 최초 설정 이후에는 버튼을 매번 완전히 가릴 필요가 없습니다. ERP를 직접 보고 있는 동안에는 사용 중으로 대기하고, 다른 프로그램으로 전환하면 다시 수집을 시도합니다. 다른 창 뒤에 있어도 되지만 **최소화 수집과 화면 잠금·잠자기 상태는 지원하지 않습니다.** 본 프로그램이 ERP 로그인이나 메뉴 진입·거래처/날짜 조건 설정까지 대신하지 않습니다. ERP 실행 전이라면 기다렸다가 연결을 시도합니다.

설정에는 창 번호(HWND)나 프로세스 번호(PID)를 저장하지 않습니다. 현재 PrimeXAR.exe ERP 창과 같은 프로세스의 도구 모음을 새로 찾고, 화면 크기·도구 모음 상대 배치·화면 배율이 일치하며 후보가 하나일 때만 실행합니다. ERP 재시작 또는 창 이동 후에도 이 조건이 맞으면 다시 연결합니다. 화면 크기나 배치가 달라지면 **ERP 최초 설정**으로 다시 지정합니다. 여러 ERP 창이 있으면 하나만 남겨 주세요.

업무 중 ERP의 탭·조회 조건을 바꾸지 마세요. 화면 배치가 같다는 것만으로 현재 보고서 탭과 조회 내용까지 증명되지는 않습니다. 원본 XLSX의 필수 열과 BASE 거래처·수량을 다시 검증하고 잘못된 자료는 반영하지 않습니다.

## 반영과 보존

거래처 가공사업부이며 품명이 정확히 BASE인 항목만 반영합니다. BASE FRAME 등은 제외합니다. 같은 발주번호·수주번호·품번은 합산하며 로봇품번별 원본 구분을 유지합니다. 16개+16개는 32개입니다.

같은 파일은 중복 반영하지 않습니다. 작업 시작·완료·작업자 기록을 초기화하지 않으며 ERP에서 빠진 항목도 누락 표시와 기록을 유지합니다. 작업 시작 후 ERP 수량이 바뀌면 자동으로 기존 작업 수량을 덮어쓰지 않고 관리자 확인 대상으로 표시합니다. ERP 입고는 담당자가 ERP에서 직접 처리합니다.

검색 요청 후 3초 대기하며 접근 가능한 조회 완료 신호가 없어 최신 조회 완료를 확정할 수는 없습니다. ERP가 느리면 이전 표가 저장되는지 최초 현장 비교가 필요합니다. 저장 성공은 최신 조회 완료의 보장이 아닙니다. 정기 검색과 새 저장 설정 자동 재연결은 실제 ERP에서 확인이 필요합니다.

## 로컬 저장과 내장 구성요소

수집한 XLSX는 `%APPDATA%\AlphaERPBridge\current.xlsx`, 연결 상태는 `status.json`, 위치 설정은 `profile.json`입니다. 외부 업로드하지 않습니다. 서버는 자동 반영을 켠 경우에 약 10초 간격으로 결과를 읽습니다.

본 프로그램에 포함된 실행 파일을 전용 자료 폴더의 `erp-helper`에 해시 이름으로 준비하고, 내용 해시를 확인해 실행합니다. 원본과 전체 소스는 배포 소스 ZIP의 `embedded/erp-bridge-source/`에 있으며 manifest에 해시를 제공합니다. 사용자가 실행 파일을 따로 관리하지 않습니다. 새 PC나 Windows 사용자로 바꾸면 최초 설정을 다시 진행합니다.

ERP가 자동으로 연 새 엑셀은 전체 경로가 일치하고 저장된 문서일 때만 닫습니다. 다른 문서나 Excel 프로그램은 닫지 않습니다. 자동으로 열린 수집 엑셀은 수정하지 마세요. 잠깐 앞으로 나타날 수 있으며 업무 창 복귀를 Windows가 거부할 수도 있습니다.

검증 범위: 저장 설정 이동·배율·크기 검사, HWND/PID 비저장, 중복 프로세스 방지, 본 프로그램 종료·비활성화 시 자식 종료, 최초 설정 중복 요청/대표 관리자/CSRF 검증, BASE 필터/합산/기록 보존, 브라우저 화면 및 전체 Go 회귀, Windows 교차 빌드와 배포 소스 재빌드 일치. 실제 Windows ERP의 새 통합 흐름은 현장 확인 전입니다.
