# ERP 자동 연결 · 최초 현장 확인 버전

PC 1.4.106과 별도 Alpha-ERP-Auto-Bridge.exe를 같은 Windows 사용자로 실행합니다. 휴대폰 APK 1.0.11은 유지합니다.

1. PC 프로그램을 업데이트합니다. 대표 관리자 로그인 → 가공 작업 관리 → ERP 자동 연결 → 자동 반영 켜기를 누릅니다.
2. ERP를 펼치고 구매관리 → 발주대비미입고현황 → 거래처 가공사업부(00530)로 검색합니다. 필요한 입고예정일 범위를 충분히 넓혀 두세요. 날짜 범위·거래처는 도구가 바꾸지 않습니다.
3. 연결 도구를 실행하고 첫 안내 후 ERP Excel 버튼 위에 마우스를 올려 F8을 누릅니다. 다음 안내 후 같은 도구 모음의 검색 버튼 위에 마우스를 올려 F7을 누릅니다. 실제 클릭은 하지 않습니다.
4. 안내 확인 후 Chrome 등으로 ERP 버튼을 가리고 F9를 누릅니다. 이후 연결 도구를 열어 두면 5분마다 검색·내보내기·저장을 요청합니다. F8/F7/F9는 도구를 다시 실행할 때 한 번만 합니다.
5. 가공 관리 화면에서 상태와 마지막 ERP 반영을 확인합니다. 처음에는 ERP BASE 수량과 목록을 비교해 주세요. 새 조회 버튼 요청과 정기 반복은 이번 버전에서 추가돼 현장 확인이 필요합니다.

ERP는 펼쳐 두되 다른 창에 가려져 있어도 됩니다. **최소화하면 수집을 건너뛰며**, 다음 주기에 다시 시도합니다. 창을 움직이거나 크기·탭·조회 조건을 바꿨으면 도구를 닫고 올바른 보고서에서 다시 실행하세요. 창이나 도구 모음이 변경되면 수집을 중단합니다. 다른 창으로 가려지지 않은 경우에도 중단하므로 작업창으로 ERP를 덮어 주세요. PC 잠금·잠자기 상태는 지원을 확인하지 않았습니다.

실제 마우스 이동·전역 키보드 입력 없이 검증된 도구 모음 메시지를 재사용합니다. 검색 요청 후 3초 대기하고, 도구 모음 활성 상태를 재확인한 후 내보냅니다. ERP가 그보다 늦게 조회를 마치거나 기존 표를 반환하는지 확정할 수 없으므로 최초 현장 비교가 필요합니다. 저장 성공이 최신 ERP 조회 완료를 보장하지는 않습니다. 오류나 잘못된 엑셀은 기존 작업목록을 삭제하지 않습니다.

저장 파일은 `%APPDATA%\AlphaERPBridge\current.xlsx`, 연결 상태는 같은 폴더의 `status.json`입니다. 외부 업로드하지 않습니다. 서버는 대표 관리자가 켠 경우에만 약 10초 간격으로 새 파일을 읽습니다. 거래처 가공사업부·정확한 품명 BASE만 가져오며 BASE FRAME 등은 제외합니다. 같은 발주번호·수주번호·품번은 수량을 합치고 로봇품번별 원본 구분을 유지합니다. 16개+16개는 32개입니다.

같은 파일 재반영은 중복 등록하지 않습니다. 진행 중 작업의 수량·시작·완료·작업자 기록은 초기화하지 않습니다. ERP에서 빠진 항목은 누락으로 표시하고 기록을 유지합니다. 작업 시작 후 수량이 달라지면 기존 수량을 자동 덮어쓰지 않고 관리자 확인 대상으로 표시합니다. ERP 입고는 기존처럼 담당자가 ERP에서 직접 처리합니다.

ERP가 자동으로 연 새 엑셀은 전체 경로가 일치하고 저장된 문서일 때만 닫습니다. 다른 문서나 Excel 프로그램은 닫지 않습니다. 새 시험 엑셀은 수정하지 마세요. 잠깐 앞으로 뜰 수 있으며 원래 작업 창 복귀는 Windows가 거부할 수도 있습니다.

중지: 가공 관리의 자동 반영 끄기 + 연결 도구 콘솔 창 닫기. PC 프로그램 업데이트 후 자동 반영 설정은 유지되지만 연결 도구는 별도로 실행해야 합니다. ERP 재시작 후에도 위치를 다시 지정합니다. 연결 도구 자동 시작·ERP 로그인·메뉴 자동 진입·최소화 수집은 포함하지 않습니다.

검증: BASE 합산/필터, 중복 반영 방지, 누락 시 작업 기록 보존, 설정 재시작 보존, 대표 관리자/CSRF 검증, 전체 Go 회귀와 Windows 교차 빌드. 기존 가려진 저장/엑셀 닫기는 v0.3 현장 결과로 확인했으며 새 정기 검색 연동은 현장 확인 전입니다.

문제 발생 시 연결 도구 옆 `ERP-background-test-*` 폴더의 `ERP-background-test.json`과 `%APPDATA%\AlphaERPBridge\status.json`을 확인합니다. 실제 업무 엑셀은 공개 저장소에 올리지 마세요.
